    Quick Start Guide¶

    Get your Isaac ROS Jetbot NanoOWL up and running in 30 minutes with this streamlined guide.

    🎯 What You'll Achieve¶

    By the end of this guide, you'll have:

    • ✅ A fully functional autonomous robot
    • ✅ Real-time object detection running at 35+ FPS
    • ✅ Basic navigation and obstacle avoidance
    • ✅ Live video streaming and telemetry

    Estimated Time: 30 minutes Difficulty: ⭐ Beginner

    📋 Prerequisites Checklist¶

    Before starting, verify you have:

    Hardware¶

    • NVIDIA Jetson Orin Nano (or Nano/Xavier NX)
    • MicroSD card (64GB+, Class 10)
    • USB-C power supply (15W minimum)
    • Camera module (CSI or USB webcam)
    • Ethernet cable or WiFi adapter

    Software¶

    • JetPack 5.1+ installed on Jetson
    • SSH access to Jetson configured
    • Internet connection available

    Don't Have Hardware Yet?

    You can start with simulation using Docker Desktop on your PC. Full instructions in Installation Guide.

    🚀 Installation Methods¶

    Choose the fastest method for your needs:

    Perfect for: First-time users, quick demos, avoiding dependency conflicts

    Step 1: Clone Repository¶

    Bash
    # On your Jetson
cd ~
git clone https://github.com/TNG-Blue/Isaac_ROS-Jetbot_NanoOWL.git
cd Isaac_ROS-Jetbot_NanoOWL

    Step 2: Run Docker Container¶

    Bash
    # Pull and run pre-built container
docker-compose up -d

    This automatically: - Downloads optimized Isaac ROS containers - Sets up ROS2 environment - Configures GPU acceleration - Starts all necessary services

    Step 3: Verify Installation¶

    Bash
    # Check container status
docker ps

# View logs
docker-compose logs -f

    You should see output indicating services are running.

    Perfect for: Developers, maximum performance, custom modifications

    Step 1: Install ROS2 Humble¶

    Bash
    # Add ROS2 repository
sudo apt update
sudo apt install software-properties-common
sudo add-apt-repository universe

# Install ROS2 Humble
sudo apt update
sudo apt install ros-humble-desktop

    Step 2: Clone and Build¶

    Bash
    # Create workspace
mkdir -p ~/ros2_ws/src
cd ~/ros2_ws/src

# Clone repository
git clone https://github.com/TNG-Blue/Isaac_ROS-Jetbot_NanoOWL.git

# Install dependencies
cd ~/ros2_ws
rosdep install --from-paths src --ignore-src -r -y

# Build packages
colcon build --symlink-install --parallel-workers 2

    Step 3: Source Environment¶

    Bash
    # Source workspace
source ~/ros2_ws/install/setup.bash

# Add to bashrc for persistence
echo "source ~/ros2_ws/install/setup.bash" >> ~/.bashrc

    Perfect for: Multi-robot fleets, production deployments

    Step 1: Install Helm¶

    Bash
    curl https://raw.githubusercontent.com/helm/helm/main/scripts/get-helm-3 | bash

    Step 2: Deploy with Helm¶

    Bash
    # Add Helm repository
helm repo add tng-blue https://tng-blue.github.io/charts
helm repo update

# Install chart
helm install jetbot-nanoowl tng-blue/jetbot-nanoowl \
  --namespace robotics \
  --create-namespace \
  --set image.tag=latest

    Step 3: Check Deployment¶

    Bash
    # View pods
kubectl get pods -n robotics

# Check logs
kubectl logs -f -n robotics -l app=jetbot-nanoowl

    🎮 Launch Your First Robot¶

    Now let's bring your robot to life!

    1. Start Core Services¶

    Bash
    # Services start automatically, just verify
docker-compose ps
    Bash
    # Launch main system
ros2 launch jetbot_nanoowl bringup.launch.py
    Bash
    # Already running, check status
kubectl get all -n robotics

    2. Verify Camera Feed¶

    Bash
    # Check camera topic
ros2 topic list | grep image

# View camera stream (install if needed: sudo apt install ros-humble-rqt-image-view)
ros2 run rqt_image_view rqt_image_view

    You should see live camera feed in the GUI window.

    3. Test Object Detection¶

    Bash
    # Start object detection
ros2 launch jetbot_detection object_detection.launch.py

# View detections in terminal
ros2 topic echo /detections

    Expected output:

    YAML
    detections:
  -
    results:
      -
        hypothesis:
          class_id: "person"
          score: 0.95
        bbox:
          center:
            x: 320.5
            y: 240.0
          size_x: 120
          size_y: 180

    4. Enable Basic Navigation¶

    Bash
    # Launch SLAM and navigation
ros2 launch jetbot_nav nav_bringup.launch.py

    📊 Verify Everything Works¶

    Run our automated verification script:

    Bash
    # Run system health check
cd ~/Isaac_ROS-Jetbot_NanoOWL
./scripts/health_check.sh

    Expected output:

    Text Only
    ✅ ROS2 environment: OK
✅ Camera detected: /dev/video0
✅ GPU acceleration: CUDA 11.8
✅ Object detection model: yolov8n.engine
✅ Network connectivity: OK
✅ All 8 core nodes: RUNNING

System Status: HEALTHY
Ready for autonomous operation!

    🎯 Your First Mission¶

    Let's test autonomous navigation with obstacle avoidance:

    Mission 1: Follow Mode¶

    Make the robot follow you:

    Bash
    # Start follow mode
ros2 launch jetbot_behavior person_following.launch.py

    What it does: - Detects people using YOLOv8 - Maintains 1.5m distance - Follows the closest person - Avoids obstacles automatically

    Stand in front of the robot and walk slowly. It should follow you while maintaining distance!

    Mission 2: Patrol Mode¶

    Set up autonomous patrol:

    Bash
    # Define patrol waypoints
ros2 run jetbot_nav set_waypoints.py

# Start patrol
ros2 launch jetbot_behavior patrol.launch.py

    What it does: - Navigates between defined waypoints - Uses SLAM for localization - Avoids dynamic obstacles - Returns to home on battery low

    🎛️ Access Control Interface¶

    Web Dashboard¶

    Open your browser and navigate to:

    Text Only
    http://<jetson-ip>:8080

    The dashboard provides: - 📹 Live camera feed with detections - 🗺️ Real-time map and robot position - 🎮 Joystick control interface - 📊 System telemetry and diagnostics - ⚙️ Configuration settings

    RViz2 Visualization¶

    For advanced visualization:

    Bash
    # On your desktop PC
export ROS_DOMAIN_ID=0
ros2 run rviz2 rviz2 -d ~/Isaac_ROS-Jetbot_NanoOWL/config/jetbot.rviz

    This shows: - 3D point cloud from LIDAR (if equipped) - Detected objects with bounding boxes - Navigation path and costmaps - TF transforms and robot model

    📈 Performance Optimization¶

    Quick Tweaks for Better Performance¶

    1. Set Power Mode (Jetson Orin Nano):

      Bash
      # Maximum performance mode (25W)
sudo nvpmodel -m 0
sudo jetson_clocks

    2. Adjust Detection Resolution:

      YAML
      # Edit: config/detection_params.yaml
detection:
  input_size: [640, 640]  # Try [416, 416] for more FPS
  confidence_threshold: 0.5

    3. Monitor Performance:

      Bash
      # Watch GPU utilization
tegrastats

# Check node performance
ros2 topic hz /detections

    ❓ Troubleshooting¶

    Common Issues¶

    Camera not detected
    Bash
    # List video devices
ls -l /dev/video*

# Check camera permissions
sudo usermod -aG video $USER

# Test camera directly
gst-launch-1.0 v4l2src device=/dev/video0 ! xvimagesink
    GPU not being used
    Bash
    # Verify CUDA installation
nvcc --version

# Check GPU access
python3 -c "import torch; print(torch.cuda.is_available())"

# Monitor GPU usage
watch -n 1 nvidia-smi
    ROS2 nodes not communicating
    Bash
    # Check network configuration
echo $ROS_DOMAIN_ID

# Verify discovery
ros2 doctor --report

# Check firewall
sudo ufw status
    Low FPS / High latency
    • Use lower resolution: 640x640 → 416x416
    • Reduce camera framerate to 15 FPS
    • Enable power mode: sudo nvpmodel -m 0
    • Check thermal throttling: tegrastats
