    First Steps with Isaac ROS Jetbot¶

    Learn the fundamentals of operating your autonomous robot through hands-on examples.

    🎯 Learning Objectives¶

    By completing this guide, you'll be able to:

    • ✅ Launch and monitor ROS2 nodes
    • ✅ Control the robot manually
    • ✅ View sensor data and camera feeds
    • ✅ Run basic autonomous behaviors
    • ✅ Understand the system architecture

    Duration: 45 minutes Level: Beginner

    🚀 Lesson 1: Understanding ROS2 Basics¶

    What is ROS2?¶

    ROS2 (Robot Operating System 2) is a framework for robot software development providing:

    • Nodes: Independent processes that perform specific tasks
    • Topics: Channels for asynchronous data streaming
    • Services: Request/response communication
    • Actions: Long-running tasks with feedback
    graph LR
    Camera[Camera Node] -->|Image Topic| Detection[Detection Node]
    Detection -->|Objects Topic| Navigation[Nav Node]
    Navigation -->|Velocity| Control[Motor Controller]

    Essential ROS2 Commands¶

    Bash
    # List all active nodes
ros2 node list

# List all topics
ros2 topic list

# View topic data
ros2 topic echo /camera/image_raw

# Check topic frequency
ros2 topic hz /camera/image_raw

# View node information
ros2 node info /object_detection

# List all services
ros2 service list

# Call a service
ros2 service call /reset_pose std_srvs/srv/Empty

    Command Shortcuts

    Use Tab for auto-completion in ROS2 commands!

    🎮 Lesson 2: Manual Control¶

    Start Teleop Control¶

    Control your robot with keyboard or joystick:

    Bash
    # Launch keyboard teleop
ros2 run teleop_twist_keyboard teleop_twist_keyboard

    Controls:

    Text Only
    Moving around:
   u    i    o
   j    k    l
   m    ,    .

u/o : rotate left/right while moving forward
j/l : rotate left/right
m/. : rotate left/right while moving backward
k   : stop

q/z : increase/decrease max speeds by 10%
w/x : increase/decrease only linear speed by 10%
e/c : increase/decrease only angular speed by 10%

    Bash
    # Install joystick support
sudo apt install ros-humble-joy -y

# Launch joy node
ros2 run joy joy_node

# Launch teleop
ros2 launch jetbot_teleop joystick.launch.py

    Controls (Xbox/PS4):

    Text Only
    Left Stick : Forward/Backward
Right Stick : Rotate Left/Right
A/X Button : Turbo mode
B/Circle : Emergency stop

    Monitor Velocity Commands¶

    In a new terminal, observe the velocity commands being sent:

    Bash
    ros2 topic echo /cmd_vel

    Expected output:

    YAML
    linear:
  x: 0.5  # Forward velocity (m/s)
  y: 0.0
  z: 0.0
angular:
  x: 0.0
  y: 0.0
  z: 0.2  # Rotation velocity (rad/s)

    📹 Lesson 3: Viewing Sensor Data¶

    View Camera Feed¶

    Bash
    # Install image viewer (if not present)
sudo apt install ros-humble-rqt-image-view -y

# View camera
ros2 run rqt_image_view rqt_image_view

    Select topic: /camera/image_raw

    View LIDAR Data¶

    Bash
    # Install RViz2 (if not present)
sudo apt install ros-humble-rviz2 -y

# Launch RViz with config
ros2 run rviz2 rviz2 -d ~/ros2_ws/src/Isaac_ROS-Jetbot_NanoOWL/config/jetbot.rviz

    Add displays: 1. Click Add → LaserScan 2. Set topic to /scan 3. Set Fixed Frame to laser_frame

    Monitor IMU Data¶

    Bash
    # View IMU topic
ros2 topic echo /imu/data

# Expected output:
# orientation: {x, y, z, w}
# angular_velocity: {x, y, z}
# linear_acceleration: {x, y, z}

    View All Topics with rqt¶

    Bash
    # Launch rqt (ROS2 GUI toolkit)
rqt

    Useful plugins: - Topic Monitor: View all topic activity - Node Graph: Visualize node connections - Message Publisher: Send test messages - Service Caller: Call services manually

    🧠 Lesson 4: Object Detection¶

    Launch Detection System¶

    Bash
    # Start object detection
ros2 launch jetbot_detection object_detection.launch.py

    This starts: - Camera capture node - YOLOv8 TensorRT inference - Bounding box visualization - Detection publisher

    View Detection Results¶

    Bash
    # View detections
ros2 topic echo /detections

    Output:

    YAML
    detections:
  -
    results:
      -
        hypothesis:
          class_id: "person"
          score: 0.94
        bbox:
          center: {x: 320, y: 240}
          size_x: 80
          size_y: 120

    Bash
    # View annotated image
ros2 run rqt_image_view rqt_image_view /detection/image_annotated

    Test Detection with Different Objects¶

    Try detecting: - ✅ People walking - ✅ Chairs and tables - ✅ Bottles and cups - ✅ Electronic devices

    Monitor detection performance:

    Bash
    # Check FPS
ros2 topic hz /detections

# Expected: 30-35 Hz on Jetson Orin Nano

    🗺️ Lesson 5: Basic Navigation¶

    Launch SLAM¶

    Bash
    # Start SLAM system
ros2 launch jetbot_slam slam_toolbox.launch.py

    This enables: - Real-time mapping - Robot localization - Loop closure detection

    Build Your First Map¶

    1. Launch SLAM (above)

    2. Open RViz:

      Bash
      ros2 run rviz2 rviz2 -d config/slam.rviz

    3. Drive Around:

      Bash
      # In new terminal
ros2 run teleop_twist_keyboard teleop_twist_keyboard

    4. Observe Map Building:

    5. Watch occupancy grid update in RViz
    6. Drive slowly for best results

    7. Cover entire area systematically

    8. Save Map:

      Bash
      ros2 run nav2_map_server map_saver_cli -f my_map

    Creates: - my_map.yaml - Map metadata - my_map.pgm - Occupancy grid image

    Navigate to Goal¶

    Once map is built:

    Bash
    # Load saved map and start navigation
ros2 launch jetbot_nav navigation.launch.py map:=my_map.yaml

    In RViz: 1. Click 2D Pose Estimate 2. Click on robot's current location 3. Click 2D Nav Goal 4. Click destination on map

    Robot will autonomously navigate to goal, avoiding obstacles!

    🤖 Lesson 6: Autonomous Behaviors¶

    Behavior 1: Person Following¶

    Bash
    ros2 launch jetbot_behavior person_following.launch.py

    Algorithm: 1. Detect people using YOLOv8 2. Track closest person 3. Maintain 1.5m distance 4. Stop if person disappears

    Safety features: - Maximum speed: 0.5 m/s - Emergency stop distance: 0.3m - Lost target timeout: 3 seconds

    Behavior 2: Line Following¶

    Bash
    ros2 launch jetbot_behavior line_following.launch.py

    Uses camera to follow colored tape on ground.

    Behavior 3: Patrol Route¶

    Bash
    # Define waypoints
ros2 run jetbot_nav set_waypoints.py

# Start patrol
ros2 launch jetbot_behavior patrol.launch.py

    Continuously patrols between defined waypoints.

    📊 Lesson 7: System Monitoring¶

    Resource Usage¶

    Bash
    # CPU and GPU usage
tegrastats

# Process monitoring
htop

# ROS2-specific monitoring
ros2 doctor --report

    Performance Metrics¶

    Bash
    # Node performance
ros2 run rqt_top rqt_top

# Topic bandwidth
ros2 topic bw /camera/image_raw

# Topic delay
ros2 topic delay /camera/image_raw

    Logging¶

    Bash
    # View node logs
ros2 run rqt_console rqt_console

# Or command line
ros2 node list
ros2 node info /node_name

    🎯 Practice Exercises¶

    Exercise 1: Sensor Fusion (15 min)¶

    Goal: Combine camera and LIDAR for obstacle detection

    Bash
    # Launch combined visualization
ros2 launch jetbot_viz sensor_fusion.launch.py

    Tasks: 1. Observe camera feed and LIDAR scan simultaneously 2. Identify objects detected by both sensors 3. Note differences in detection range and accuracy

    Exercise 2: Custom Waypoint Mission (20 min)¶

    Goal: Create custom navigation mission

    Bash
    # Record waypoints
ros2 run jetbot_nav waypoint_recorder.py

    Drive robot manually to 4-5 locations, pressing 'w' at each to save waypoint.

    Then execute:

    Bash
    ros2 run jetbot_nav waypoint_follower.py waypoints.yaml

    Exercise 3: Behavior Modification (30 min)¶

    Goal: Modify person-following distance

    1. Open source file:

      Bash
      nano ~/ros2_ws/src/Isaac_ROS-Jetbot_NanoOWL/jetbot_behavior/scripts/person_following.py

    2. Change target distance (line ~45):

      Python
      TARGET_DISTANCE = 2.0  # Changed from 1.5m to 2.0m

    3. Rebuild:

      Bash
      cd ~/ros2_ws
colcon build --packages-select jetbot_behavior
source install/setup.bash

    4. Test modified behavior!

    ✅ Knowledge Check¶

    Test your understanding:

    What command lists all active ROS2 nodes?
    Bash
    ros2 node list
    How do you view data being published to a topic?
    Bash
    ros2 topic echo /topic_name
    What are the three main communication types in ROS2?
    • Topics: Streaming data (publisher/subscriber)
    • Services: Request/response
    • Actions: Long-running tasks with feedback
    How do you save a map created by SLAM?
    Bash
    ros2 run nav2_map_server map_saver_cli -f map_name
