    Getting Started¶

    Welcome to Isaac ROS Jetbot NanoOWL! This guide will help you get your robot up and running quickly.

    🎯 Prerequisites¶

    Before you begin, ensure you have:

    Hardware Requirements¶

    • ✅ NVIDIA Jetson Orin Nano Super (8GB recommended)
    • ✅ SD Card: 128GB or larger, Class 10/UHS-I
    • ✅ Power Supply: 5V/4A USB-C or barrel jack adapter
    • ✅ Robot Chassis: Compatible mobile platform
    • ✅ Sensors: At minimum, one camera module

    Software Requirements¶

    • ✅ JetPack: 5.1.2 or later
    • ✅ Ubuntu: 22.04 LTS (included in JetPack)
    • ✅ ROS2: Humble Hawksbill (installation covered)
    • ✅ Python: 3.10+
    • ✅ Git: For cloning repositories

    Knowledge Requirements¶

    • 📚 Basic Linux command line usage
    • 📚 Familiarity with ROS2 concepts (helpful but not required)
    • 📚 Understanding of robotics basics

    📋 Installation Paths¶

    We offer multiple installation methods:

    Best for: Quick setup, isolated environment, easy updates

    Bash
    # Clone repository
git clone https://github.com/TNG-Blue/Isaac_ROS-Jetbot_NanoOWL.git
cd Isaac_ROS-Jetbot_NanoOWL

# Run with Docker Compose
docker-compose up -d

    ✅ Advantages: - Fastest setup time (~30 minutes) - No dependency conflicts - Easy rollback and updates - Consistent environment

    ⚠️ Considerations: - Requires ~10GB disk space - Slight performance overhead

    Best for: Maximum performance, development work, custom modifications

    Bash
    # Install ROS2 Humble
sudo apt update && sudo apt install -y ros-humble-desktop

# Clone and build
git clone https://github.com/TNG-Blue/Isaac_ROS-Jetbot_NanoOWL.git
cd Isaac_ROS-Jetbot_NanoOWL
colcon build --symlink-install

    ✅ Advantages: - Best performance - Full system access - Easier debugging - No containerization overhead

    ⚠️ Considerations: - Longer setup time (~2 hours) - Potential dependency conflicts - Manual updates required

    Best for: Multi-robot fleets, production deployments, scalability

    Bash
    # Add Helm repository
helm repo add tng-blue https://tng-blue.github.io/charts

# Install with Helm
helm install jetbot-nanoowl tng-blue/jetbot-nanoowl \
  --namespace robotics --create-namespace

    ✅ Advantages: - Production-ready orchestration - Easy scaling and updates - Built-in monitoring - High availability

    ⚠️ Considerations: - Complex initial setup - Requires K8s knowledge - Resource overhead

    ❓ Common Questions¶

    What if I don't have all the hardware?

    You can start with minimal hardware (Jetson + one camera) and add sensors gradually. Many features work with reduced sensor sets.

    Can I use a different Jetson model?

    Yes! The platform supports Jetson Nano, Xavier NX, and AGX Xavier. Performance will vary.

    Do I need robotics experience?

    Not required! Our tutorials start from basics. However, Linux familiarity is helpful.

    What if I get stuck?

    Check our Troubleshooting Guide or ask in GitHub Discussions.
