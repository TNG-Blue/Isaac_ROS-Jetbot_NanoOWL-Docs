    Getting Started

    Hardware Setup Guide¶

    Complete guide to assembling and connecting all hardware components for your Isaac ROS Jetbot NanoOWL.

    📦 Bill of Materials (BOM)¶

    Essential Components¶

    Component Specification Quantity Purpose
    NVIDIA Jetson Orin Nano Super 8GB Developer Kit 1 Main compute unit
    MicroSD Card 128GB UHS-I (or NVMe SSD) 1 Storage
    Power Supply 5V/4A USB-C or barrel jack 1 Power
    Camera Module IMX-477 (4K) or IMX-219 1+ Vision
    Robot Chassis Compatible mobile platform 1 Mobility
    Motor Controller I2C or PWM compatible 1 Motor control
    Ethernet Cable Cat5e or better 1 Initial setup

    Recommended Add-ons¶

    Component Specification Quantity Purpose
    Arduino Portenta H7 Dual-core STM32H747 1 Motor control hub
    OpenMV Cam H7 NXP i.MX RT1062 1 Edge vision
    LIDAR RPLIDAR A1/A2 1 360° ranging
    IMU MPU6050 or MPU9250 1-2 Motion sensing
    GPS Module Neo-M8N or better 1-2 Positioning
    Stereo Cameras IMX-219 pair 2 Depth perception
    LoRa Module SX1276/78 1-2 Long-range comm
    WiFi Adapter 2.⅘GHz dual-band 1 Wireless connectivity

    🔧 Assembly Instructions¶

    Step 1: Mount Jetson Orin Nano Super¶

    1. Prepare Chassis: 

      - Clean mounting surface
- Install standoffs (M2.5 or M3)
- Ensure ventilation clearance

    2. Secure Jetson: 

      - Align mounting holes
- Use anti-vibration standoffs
- Leave 20mm clearance above for cooling
- Thermal pad on underside recommended

    Cooling Requirements

    Jetson Orin Nano Super can dissipate 25W. Ensure active cooling (fan) or large heatsink for sustained workloads.

    Step 2: Connect Camera(s)¶

    CSI Camera Connection¶

    1. Lift black latch on CSI port CAM0
2. Insert camera ribbon cable (contacts facing PCB)
3. Press latch down firmly
4. Secure camera module to chassis

    Test camera: 

    # List video devices
ls /dev/video*

# Test capture
nvgstcapture-1.0


    1. Connect left camera to CSI CAM0
2. Connect right camera to CSI CAM1
3. Measure baseline distance (10-15cm recommended)
4. Mount cameras parallel and level
5. Use calibration target for alignment

    Test stereo: 

    # Test both cameras
ros2 launch jetbot_stereo test_cameras.launch.py

    Step 3: Install LIDAR¶

    1. Physical Mount: 

      - Mount on top plate for 360° view
- Center on robot for balanced measurements
- Height: 15-20cm above ground
- Ensure clear rotation (no obstructions)

    2. USB Connection: 

      # Connect LIDAR to USB port
# Verify detection
ls /dev/ttyUSB*

# Set permissions
sudo chmod 666 /dev/ttyUSB0

# Or add permanent udev rule
sudo cp config/99-rplidar.rules /etc/udev/rules.d/
sudo udevadm control --reload-rules

    3. Test LIDAR: 

      ros2 launch rplidar_ros rplidar_a2_launch.py

# View data
ros2 topic echo /scan

    Step 4: Connect IMU¶

    I2C Connection¶

    # Enable I2C on Jetson
sudo usermod -aG i2c $USER

# Verify I2C bus
i2cdetect -y -r 1

# Expected output: MPU6050 at 0x68

    Wiring (primary IMU): 

    Jetson GPIO → MPU6050
Pin 3 (SDA) → SDA
Pin 5 (SCL) → SCL
Pin 1 (3.3V) → VCC
Pin 6 (GND)  → GND

    Test IMU: 

    ros2 run jetbot_imu imu_node

# Verify data
ros2 topic echo /imu/data

    Step 5: Connect Motor Controller¶

    Ethernet Connection (Portenta H7)¶

    # Assign static IP
sudo nano /etc/netplan/01-netcfg.yaml

    network:
  version: 2
  ethernets:
    eth0:
      addresses:
        - 192.168.1.100/24  # Jetson IP
      dhcp4: no

    sudo netplan apply

# Test connection to Portenta (192.168.1.103)
ping 192.168.1.103

    I2C Connection (Alternative)¶

    If using I2C motor controller: 

    Jetson GPIO → Motor Controller
Pin 3 (SDA) → SDA
Pin 5 (SCL) → SCL
Pin 2 (5V)  → VIN
Pin 6 (GND) → GND

    Step 6: GPS Module¶

    Jetson GPIO → GPS Module
Pin 8 (TX)  → RX
Pin 10 (RX) → TX
Pin 2 (5V)  → VCC
Pin 6 (GND) → GND

    Test GPS: 

    # Install GPS tools
sudo apt install gpsd gpsd-clients -y

# Start GPS daemon
sudo systemctl start gpsd
sudo systemctl enable gpsd

# Test reception
cgps -s

    Step 7: Power System¶

    Power Distribution¶

    graph LR
    PSU[5V/4A Power Supply] --> JETSON[Jetson: 5V/15W]
    PSU --> PORTENTA[Portenta: 5V/2W]
    BUCK[Buck Converter] --> MOTORS[Motors: 12V]
    BATTERY[Battery 11.1V] --> BUCK

    style PSU fill:#FF6B6B
    style BATTERY fill:#4ECDC4

    Power Safety

    • Never connect motors directly to Jetson power
    • Use separate power rails for high-current devices
    • Add fuses for overcurrent protection
    • Ensure proper wire gauge (16-18 AWG for motors)

    ✅ Verification Checklist¶

    Power System¶

    • All voltage rails measured correctly
    • No excessive heat from regulators
    • Battery protection circuit functional
    • Emergency stop working

    Vision System¶

    • Cameras detected (/dev/video*)
    • Image quality acceptable
    • Frame rate stable at 30 FPS
    • No connection errors in logs

    Sensors¶

    • LIDAR spinning and publishing data
    • IMU publishing at 100+ Hz
    • GPS acquiring satellites (outdoors)
    • All I2C devices detected

    Motor Control¶

    • Communication with motor controller
    • Motors respond to test commands
    • Emergency stop tested
    • Encoders publishing data (if equipped)

    Networking¶

    • Ethernet connection stable
    • WiFi connecting properly
    • LoRa modules paired
    • ROS2 nodes discovering each other

    🎯 Calibration¶

    Camera Calibration¶

    # Install calibration tool
sudo apt install ros-humble-camera-calibration -y

# Run calibration
ros2 run camera_calibration cameracalibrator \
  --size 8x6 \
  --square 0.108 \
  image:=/camera/image_raw

    Follow on-screen instructions with checkerboard pattern.

    Stereo Calibration¶

    ros2 launch jetbot_stereo stereo_calibration.launch.py

# Move checkerboard through field of view
# Calibration data saved to: ~/.ros/camera_info/

    IMU Calibration¶

    # Place robot on level surface
ros2 run jetbot_imu calibrate_imu.py

# Follow prompts for 6-axis calibration

    🔧 Troubleshooting¶

    Camera not detected 
    # Check CSI connection
dmesg | grep -i camera

# Try different CSI port
# Verify ribbon cable orientation (contacts toward PCB)

# Test with NVIDIA tools
nvgstcapture-1.0
    LIDAR not spinning
    • Check USB connection and power
    • Verify motor driver not overheating
    • Test with rplidar-motor-test utility
    IMU data erratic
    • Check I2C connections for loose wires
    • Verify I2C pull-up resistors (4.7kΩ)
    • Shield from electromagnetic interference
    • Calibrate IMU in stable environment
    Motors not responding
    • Verify motor controller power
    • Check PWM signal connections
    • Test motor controller independently
    • Verify communication protocol (I2C/UART/Ethernet)
