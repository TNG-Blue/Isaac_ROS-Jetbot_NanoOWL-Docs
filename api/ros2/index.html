    ROS2 Interfaces Reference¶

    Message definitions and service interfaces for ROS2 communication.

    📚 Overview¶

    ROS2 Interfaces define the contract for communication between nodes in a distributed system. This document describes all messages, services, and actions available in the Isaac ROS Jetbot NanoOWL platform.

    Key Features: - ✅ Standardized message types - ✅ Language-agnostic communication - ✅ Type-safe interfaces - ✅ Middleware abstraction - ✅ Distributed system support

    📦 Installation¶

    Prerequisites¶

    Bash
    # Install ROS2 Humble
sudo apt install ros-humble-desktop

# Source ROS2
source /opt/ros/humble/setup.bash

    Install jetbot_interfaces Package¶

    Bash
    # Clone and build
cd ~/ros2_ws/src
git clone https://github.com/TNG-Blue/Isaac_ROS-Jetbot_NanoOWL.git
cd Isaac_ROS-Jetbot_NanoOWL

# Build interfaces
cd ~/ros2_ws
colcon build --packages-select jetbot_interfaces

# Source workspace
source install/setup.bash

    📊 Message Types¶

    1. Motor Commands¶

    MotorCommand¶

    YAML
    # jetbot_interfaces/msg/MotorCommand.msg
float64 left_speed    # Left motor speed (0-255)
float64 right_speed   # Right motor speed (0-255)

    Usage:

    Bash
    ros2 topic pub /motor/command jetbot_interfaces/MotorCommand \
  "{left_speed: 128, right_speed: 128}"

    2. Sensor Data¶

    MotorState¶

    YAML
    # jetbot_interfaces/msg/MotorState.msg
float64 left_velocity      # m/s
float64 right_velocity     # m/s
float64 left_current       # Amperes
float64 right_current      # Amperes
float64 left_temperature   # °C
float64 right_temperature  # °C

    IMUData¶

    YAML
    # jetbot_interfaces/msg/IMUData.msg
Header header
geometry_msgs/Vector3Stamped acceleration    # m/s²
geometry_msgs/Vector3Stamped angular_velocity  # rad/s
geometry_msgs/Vector3Stamped magnetic_field  # Gauss
float64 temperature         # °C

    DetectionArray¶

    YAML
    # jetbot_interfaces/msg/DetectionArray.msg
Header header
Detection[] detections
bool is_async              # True if asynchronous

---
# Definition of Detection
Header header
int32 class_id
string class_name
float32 confidence
geometry_msgs/Polygon bbox  # Normalized coordinates

    3. Navigation¶

    Trajectory¶

    YAML
    # jetbot_interfaces/msg/Trajectory.msg
Header header
geometry_msgs/PoseStamped[] waypoints
float64[] velocities       # Target velocity at each waypoint
float64 total_distance     # meters
float64 estimated_time     # seconds

    🔧 Service Types¶

    1. Motor Services¶

    SetVelocity¶

    YAML
    # jetbot_interfaces/srv/SetVelocity.srv
---
Request:
  float64 linear_x   # m/s
  float64 angular_z  # rad/s
---
Response:
  bool success
  string message

    Usage:

    Bash
    ros2 service call /motor/set_velocity jetbot_interfaces/SetVelocity \
  "{linear_x: 0.5, angular_z: 0.0}"

    GetMotorState¶

    YAML
    # jetbot_interfaces/srv/GetMotorState.srv
---
Request:
  # (empty)
---
Response:
  MotorState state

    ⚡ Action Types¶

    Navigation Actions¶

    NavigateToGoal¶

    YAML
    # jetbot_interfaces/action/NavigateToGoal.action
---
Goal:
  geometry_msgs/PoseStamped target_pose
  float64 max_velocity
  bool avoid_obstacles
---
Result:
  bool success
  float64 distance_traveled
  float64 time_elapsed
---
Feedback:
  geometry_msgs/PoseStamped current_pose
  float64 distance_to_goal
  int32 percent_complete

    Usage:

    Python
    from rclpy.action import ActionClient
from jetbot_interfaces.action import NavigateToGoal

client = ActionClient(node, NavigateToGoal, 'navigate_to_goal')

goal_msg = NavigateToGoal.Goal()
goal_msg.target_pose.position.x = 5.0
goal_msg.target_pose.position.y = 5.0

future = client.send_goal_async(goal_msg)

  Type: jetbot_interfaces/MotorState

  Description: Motor feedback

/detection/objects:
  Type: jetbot_interfaces/DetectionArray

  Type: nav_msgs/Odometry
  Frequency: 50 Hz
  Description: Odometry estimation

/slam/pose:
  Type: geometry_msgs/PoseWithCovarianceStamped

  Description: SLAM pose estimate

    Common parameters exposed via ROS2 parameter interface:

    YAML
    Motor Parameters:

  /motor_controller/max_angular: float
  /motor_controller/acceleration_limit: float

Camera Parameters:
  /camera/exposure: int
  /camera/gain: int
  /camera/auto_white_balance: bool

Detection Parameters:
  /detector/confidence_threshold: float
  /detector/nms_threshold: float
  /detector/input_size: int

    Usage:

    Bash
    # Get parameter
ros2 param get /motor_controller max_velocity

# Set parameter
ros2 param set /motor_controller max_velocity 2.0

# List all parameters
ros2 param list

    📝 Message Examples¶

    Example 1: Publish Motor Command¶

    Python
    import rclpy
from jetbot_interfaces.msg import MotorCommand

def main():
    rclpy.init()
    node = rclpy.create_node('motor_commander')

    publisher = node.create_publisher(MotorCommand, '/motor/command', 10)

    msg = MotorCommand()
    msg.left_speed = 128
    msg.right_speed = 128

    publisher.publish(msg)
    print("Sent motor command")

    rclpy.shutdown()

if __name__ == '__main__':
    main()

    Example 2: Subscribe to Motor State¶

    Python
    import rclpy
from jetbot_interfaces.msg import MotorState

def motor_callback(msg):
    print(f"Left velocity: {msg.left_velocity} m/s")
    print(f"Right velocity: {msg.right_velocity} m/s")
    print(f"Left current: {msg.left_current} A")

def main():
    rclpy.init()
    node = rclpy.create_node('motor_listener')

    subscription = node.create_subscription(
        MotorState,
        '/motor/state',
        motor_callback,
        10
    )

    rclpy.spin(node)
    rclpy.shutdown()

if __name__ == '__main__':
    main()

    Example 3: Call Service¶

    Python
    import rclpy
from jetbot_interfaces.srv import SetVelocity

def main():
    rclpy.init()
    node = rclpy.create_node('velocity_controller')

    client = node.create_client(SetVelocity, '/motor/set_velocity')

    while not client.wait_for_service(timeout_sec=1.0):
        print('Service not available, waiting again...')

    request = SetVelocity.Request()
    request.linear_x = 0.5
    request.angular_z = 0.0

    future = client.call_async(request)
    rclpy.spin_until_future_complete(node, future)

    result = future.result()
    print(f"Success: {result.success}")
    print(f"Message: {result.message}")

    rclpy.shutdown()

if __name__ == '__main__':
    main()

    🎯 Complete Example: Multi-Robot Communication¶

    Python
    import rclpy
from rclpy.node import Node
from geometry_msgs.msg import Twist
from jetbot_interfaces.msg import MotorState

class FleetController(Node):
    def __init__(self):
        super().__init__('fleet_controller')

        # Publishers for each robot
        self.robot1_pub = self.create_publisher(Twist, '/jetbot1/cmd_vel', 10)
        self.robot2_pub = self.create_publisher(Twist, '/jetbot2/cmd_vel', 10)

        # Subscribers for status
        self.robot1_sub = self.create_subscription(
            MotorState, '/jetbot1/motor/state', self.robot1_callback, 10)
        self.robot2_sub = self.create_subscription(
            MotorState, '/jetbot2/motor/state', self.robot2_callback, 10)

        # Timer for control loop
        self.timer = self.create_timer(0.1, self.control_loop)

        self.robot1_state = None
        self.robot2_state = None

    def robot1_callback(self, msg):
        self.robot1_state = msg

    def robot2_callback(self, msg):
        self.robot2_state = msg

    def control_loop(self):
        if self.robot1_state and self.robot2_state:
            # Send coordinated commands
            cmd = Twist()
            cmd.linear.x = 0.5

            self.robot1_pub.publish(cmd)
            self.robot2_pub.publish(cmd)

            self.get_logger().info(
                f"Robot1 velocity: {self.robot1_state.left_velocity:.2f}")
            self.get_logger().info(
                f"Robot2 velocity: {self.robot2_state.left_velocity:.2f}")

def main():
    rclpy.init()
    controller = FleetController()
    rclpy.spin(controller)
    rclpy.shutdown()

if __name__ == '__main__':
    main()

    🔍 Discovery Commands¶

    Bash
    # List all message types
ros2 interface list --filter-type msg

# List all service types
ros2 interface list --filter-type srv

# List all action types
ros2 interface list --filter-type action

# Show message definition
ros2 interface show jetbot_interfaces/msg/MotorState

# Show service definition
ros2 interface show jetbot_interfaces/srv/SetVelocity

    🐛 Debugging¶

    Bash
    # Monitor specific topic
ros2 topic echo /motor/state

# Check message frequency
ros2 topic hz /motor/state

# Check bandwidth usage
ros2 topic bw /camera/image_raw

# List subscribers/publishers
ros2 topic info /motor/state

# Capture data to bag file
ros2 bag record -o my_data /motor/state /camera/image_raw
