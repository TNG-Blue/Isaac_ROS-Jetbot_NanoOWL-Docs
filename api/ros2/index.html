    API ROS 2

    ROS 2 Interfaces¶

    Conventions (frames, QoS, acknowledgement) are described in ROS 2 Integration; the complete wiring of all nodes is the System Node Graph.

    Cross-package topics¶

    Topic Type Publisher Subscribers
    /imu/data sensor_msgs/Imu (ENU/FLU) jetowl_fc (200 Hz) or jetowl_bridge sensor link (1 kHz) uav_state_estimator, flight_controller_node, lidar_slam_node, dashboards
    /gps/fix, /gps/vel_cov NavSatFix, TwistWithCovarianceStamped jetowl_bridge sensor link uav_state_estimator, flight_controller_node, network_bridge_node
    /baro/pressure sensor_msgs/FluidPressure jetowl_fc (25 Hz) uav_state_estimator
    /odometry/filtered nav_msgs/Odometry uav_state_estimator flight controller, MPC, mission planner, network bridge, telemetry logger
    flight/setpoint, flight/active MultiDOFJointTrajectory, Bool flight_controller_node uav_trajectory_controller
    flight/cmd_vel geometry_msgs/Twist (world ENU) flight_controller_node external velocity-mode autopilot
    /cmd_vel geometry_msgs/Twist (heading frame) target follower, joystick flight_controller_node in MANUAL
    flight/status std_msgs/String flight_controller_node bridges, mission planner, dashboards
    flight/waypoints, flight/nav_command PoseArray, String mission planner, network bridge, RF failsafe, dashboards flight_controller_node
    control/attitude_setpoint, control/thrust QuaternionStamped, Float64 [N] uav_trajectory_controller jetowl_fc
    control/disturbance Vector3Stamped [m/s²] uav_trajectory_controller mission_planner_node (wind estimate)
    mission/status ros2_mission_planner/MissionStatus mission_planner_node network bridge, dashboards
    /tracked/markers, /tracked/objects MarkerArray, ros2_lidar_ai_msgs/TrackedObjectArray object_tracker_node MPC obstacles, costmap, semantic fusion
    /object_detections vision_msgs/Detection2DArray object-detection decoders visualiser, semantic fusion
    /scan, /range LaserScan, Range ld19_node, lpb40b_node lidar_slam_node; /scan also to the network bridge (MAVLink OBSTACLE_DISTANCE)
    /map, slam/pose OccupancyGrid, PoseWithCovarianceStamped lidar_slam_node dashboards, RViz
    rf_threat_alert, rf_failsafe/active String, Bool (transient local) RF spectrum nodes dashboards
    /diagnostics DiagnosticArray every 📊 node monitoring, dashboards, pipeline coordinator

    micro-ROS contracts¶

    The firmware topic contracts are defined in uros_app.h of each firmware and mirrored by the bridge:

    • Flight controller: micro-ROS over Ethernet §2.
    • Camera MCU: micro-ROS over Ethernet §2.
    • Bridge side: JetOwl Bridge.
