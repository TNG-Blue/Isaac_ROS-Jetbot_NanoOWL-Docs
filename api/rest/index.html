    REST API Reference¶

    HTTP-based API for remote control and cloud integration.

    📚 Overview¶

    The REST API provides language-agnostic access to robot functionalities via HTTP, enabling remote control, web dashboards, and cloud integration.

    Key Features: - ✅ Language-agnostic (any HTTP client) - ✅ Cloud-friendly - ✅ Web dashboard integration - ✅ Standard HTTP methods - ✅ JSON request/response - ✅ Authentication support

    🚀 Quick Start¶

    Base URL¶

    Text Only
    http://jetbot.local:8080/api/v1

    Or with IP:

    Text Only
    http://192.168.1.100:8080/api/v1

    Simple Command¶

    Bash
    # Move forward
curl -X POST http://jetbot.local:8080/api/v1/motor/velocity \
  -H "Content-Type: application/json" \
  -d '{"linear_x": 0.5, "angular_z": 0.0}'

# Response
{
  "success": true,
  "message": "Velocity command sent"
}

    🔐 Authentication¶

    API Keys¶

    All requests require an API key in the header:

    Bash
    curl -X GET http://jetbot.local:8080/api/v1/status \
  -H "Authorization: Bearer YOUR_API_KEY"

    Getting an API Key¶

    Bash
    # First-time setup
curl -X POST http://jetbot.local:8080/api/v1/auth/register \
  -H "Content-Type: application/json" \
  -d '{
    "username": "admin",
    "password": "secure_password"
  }'

# Response
{
  "api_key": "sk_live_abc123def456...",
  "expires_in": 86400
}

    📊 API Endpoints¶

    Motor Control¶

    POST /motor/velocity¶

    Set robot velocity.

    Request:

    JSON
    {
  "linear_x": 0.5,      // m/s, range [-1.0, 1.0]
  "angular_z": 0.1,     // rad/s, range [-3.14, 3.14]
  "duration": 5.0       // Optional, seconds
}

    Response:

    JSON
    {
  "success": true,
  "message": "Velocity set",
  "velocity": {
    "linear_x": 0.5,
    "angular_z": 0.1
  }
}

    GET /motor/state¶

    Get current motor state.

    Response:

    JSON
    {
  "left_velocity": 0.5,
  "right_velocity": 0.5,
  "left_current": 0.8,
  "right_current": 0.8,
  "left_temperature": 35.2,
  "right_temperature": 35.5,
  "healthy": true
}

    POST /motor/emergency_stop¶

    Emergency stop.

    Response:

    JSON
    {
  "success": true,
  "message": "Emergency stop activated"
}

    Camera¶

    GET /camera/frame¶

    Get latest camera frame.

    Parameters:

    Text Only
    ?format=base64    // base64, binary, json
?quality=95       // JPEG quality (1-100)
?width=640        // Resize to width (optional)
?height=480       // Resize to height (optional)

    Response (format=base64):

    JSON
    {
  "frame": "iVBORw0KGgoAAAANS...",
  "width": 1280,
  "height": 720,
  "timestamp": "2026-02-04T10:30:45Z",
  "camera_matrix": [[919.8, 0, 640], [0, 919.8, 360], [0, 0, 1]]
}

    Response (format=binary):

    Text Only
    [Binary JPEG data]
Content-Type: image/jpeg

    POST /camera/snapshot¶

    Save snapshot to disk.

    Request:

    JSON
    {
  "filename": "snapshot_001.jpg",
  "directory": "/data/snapshots"
}

    Response:

    JSON
    {
  "success": true,
  "filepath": "/data/snapshots/snapshot_001.jpg",
  "size_bytes": 102400
}

    GET /camera/info¶

    Get camera calibration info.

    Response:

    JSON
    {
  "width": 1280,
  "height": 720,
  "fps": 30,
  "camera_matrix": [
    [919.8, 0, 640],
    [0, 919.8, 360],
    [0, 0, 1]
  ],
  "distortion": [0.05, -0.1, 0.0, 0.0, 0.0],
  "calibrated": true
}

    Object Detection¶

    POST /detection/detect¶

    Run object detection on image.

    Request (option 1: URL):

    JSON
    {
  "image_url": "http://jetbot.local:8080/api/v1/camera/frame?format=base64",
  "confidence_threshold": 0.5
}

    Request (option 2: Binary):

    Text Only
    Content-Type: application/octet-stream
[Binary JPEG data]

    Response:

    JSON
    {
  "detections": [
    {
      "class_id": 0,
      "class_name": "person",
      "confidence": 0.92,
      "bbox": {
        "x": 0.1,
        "y": 0.2,
        "width": 0.3,
        "height": 0.4
      }
    },
    {
      "class_id": 2,
      "class_name": "car",
      "confidence": 0.85,
      "bbox": {
        "x": 0.5,
        "y": 0.3,
        "width": 0.2,
        "height": 0.25
      }
    }
  ],
  "inference_time_ms": 45.2,
  "fps": 22
}

    GET /detection/config¶

    Get detection configuration.

    Response:

    JSON
    {
  "model": "yolov8n.engine",
  "confidence_threshold": 0.5,
  "nms_threshold": 0.45,
  "input_size": 640,
  "inference_time_ms": 45.0,
  "fps": 22
}

    POST /detection/config¶

    Update detection configuration.

    Request:

    JSON
    {
  "confidence_threshold": 0.6,
  "nms_threshold": 0.5
}

    Navigation¶

    POST /navigation/goal¶

    Set navigation goal.

    Request:

    JSON
    {
  "x": 5.0,
  "y": 5.0,
  "theta": 0.0,
  "max_velocity": 0.5,
  "avoid_obstacles": true
}

    Response:

    JSON
    {
  "success": true,
  "goal_id": "nav_001",
  "estimated_distance": 7.07,
  "estimated_time": 14.14
}

    GET /navigation/status¶

    Get navigation status.

    Response:

    JSON
    {
  "status": "executing",  // idle, executing, completed, failed
  "current_pose": {
    "x": 2.5,
    "y": 2.5,
    "theta": 0.0
  },
  "distance_to_goal": 3.54,
  "progress_percent": 50
}

    POST /navigation/cancel¶

    Cancel navigation.

    Response:

    JSON
    {
  "success": true,
  "message": "Navigation cancelled"
}

    🧪 Code Examples¶

    Python with requests¶

    Python
    import requests
import json
import base64
from PIL import Image
from io import BytesIO

BASE_URL = "http://jetbot.local:8080/api/v1"
API_KEY = "sk_live_abc123..."

headers = {
    "Authorization": f"Bearer {API_KEY}",
    "Content-Type": "application/json"
}

# Move forward
response = requests.post(
    f"{BASE_URL}/motor/velocity",
    headers=headers,
    json={"linear_x": 0.5, "angular_z": 0.0}
)
print(response.json())

# Get camera frame
response = requests.get(
    f"{BASE_URL}/camera/frame?format=base64",
    headers=headers
)
data = response.json()
frame_data = base64.b64decode(data['frame'])
image = Image.open(BytesIO(frame_data))
image.show()

# Run detection
response = requests.post(
    f"{BASE_URL}/detection/detect",
    headers=headers,
    json={"image_url": f"{BASE_URL}/camera/frame?format=base64"}
)
detections = response.json()['detections']
for det in detections:
    print(f"{det['class_name']}: {det['confidence']:.2f}")

# Set navigation goal
response = requests.post(
    f"{BASE_URL}/navigation/goal",
    headers=headers,
    json={"x": 5.0, "y": 5.0, "max_velocity": 0.5}
)
print(response.json())

    JavaScript/Node.js¶

    JavaScript
    const fetch = require('node-fetch');

const BASE_URL = 'http://jetbot.local:8080/api/v1';
const API_KEY = 'sk_live_abc123...';

const headers = {
  'Authorization': `Bearer ${API_KEY}`,
  'Content-Type': 'application/json'
};

// Move forward
async function moveForward() {
  const response = await fetch(`${BASE_URL}/motor/velocity`, {
    method: 'POST',
    headers,
    body: JSON.stringify({
      linear_x: 0.5,
      angular_z: 0.0
    })
  });
  const data = await response.json();
  console.log(data);
}

// Get camera frame
async function getCameraFrame() {
  const response = await fetch(
    `${BASE_URL}/camera/frame?format=base64`,
    { headers }
  );
  const data = await response.json();
  console.log(`Frame: ${data.width}x${data.height}`);
}

// Run detection
async function detectObjects() {
  const response = await fetch(`${BASE_URL}/detection/detect`, {
    method: 'POST',
    headers,
    body: JSON.stringify({
      image_url: `${BASE_URL}/camera/frame?format=base64`,
      confidence_threshold: 0.5
    })
  });
  const data = await response.json();
  data.detections.forEach(det => {
    console.log(`${det.class_name}: ${det.confidence.toFixed(2)}`);
  });
}

moveForward();
getCameraFrame();
detectObjects();

    cURL Examples¶

    Bash
    # Setup
API_KEY="sk_live_abc123..."
URL="http://jetbot.local:8080/api/v1"

# Move forward
curl -X POST $URL/motor/velocity \
  -H "Authorization: Bearer $API_KEY" \
  -H "Content-Type: application/json" \
  -d '{"linear_x": 0.5, "angular_z": 0.0}'

# Get motor state
curl -X GET $URL/motor/state \
  -H "Authorization: Bearer $API_KEY"

# Get camera frame
curl -X GET "$URL/camera/frame?format=base64" \
  -H "Authorization: Bearer $API_KEY" > frame.json

# Run detection
curl -X POST $URL/detection/detect \
  -H "Authorization: Bearer $API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "image_url": "'$URL'/camera/frame?format=base64",
    "confidence_threshold": 0.5
  }'

# Get system status
curl -X GET $URL/status \
  -H "Authorization: Bearer $API_KEY"

    📊 Response Codes¶

    Code Meaning Example
    200 Success Motor velocity set successfully
    201 Created New resource created
    400 Bad Request Invalid JSON or parameters
    401 Unauthorized Missing or invalid API key
    404 Not Found Endpoint doesn't exist
    429 Too Many Requests Rate limit exceeded
    500 Server Error Internal server error
    503 Service Unavailable Robot not responding

    🔄 WebSocket Support (Optional)¶

    For real-time streaming:

    JavaScript
    const ws = new WebSocket('ws://jetbot.local:8080/ws/stream');

ws.onopen = () => {
  console.log('Connected');
  ws.send(JSON.stringify({
    type: 'subscribe',
    channel: 'camera_stream'
  }));
};

ws.onmessage = (event) => {
  const data = JSON.parse(event.data);
  if (data.type === 'frame') {
    console.log('Received frame:', data.width, 'x', data.height);
  }
};

    🐛 Error Handling¶

    Python
    import requests

try:
    response = requests.post(
        "http://jetbot.local:8080/api/v1/motor/velocity",
        headers={"Authorization": f"Bearer {API_KEY}"},
        json={"linear_x": 0.5, "angular_z": 0.0},
        timeout=5
    )

    if response.status_code == 200:
        print("Success:", response.json())
    elif response.status_code == 401:
        print("Authentication failed")
    elif response.status_code == 503:
        print("Robot unavailable")
    else:
        print(f"Error {response.status_code}: {response.text}")

except requests.ConnectionError:
    print("Cannot connect to robot")
except requests.Timeout:
    print("Request timed out")

    📈 Rate Limiting¶

    API requests are rate-limited to prevent abuse:

    Text Only
    - 100 requests per minute (free tier)
- 1000 requests per minute (pro tier)

Remaining quota in response headers:
X-RateLimit-Limit: 100
X-RateLimit-Remaining: 95
X-RateLimit-Reset: 1675000000
