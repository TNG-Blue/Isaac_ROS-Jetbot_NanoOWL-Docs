    📚 API Overview¶

    The Isaac ROS Jetbot NanoOWL platform provides multiple APIs for different programming languages and use cases.

    🔧

    C++ API

    High-performance native API for system-level programming and real-time control

    ROS2 Docs →
    🌐

    HTTP-based API for remote control and cloud integration

    REST Docs →

    🎯 Choose Your API¶

    When to Use Each API¶

    API Use Case Pros Cons
    C++ Real-time control, performance-critical Maximum performance, low latency Complex, steeper learning curve
    Python Development, scripting, prototyping Easy to learn, rapid development Slower, higher overhead
    ROS2 Multi-process distributed systems Middleware abstraction, modularity Requires ROS2 framework
    REST Remote access, web integration, cloud Language-agnostic, firewall-friendly Network latency, less real-time

    🚀 Quick Start by Language¶

    C++¶

    C++
    #include <jetbot/motor_controller.hpp>

int main() {
    jetbot::MotorController motor;
    motor.setVelocity(0.5, 0.0);  // Move forward
    return 0;
}

    → Full C++ API Documentation

    Python¶

    Python
    from jetbot import MotorController

motor = MotorController()
motor.set_velocity(linear_x=0.5, angular_z=0.0)

    → Full Python API Documentation

    ROS2¶

    Bash
    ros2 service call /motor_control jetbot_interfaces/SetVelocity \
  "{linear_x: 0.5, angular_z: 0.0}"

    → Full ROS2 Interfaces Documentation

    REST¶

    Bash
    curl -X POST http://jetbot.local:8080/api/v1/motor/velocity \
  -H "Content-Type: application/json" \
  -d '{"linear_x": 0.5, "angular_z": 0.0}'

    → Full REST API Documentation

    💡 API Selection Guide¶

    Use C++ API If:¶

    • ✅ You need maximum performance
    • ✅ Real-time constraints exist
    • ✅ Minimizing latency is critical
    • ✅ You're integrating native libraries
    • ❌ You're just prototyping

    Use Python API If:¶

    • ✅ You're prototyping quickly
    • ✅ Ease of use is important
    • ✅ You need rapid development
    • ✅ Performance is adequate
    • ❌ You need sub-millisecond latency

    Use ROS2 Interfaces If:¶

    • ✅ Building modular systems
    • ✅ Need inter-process communication
    • ✅ Using ROS2 ecosystem
    • ✅ Multi-node coordination needed
    • ❌ You want simple scripting

    Use REST API If:¶

    • ✅ Integrating with cloud
    • ✅ Need language-agnostic access
    • ✅ Web dashboard required
    • ✅ Remote access needed
    • ❌ Real-time performance critical
