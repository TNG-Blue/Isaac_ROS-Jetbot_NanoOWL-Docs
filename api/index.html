        📚 API Reference¶

        Welcome to the comprehensive API documentation for Isaac ROS Jetbot NanoOWL. This section provides detailed information about all available APIs, services, interfaces, and the integrated CudaVision high-performance image processing library.

        🎯 API Overview

        Isaac ROS Jetbot NanoOWL provides multiple API layers for different use cases: ROS 2 interfaces, REST APIs, WebSocket connections, gRPC services for high-performance applications, and CudaVision for GPU-accelerated image processing with 15-20x performance improvements.

        🏗️ API Architecture¶

        🚀 CudaVision Processing Layer

        GPU-accelerated image processing with 15-20x performance boost

        • Professional camera enhancement
        • Real-time background removal
        • Advanced noise reduction
        • RAW sensor processing

        🤖 ROS 2 Interface Layer

        Native robotics communication via ROS 2 topics and services

        • Real-time sensor data
        • Navigation commands
        • Perception results
        • Motor control

        ⚡ WebSocket Layer

        Real-time bidirectional communication for live updates

        • Live video streaming
        • Telemetry data
        • System notifications
        • Remote debugging

        🚀 gRPC Layer

        High-performance binary protocol for enterprise applications

        • Bulk data transfer
        • Service mesh integration
        • Multi-language support
        • Advanced streaming

        from isaac_ros_jetbot import JetbotClient
import cudavision as cv

# Initialize client with CudaVision support
client = JetbotClient('http://localhost:8080')
client.authenticate('your-api-key')

# Get robot status
status = client.robot.get_status()
print(f"Battery: {status.battery_level}%")

# Enhanced camera processing with CudaVision
camera_feed = client.perception.get_camera_feed()
enhanced_image = cv.auto_enhance_image(camera_feed)

# Real-time background removal
no_bg_image = cv.remove_background(
    camera_feed, 
    background_color=(0, 255, 0),  # Green screen
    threshold=25
)

# Professional image enhancement
with cv.CudaVisionCore() as processor:
    result = processor.enhance_image(camera_feed, mode='professional')
    stats = processor.get_performance_stats()
    print(f"GPU processing time: {stats['processing_time_ms']:.2f}ms")

# Move robot
client.robot.move(linear_x=0.5, angular_z=0.2, duration=3.0)
