        Isaac ROS Jetbot NanoOWL¶

        🤖 Isaac ROS Jetbot NanoOWL

        Advanced Robotics Platform with AI-Powered Object Detection

        🚀 Get Started📚 View Tutorials

        🌟 Overview¶

        Isaac ROS Jetbot NanoOWL là một nền tảng robotics tiên tiến được xây dựng trên Jetson Orin Nano Super, tích hợp các công nghệ AI và computer vision hàng đầu. Dự án kết hợp sức mạnh của Isaac ROS với khả năng phát hiện đối tượng thời gian thực của NanoOWL.

        ⚡

        High Performance Computing

        Powered by dual Jetson Orin Nano Super delivering 40 TOPS AI performance for exceptional real-time processing

        🧠

        AI-Powered Perception

        Real-time object detection using NanoOWL and Isaac ROS perception stack with 30+ FPS processing

        🔧

        Professional Hardware

        6 BLDC motors with high-resolution encoders and Arduino Portenta H7 for precise real-time control

        ☁️

        Cloud Native Architecture

        Fully containerized with Docker and orchestrated using Kubernetes for scalable deployment

        🔥 Key Features¶

        💻 Computing Power¶

        • Dual Jetson Orin Nano Super: 2× 1024-core NVIDIA Ampere GPU, 6-core ARM Cortex-A78AE CPU
        • Combined Performance: 40 TOPS AI, 48 GFLOPS CPU processing
        • Memory: 16GB total LPDDR5 @ 102.4 GB/s bandwidth
        • Storage: High-speed eUFS + microSD expansion

        🎯 AI & Machine Learning¶

        • Real-time Object Detection: NanoOWL with 15-20 FPS inference
        • Visual SLAM: 20Hz mapping and localization updates
        • Computer Vision: Isaac ROS perception pipeline
        • Deep Learning: TensorRT optimized models

        🛠️ Hardware Components¶

        • Motors: 6× BLDC motors with integrated encoders
        • Control: Arduino Portenta H7 (STM32H747) dual-core MCU
        • Communication: CAN, I2C, UART, SPI interfaces
        • Power: 24V/480W distributed power system

        🏗️ System Architecture¶

        🧠 Distributed Computing¶

        • Jetson 1: Perception, object detection, sensor processing
        • Jetson 2: SLAM, navigation, path planning
        • Portenta H7: Real-time motor control, safety systems
        • Host PC: Development, monitoring, visualization

        📡 Communication Stack¶

        • ROS 2 Humble: Primary robotics middleware
        • DDS: Real-time distributed communication
        • micro-ROS: Bridge between Jetson and Portenta H7
        • CAN Bus: Motor controller communication

        🐳 Container Architecture¶

        • Base Images: Isaac ROS optimized containers
        • Microservices: Perception, navigation, control services
        • Orchestration: Kubernetes for scaling and management
        • Monitoring: Prometheus + Grafana observability
