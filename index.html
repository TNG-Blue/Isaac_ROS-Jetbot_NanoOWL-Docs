    🤖 Isaac ROS Jetbot NanoOWL

    Enterprise-grade autonomous robotics platform powered by NVIDIA Jetson Orin Nano Super

    ⚡ Real-time AI Perception • 🗺️ Advanced SLAM • 🚀 Production-Ready Deployment

    ✨ Key Features¶

    🧠

    Advanced AI Perception

    State-of-the-art object detection with YOLOv8 and NanoOWL, optimized for real-time inference on Jetson hardware with TensorRT acceleration.

    🗺️

    Real-time SLAM

    Visual-inertial odometry with 3D reconstruction, path planning using A* and RRT* algorithms, and dynamic obstacle avoidance.

    📡

    Multi-sensor Fusion

    Seamless integration of cameras, LIDAR, IMU, and GPS sensors with synchronized data processing and advanced sensor calibration.

    ⚡

    CUDA Acceleration

    GPU-optimized computer vision pipeline with custom CUDA kernels for image processing, feature extraction, and neural network inference.

    🌙

    Night Vision

    Thermal camera integration with AI-enhanced low-light performance for 24/7 autonomous operation in any lighting condition.

    🚀

    Production Ready

    Complete deployment stack with Docker, Kubernetes, Helm charts, OTA updates, and comprehensive monitoring solutions.

    🚀 Quick Start¶

    Get up and running in minutes:

    Bash
    # Clone the repository
git clone https://github.com/TNG-Blue/Isaac_ROS-Jetbot_NanoOWL.git
cd Isaac_ROS-Jetbot_NanoOWL

# Build and run with Docker
docker-compose up -d

# Access the system
ros2 launch jetbot_nanoowl bringup.launch.py
    Bash
    # Install ROS2 Humble
sudo apt update
sudo apt install ros-humble-desktop

# Clone and build
git clone https://github.com/TNG-Blue/Isaac_ROS-Jetbot_NanoOWL.git
cd Isaac_ROS-Jetbot_NanoOWL
colcon build --symlink-install

# Source and launch
source install/setup.bash
ros2 launch jetbot_nanoowl bringup.launch.py
    Bash
    # Install with Helm
helm repo add tng-blue https://tng-blue.github.io/charts
helm install jetbot-nanoowl tng-blue/jetbot-nanoowl

# Check status
kubectl get pods -n robotics
