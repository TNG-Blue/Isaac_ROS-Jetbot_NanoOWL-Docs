    Android Mobile User Interface

    Mobile App¶

    JetbotNanoOWL is the Android ground station for the Jetbot / JetOwl robots: flight display, 3-D and satellite maps, mission planning, the Remote UAV link, RViz2, remote desktop and a full Ubuntu on the phone. It lives in its own repository, TNG-Blue/JetbotNanoOWL, pulled in here as the submodule Mobile/Android/JetbotNanoOWL.

    • Qt app — the one to install

      C++17 + Qt 6.8 Quick. Satellite map and missions, Remote UAV over USB-C or Bluetooth, RViz2, Linux environment, VNC/SSH. Release qt-build-N.

      Qt app

    • Kotlin app — the original console

      Kotlin UI on the original C++ estimation core (JNI), with its own Linux environment. Kept and built alongside. Release kotlin-build-N.

    Architecture¶

    The phone observes and plans; it does not fly. The estimation chain runs in C++ on its own thread; QML only draws. Commands reach the aircraft through the pilot's remote, or — with no remote — directly to the Jetson only after the operator arms it.

    Who commands the aircraft¶

    CommandArbiter decides every 50 ms. No timer ever hands control back to the phone: the direct latch clears whenever a remote is heard, and only a new tap by the operator re-arms it.

    stateDiagram-v2
    [*] --> NONE
    NONE --> REMOTE: remote STATUS < 1.5 s old
    DIRECT --> REMOTE: remote heard (latch cleared)
    REMOTE --> NONE: no STATUS for 1.5 s
    NONE --> DIRECT: operator arms it, heartbeat < 3 s
    DIRECT --> NONE: heartbeat lost
    note right of REMOTE
        plans go to the remote;
        MAVLink commands closed in the core
    end note
    note right of DIRECT
        MAVLink mission upload,
        MISSION_START, RTL
    end note
