    Power System¶

    Complete power management, battery systems, and energy distribution documentation.

    ⚡ Power System Overview¶

    The Isaac ROS Jetbot NanoOWL platform features a sophisticated power management system designed for extended autonomous operation and system reliability.

    System Highlights: - 🔋 Dual Battery Support: Hot-swappable battery configuration - ⚡ Intelligent Power Distribution: Prioritized power delivery - 🛡️ Multiple Protection Layers: Overvoltage, overcurrent, thermal - 📊 Real-time Monitoring: Battery health, power consumption tracking - 🔌 Multiple Power Rails: 12V, 5V, 3.3V optimized distribution

    🔋 Battery System¶

    Primary Battery (11.1V LiPo 3S)¶

    Specifications:

    YAML
    Chemistry: Lithium Polymer (LiPo)
Configuration: 3S (3 cells in series)
Nominal Voltage: 11.1V (3.7V per cell)
Voltage Range:
  Fully Charged: 12.6V (4.2V per cell)
  Nominal: 11.1V (3.7V per cell)
  Minimum Safe: 9.0V (3.0V per cell)
  Critical Low: 7.5V (2.5V per cell - avoid)

Capacity Options:
  Standard: 5000 mAh
  Extended: 8000 mAh
  Competition: 10000 mAh

Discharge Rating:
  Continuous: 25C (125A for 5000mAh)
  Burst: 50C (250A for 5000mAh)

Connector: XT60 (high-current rated)
Balance Connector: JST-XH 4S

Physical:
  Dimensions: 138 x 43 x 25 mm (5000mAh)
  Weight: 380g (5000mAh)

    Runtime Estimation:

    YAML
    Power Consumption Profile:
  Idle: 8-10W
  Normal Operation: 15-20W
  Peak Load: 30-35W
  Maximum: 50W (burst)

Expected Runtime (5000mAh @ 11.1V = 55.5Wh):
  Idle Mode: 5.5 hours
  Normal Operation: 3.0 hours
  Continuous Peak: 1.5 hours
  Mixed Usage: 2.5 hours (typical)

    Battery Management System (BMS)¶

    Protection Features:

    YAML
    Overvoltage Protection:
  Threshold: 4.25V per cell
  Action: Disconnect charging

Undervoltage Protection:
  Warning: 3.2V per cell
  Critical: 3.0V per cell
  Action: System shutdown at critical

Overcurrent Protection:
  Continuous: 30A
  Burst (10s): 50A
  Short Circuit: Immediate disconnect

Thermal Protection:
  Operating Range: 0°C to 45°C
  Warning: 50°C
  Shutdown: 60°C

Cell Balancing:
  Type: Passive balancing
  Balance Current: 50mA per cell
  Balance Threshold: 0.01V difference

    BMS Wiring:

    Text Only
    Battery Pack → BMS → Power Distribution
───────────────────────────────────────

Battery Connections:
  B- (Black)   → BMS B- terminal
  B1 (Red)     → BMS Cell 1 (3.7V)
  B2 (Red)     → BMS Cell 2 (7.4V)
  B3 (Red)     → BMS Cell 3 (11.1V)
  B+ (Red)     → BMS B+ terminal

BMS Outputs:
  P+ → Power Distribution (12V)
  P- → Ground

Balance Lead:
  JST-XH 4-pin → BMS balance port
  Pin 1: B-
  Pin 2: Cell 1
  Pin 3: Cell 2
  Pin 4: B+

    Power Rails:

    YAML
    12V Rail (Motors & Servos):
  Input: 11.1V (battery)
  Regulation: None (direct)
  Filtering: LC filter (100μH, 470μF)
  Max Current: 20A
  Protection: Resettable fuse (PTC)
  Loads:
    - DC Motors (2x): 15A peak
    - Servo Motors (4x): 3A peak

5V Rail (Jetson & Peripherals):
  Input: 11.1V (battery)
  Regulation: Buck converter (>90% efficiency)
  Output: 5V ± 0.1V
  Max Current: 5A
  Protection: Overcurrent, overvoltage
  Loads:
    - Jetson Orin Nano: 3A typical
    - USB Devices: 1A
    - Cooling Fan: 0.5A

5V Rail (USB Hub):
  Input: 11.1V (battery)
  Regulation: Separate buck converter
  Output: 5V ± 0.05V (USB compliant)
  Max Current: 3A
  Protection: Per-port current limiting
  Loads:
    - USB Camera: 500mA
    - USB LIDAR: 1A
    - USB Accessories: 1.5A

3.3V Rail (Sensors):
  Input: 5V
  Regulation: LDO (Low Dropout)
  Output: 3.3V ± 0.05V
  Max Current: 2A
  Protection: Thermal shutdown
  Loads:
    - IMU: 50mA
    - GPS: 100mA
    - Magnetometer: 50mA
    - Digital Sensors: 500mA

    📊 Power Monitoring¶

    Real-time Monitoring System¶

    Hardware:

    YAML
    Voltage Monitoring:
  IC: INA260 (Texas Instruments)
  Resolution: 1.25mV
  Range: 0-36V
  Accuracy: ±1%

Current Monitoring:
  Method: Hall-effect sensor
  IC: ACS712-30A
  Resolution: 66mV/A
  Range: -30A to +30A
  Accuracy: ±1.5%

Power Calculation:
  P = V × I
  Update Rate: 10 Hz
  Averaging: 10-sample moving average

    ROS2 Monitoring Node:

    Python
    #!/usr/bin/env python3
"""
Power monitoring node - Publishes battery and power consumption data
"""

import rclpy
from rclpy.node import Node
from sensor_msgs.msg import BatteryState
from std_msgs.msg import Float32
import smbus2
import time

# INA260 I2C address
INA260_ADDR = 0x40

# Register addresses
REG_VOLTAGE = 0x02
REG_CURRENT = 0x01
REG_POWER = 0x03

class PowerMonitorNode(Node):
    def __init__(self):
        super().__init__('power_monitor_node')

        # I2C bus
        self.bus = smbus2.SMBus(1)

        # Publishers
        self.battery_pub = self.create_publisher(
            BatteryState,
            '/battery/state',
            10
        )

        self.power_pub = self.create_publisher(
            Float32,
            '/battery/power',
            10
        )

        # Battery parameters
        self.declare_parameter('capacity_ah', 5.0)
        self.declare_parameter('voltage_min', 9.0)
        self.declare_parameter('voltage_max', 12.6)
        self.declare_parameter('voltage_nominal', 11.1)

        # State tracking
        self.total_charge = 0.0  # Coulomb counting
        self.last_time = time.time()

        # Timer for periodic monitoring
        self.create_timer(0.1, self.monitor_callback)  # 10 Hz

        self.get_logger().info('Power monitor node started')

    def read_ina260(self, register):
        """Read 16-bit value from INA260"""
        data = self.bus.read_i2c_block_data(INA260_ADDR, register, 2)
        value = (data[0] << 8) | data[1]

        # Convert to signed if needed
        if value & 0x8000:
            value = -((value ^ 0xFFFF) + 1)

        return value

    def monitor_callback(self):
        """Monitor battery and publish state"""
        try:
            # Read voltage (LSB = 1.25 mV)
            voltage_raw = self.read_ina260(REG_VOLTAGE)
            voltage = voltage_raw * 1.25 / 1000.0  # Convert to Volts

            # Read current (LSB = 1.25 mA)
            current_raw = self.read_ina260(REG_CURRENT)
            current = current_raw * 1.25 / 1000.0  # Convert to Amps

            # Read power (LSB = 10 mW)
            power_raw = self.read_ina260(REG_POWER)
            power = power_raw * 10 / 1000.0  # Convert to Watts

            # Coulomb counting for charge estimation
            current_time = time.time()
            dt = current_time - self.last_time
            self.total_charge += current * dt / 3600.0  # Convert to Ah
            self.last_time = current_time

            # Estimate state of charge (SOC)
            capacity = self.get_parameter('capacity_ah').value
            soc = max(0.0, min(1.0, 1.0 - (self.total_charge / capacity)))

            # Adjust SOC based on voltage (voltage-based estimation)
            v_min = self.get_parameter('voltage_min').value
            v_max = self.get_parameter('voltage_max').value
            voltage_soc = (voltage - v_min) / (v_max - v_min)
            voltage_soc = max(0.0, min(1.0, voltage_soc))

            # Blend coulomb counting and voltage estimation
            soc_blended = 0.7 * soc + 0.3 * voltage_soc

            # Create BatteryState message
            battery_msg = BatteryState()
            battery_msg.header.stamp = self.get_clock().now().to_msg()
            battery_msg.voltage = voltage
            battery_msg.current = -current  # Negative = discharging
            battery_msg.charge = soc_blended * capacity
            battery_msg.capacity = capacity
            battery_msg.design_capacity = capacity
            battery_msg.percentage = soc_blended
            battery_msg.power_supply_status = BatteryState.POWER_SUPPLY_STATUS_DISCHARGING
            battery_msg.power_supply_health = self.get_health_status(voltage)
            battery_msg.power_supply_technology = BatteryState.POWER_SUPPLY_TECHNOLOGY_LIPO
            battery_msg.present = True

            # Publish
            self.battery_pub.publish(battery_msg)

            # Publish power consumption
            power_msg = Float32()
            power_msg.data = power
            self.power_pub.publish(power_msg)

            # Log warnings
            if voltage < v_min + 0.5:
                self.get_logger().warn(
                    f'Low battery: {voltage:.2f}V ({soc_blended*100:.0f}%)'
                )

        except Exception as e:
            self.get_logger().error(f'Power monitoring error: {e}')

    def get_health_status(self, voltage):
        """Determine battery health based on voltage"""
        v_min = self.get_parameter('voltage_min').value
        v_max = self.get_parameter('voltage_max').value

        if voltage > v_max + 0.5:
            return BatteryState.POWER_SUPPLY_HEALTH_OVERVOLTAGE
        elif voltage < v_min:
            return BatteryState.POWER_SUPPLY_HEALTH_DEAD
        elif voltage < v_min + 1.0:
            return BatteryState.POWER_SUPPLY_HEALTH_COLD  # Repurposed as "low"
        else:
            return BatteryState.POWER_SUPPLY_HEALTH_GOOD

def main(args=None):
    rclpy.init(args=args)
    node = PowerMonitorNode()

    try:
        rclpy.spin(node)
    except KeyboardInterrupt:
        pass
    finally:
        node.destroy_node()
        rclpy.shutdown()

if __name__ == '__main__':
    main()

    🔋 Battery Charging¶

    Charging Specifications¶

    YAML
    Charger Type: Balance Charger (required for LiPo)
Recommended Model: SkyRC iMAX B6AC or similar

Charging Modes:
  Balance Charge:
    Current: 1-2C (5A for 5000mAh)
    Voltage: 4.2V per cell
    Duration: 2-3 hours

  Fast Charge:
    Current: 2C (10A for 5000mAh)
    Voltage: 4.2V per cell
    Duration: 45 minutes
    Warning: Reduces battery lifespan

  Storage Charge:
    Voltage: 3.85V per cell
    Current: 0.5-1C
    Use: For long-term storage (>2 weeks)

Safety Rules:
  - NEVER charge unattended
  - Use fireproof LiPo bag
  - Charge in open, ventilated area
  - Monitor temperature during charge
  - Stop if battery swells or gets hot (>40°C)

    Charging Procedure:

    Bash
    # 1. Inspect battery
# - Check for physical damage
# - Measure voltage (should be >9.0V)
# - Check for swelling

# 2. Connect balance lead

# 3. Connect main power
# - Plug XT60 into charger

# 4. Configure charger
# - Battery Type: LiPo
# - Cell Count: 3S
# - Charge Current: 5A (1C for 5000mAh)
# - Charge Mode: Balance

# 5. Start charging
# - Double-check settings
# - Monitor first 10 minutes
# - Check temperature periodically

# 6. Charging complete
# - Charger will beep when done
# - Verify voltage: 12.6V total
# - Disconnect balance lead first
# - Then disconnect main power

    🛡️ Safety Systems¶

    Hardware Protection¶

    Primary Protection:

    YAML
    Main Fuse:
  Rating: 30A automotive blade fuse
  Type: ATO/ATC fast-acting
  Location: Between battery and PDB
  Purpose: Catastrophic fault protection

Resettable Fuses (PTC):
  12V Rail: 20A (Polyfuse)
  5V Rail: 5A (Polyfuse)
  3.3V Rail: 2A (Polyfuse)
  Reset: Automatic after cooling

Voltage Regulators:
  Thermal Shutdown: 150°C junction
  Current Limiting: Foldback protection
  Overvoltage Lockout: 20V

Reverse Polarity Protection:
  Method: P-channel MOSFET
  Location: Battery input
  Voltage Drop: <100mV @ 20A

    Software Protection:

    Python
    #!/usr/bin/env python3
"""
Safety monitor - Automatic shutdown on critical conditions
"""

import rclpy
from rclpy.node import Node
from sensor_msgs.msg import BatteryState
from std_msgs.msg import Bool
import subprocess

class SafetyMonitorNode(Node):
    def __init__(self):
        super().__init__('safety_monitor_node')

        # Thresholds
        self.declare_parameter('voltage_critical', 9.0)
        self.declare_parameter('voltage_warning', 9.5)
        self.declare_parameter('temp_warning', 50.0)
        self.declare_parameter('temp_critical', 60.0)

        # Subscribers
        self.create_subscription(
            BatteryState,
            '/battery/state',
            self.battery_callback,
            10
        )

        # Publishers
        self.emergency_stop_pub = self.create_publisher(
            Bool,
            '/emergency_stop',
            10
        )

        # State
        self.warning_count = 0
        self.shutdown_initiated = False

        self.get_logger().info('Safety monitor node started')

    def battery_callback(self, msg):
        """Monitor battery and take action if needed"""
        voltage = msg.voltage
        v_critical = self.get_parameter('voltage_critical').value
        v_warning = self.get_parameter('voltage_warning').value

        # Critical voltage - immediate shutdown
        if voltage < v_critical and not self.shutdown_initiated:
            self.get_logger().error(
                f'CRITICAL: Battery voltage {voltage:.2f}V < {v_critical}V'
            )
            self.initiate_emergency_shutdown()

        # Warning voltage - alert user
        elif voltage < v_warning:
            self.warning_count += 1
            if self.warning_count % 10 == 0:  # Every second at 10Hz
                self.get_logger().warn(
                    f'WARNING: Low battery {voltage:.2f}V'
                )
                # Publish emergency stop signal
                stop_msg = Bool()
                stop_msg.data = True
                self.emergency_stop_pub.publish(stop_msg)

    def initiate_emergency_shutdown(self):
        """Emergency system shutdown"""
        self.shutdown_initiated = True

        self.get_logger().error('Initiating emergency shutdown!')

        # Stop all motors
        stop_msg = Bool()
        stop_msg.data = True
        self.emergency_stop_pub.publish(stop_msg)

        # Wait for motors to stop
        time.sleep(2)

        # Shutdown system
        subprocess.call(['sudo', 'shutdown', '-h', 'now'])

def main(args=None):
    rclpy.init(args=args)
    node = SafetyMonitorNode()

    try:
        rclpy.spin(node)
    except KeyboardInterrupt:
        pass
    finally:
        node.destroy_node()
        rclpy.shutdown()

if __name__ == '__main__':
    main()

    🔧 Maintenance¶

    Battery Care¶

    YAML
    Storage Guidelines:
  Short-term (<2 weeks):
    - Charge to 50-70%
    - Store at room temperature (20-25°C)
    - Check voltage monthly

  Long-term (>2 weeks):
    - Charge to storage voltage (3.85V/cell = 11.55V)
    - Store in cool, dry place (15-20°C)
    - Check voltage every 2-3 months
    - Recharge if below 11.0V

Operating Guidelines:
  - Never discharge below 3.0V/cell (9.0V total)
  - Avoid continuous high-current discharge (>20A)
  - Let battery cool before recharging
  - Monitor temperature during use
  - Balance charge every 10 cycles

Lifespan:
  Typical: 300-500 cycles
  Factors: Charge/discharge rate, temperature, storage
  Signs of aging: Reduced capacity, longer charge time, swelling
  Replacement: When capacity < 80% or physical damage

    Troubleshooting¶

    YAML
    Issue: Battery won't charge
  Check:
    - Charger settings (3S LiPo mode)
    - Balance lead connection
    - Fuse continuity
    - Cell voltages (should be similar)
  Solution:
    - Verify charger output voltage
    - Check for internal BMS fault
    - Replace if cells imbalanced (>0.3V difference)

Issue: Rapid discharge
  Check:
    - Power consumption (use power monitor)
    - Short circuits
    - BMS bypass
  Solution:
    - Identify high-current loads
    - Check wiring for shorts
    - Test with known-good battery

Issue: Battery swelling
  Action:
    - STOP using immediately
    - Discharge to 0V in safe location
    - Dispose at proper recycling facility
    - NEVER puncture or disassemble
