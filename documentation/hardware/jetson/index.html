    NVIDIA Jetson Orin Nano Super¶

    Complete technical documentation for the NVIDIA Jetson Orin Nano Super computing platform.

    🎯 Overview¶

    The NVIDIA Jetson Orin Nano Super is the heart of the Isaac ROS Jetbot NanoOWL platform, delivering unprecedented AI performance in a compact, energy-efficient package.

    Key Highlights: - 67 TOPS AI performance (INT8) - 8GB LPDDR5 high-speed memory - 128GB UFS 3.1 storage - 25W maximum power consumption - Full CUDA, cuDNN, and TensorRT support

    💻 Technical Specifications¶

    Compute Performance¶

    Component Specification Details
    CPU Arm Cortex-A78AE v8.2 64-bit 6 cores @ up to 1.7 GHz
    GPU NVIDIA Ampere 1024 CUDA cores, 32 Tensor cores, up to 1020 MHz
    CUDA Compute Capability 8.7 Build target sm_87
    AI Performance 67 TOPS INT8, sparse, MAXN SUPER mode
    Memory 8GB 128-bit LPDDR5 102 GB/s bandwidth
    Storage microSD + M.2 Key M NVMe Carrier board provides the SSD slot

    Figures follow the Jetson Orin Nano Super Developer Kit datasheet. Note that MAXN SUPER (67 TOPS, 1020 MHz GPU, 102 GB/s) requires JetPack 6.2 or newer; on JetPack 6.1 the same board runs at 40 TOPS / 68 GB/s.

    Power & Thermal¶

    Power Consumption:
  Idle: 5-8W
  Typical Load: 10-15W
  Maximum: 25W
  Power Mode: 7W, 15W, 25W selectable

Thermal Management:
  Operating Temperature: 0°C to 50°C
  Storage Temperature: -25°C to 85°C
  Cooling: Passive heatsink + active fan (optional)
  Thermal Throttling: Starts at 80°C

    Form Factor¶

    Dimensions:
  Module: 69.6mm x 45mm
  Developer Kit: 110mm x 100mm x 50mm
  Weight: 110g (module only)

Mounting:
  Carrier Board: SO-DIMM connector (260-pin)
  Thermal Interface: Pre-applied thermal pad
  Mounting Holes: M3 x 4 (compatible with 96Boards CE)

    🔌 Hardware Interfaces¶

    I/O Capabilities¶

    Display:
  - 2x DisplayPort 1.4 (4K @ 60Hz each)
  - HDMI 2.0 (4K @ 60Hz)

Camera:
  - 2x MIPI CSI-2 (4-lane, 2.5 Gbps/lane)
  - USB 3.2 Gen 2 (for USB cameras)
  - Supports up to 6 cameras total

USB:
  - 4x USB 3.2 Gen 2 (10 Gbps)
  - 1x USB 2.0 Micro-B (device mode)

Networking:
  - Gigabit Ethernet (RJ45)
  - M.2 Key E (for WiFi/BT module)

Storage:
  - M.2 Key M (NVMe SSD, PCIe Gen3 x4)
  - microSD card slot (UHS-I)

GPIO:
  - 40-pin expansion header
  - UART, SPI, I2C, I2S, GPIO
  - PWM outputs (4 channels)

Other:
  - JTAG debug port
  - CAN bus (via expansion)
  - Fan control (PWM)

    🚀 Performance Benchmarks¶

    AI Inference Performance¶

    Model Precision Batch Size FPS Latency
    YOLOv8n FP16 1 45 22ms
    YOLOv8n INT8 1 60 17ms
    YOLOv8s FP16 1 35 29ms
    ResNet-50 FP16 1 120 8ms
    MobileNetV2 INT8 1 250 4ms

    Memory Bandwidth¶

    LPDDR5 Performance:
  Theoretical Maximum: 102 GB/s
  Measured Read: 88 GB/s
  Measured Write: 76 GB/s
  Latency: ~90ns

GPU Memory Sharing:
  Unified Memory Architecture (UMA)
  Zero-copy between CPU and GPU
  Automatic memory management

    Storage Performance¶

    UFS 3.1 (eMMC):
  Sequential Read: 2100 MB/s
  Sequential Write: 1200 MB/s
  Random Read (4K): 45,000 IOPS
  Random Write (4K): 38,000 IOPS

NVMe SSD (optional):
  Sequential Read: 3500 MB/s
  Sequential Write: 3000 MB/s
  Interface: PCIe Gen3 x4

    ⚙️ Software Support¶

    Operating Systems¶

    Official Support:
  - Ubuntu 22.04 LTS (ARM64)
  - JetPack SDK 6.2+ (required for MAXN SUPER)
  - Jetson Linux (L4T) 36.4.3+
  - Linux Kernel 5.15+

Alternative Distributions:
  - Custom Yocto builds (unvalidated)

    Development Tools¶

    NVIDIA SDKs:
  - CUDA Toolkit 12.6+ (JetPack 6.2)
  - cuDNN 9.3+
  - TensorRT 10.3+
  - DeepStream 7.0+
  - VPI (Vision Programming Interface) 3.0+

Deep Learning Frameworks:
  - PyTorch 2.1+ (with CUDA support)
  - TensorFlow 2.14+
  - ONNX Runtime 1.16+
  - OpenCV 4.8+ (with CUDA)

ROS Support:
  - ROS2 Humble (the project's target distribution)

    🔧 Setup & Configuration¶

    Initial Setup¶

    # 1. Download JetPack SDK
# Visit: https://developer.nvidia.com/jetpack

# 2. Flash OS to Jetson
sudo ./sdkmanager --cli install \
  --logintype devzone \
  --product Jetson \
  --version 6.0 \
  --targethw JETSON_ORIN_NANO_TARGETS \
  --host \
  --target JETSON_ORIN_NANO_TARGETS \
  --flash all

# 3. Boot and initial configuration
# Connect display, keyboard, mouse
# Follow on-screen setup wizard

# 4. Update system
sudo apt update && sudo apt upgrade -y

# 5. Install NVIDIA container toolkit
distribution=$(. /etc/os-release;echo $ID$VERSION_ID)
curl -s -L https://nvidia.github.io/nvidia-docker/gpgkey | sudo apt-key add -
curl -s -L https://nvidia.github.io/nvidia-docker/$distribution/nvidia-docker.list | \
  sudo tee /etc/apt/sources.list.d/nvidia-docker.list

sudo apt update
sudo apt install -y nvidia-container-toolkit

    Power Mode Configuration¶

    # View available power modes
sudo nvpmodel -q

# Mode IDs on Jetson Orin Nano Super 8GB with JetPack 6.2:
#   0 = 15W, 1 = 7W, 2 = MAXN SUPER (25W)
# Always confirm with `nvpmodel -q` -- IDs differ between boards and releases.
sudo nvpmodel -m 2  # MAXN SUPER, maximum performance (25W)
sudo nvpmodel -m 0  # Balanced (15W)
sudo nvpmodel -m 1  # Power saving (7W)

# Enable jetson_clocks for maximum performance
sudo jetson_clocks --show
sudo jetson_clocks

    Fan Control¶

    # Check fan status
cat /sys/devices/pwm-fan/cur_pwm

# Set fan speed (0-255)
echo 128 | sudo tee /sys/devices/pwm-fan/target_pwm

# Automatic fan control (via jetson-stats)
sudo pip3 install jetson-stats
sudo jtop  # Interactive monitoring tool

    📊 Monitoring & Diagnostics¶

    System Monitoring Tools¶

    # Install jetson-stats
sudo pip3 install jetson-stats
sudo systemctl restart jtop.service

# Launch interactive dashboard
sudo jtop

# Tegrastats (built-in monitoring)
tegrastats --interval 1000  # 1 second intervals

# NVIDIA System Management Interface
nvidia-smi

# Check GPU utilization
watch -n 1 nvidia-smi

    Key Metrics to Monitor¶

    Temperature:
  - CPU: thermal_zone0
  - GPU: thermal_zone1
  - Thermal Throttling: > 80°C
  - Critical: > 95°C

Power:
  - Current Draw: VDD_IN
  - GPU Power: VDD_GPU_SOC
  - CPU Power: VDD_CPU_CV
  - Total System: Sum of all rails

Memory:
  - RAM Usage: free -h
  - GPU Memory: nvidia-smi
  - Swap Usage: swapon --show

Frequency:
  - CPU: /sys/devices/system/cpu/cpu*/cpufreq/scaling_cur_freq
  - GPU: /sys/devices/gpu.0/devfreq/*/cur_freq
  - EMC (memory): /sys/kernel/debug/bpmp/debug/clk/emc/rate

    🔒 Security Features¶

    Hardware Security¶

    Secure Boot:
  - UEFI Secure Boot support
  - Boot ROM verification
  - Trusted Execution Environment (TEE)

Encryption:
  - AES-256 hardware acceleration
  - Secure key storage
  - Encrypted storage support

Isolation:
  - ARM TrustZone technology
  - Hypervisor support (KVM)
  - Secure firmware updates

    Software Security¶

    # Enable automatic security updates
sudo apt install unattended-upgrades
sudo dpkg-reconfigure --priority=low unattended-upgrades

# Configure firewall
sudo ufw enable
sudo ufw allow ssh
sudo ufw allow from 192.168.1.0/24  # Local network only

# Disable unused services
sudo systemctl disable bluetooth
sudo systemctl disable avahi-daemon

# Set up fail2ban
sudo apt install fail2ban
sudo systemctl enable fail2ban

    ⚡ Performance Optimization¶

    GPU Optimization¶

    # Enable maximum GPU clock
sudo jetson_clocks --fan

# Persistent mode (for servers)
sudo nvidia-smi -pm 1

# Set GPU frequency
# View available frequencies
cat /sys/devices/gpu.0/devfreq/*/available_frequencies

# Set to maximum
echo $(cat /sys/devices/gpu.0/devfreq/*/max_freq) | \
  sudo tee /sys/devices/gpu.0/devfreq/*/userspace/set_freq

    Memory Optimization¶

    # Increase swap size (for large models)
sudo systemctl disable nvzramconfig
sudo fallocate -l 8G /swapfile
sudo chmod 600 /swapfile
sudo mkswap /swapfile
sudo swapon /swapfile
echo '/swapfile none swap sw 0 0' | sudo tee -a /etc/fstab

# Disable zram (for consistent performance)
sudo systemctl disable nvzramconfig.service

# Adjust swappiness
echo 'vm.swappiness=10' | sudo tee -a /etc/sysctl.conf
sudo sysctl -p

    Storage Optimization¶

    # Install on NVMe SSD (recommended)
# 1. Clone rootfs to NVMe
git clone https://github.com/jetsonhacks/rootOnNVMe.git
cd rootOnNVMe
./copy-rootfs-ssd.sh
./setup-service.sh

# 2. Reboot and verify
df -h

# Optimize ext4 filesystem
sudo tune2fs -O ^has_journal /dev/nvme0n1p1  # Disable journaling (optional)
sudo tune2fs -o discard /dev/nvme0n1p1      # Enable TRIM

    🛠️ Troubleshooting¶

    Common Issues¶

    Boot Failures¶

    # Issue: Jetson won't boot
# Solution: Force recovery mode
1. Power off Jetson
2. Hold FORCE RECOVERY button
3. Press POWER button
4. Release both after 2 seconds
5. Reflash with SDK Manager

# Check boot logs
dmesg | grep -i error
journalctl -xe

    Overheating¶

    # Issue: Thermal throttling
# Check temperature
cat /sys/devices/virtual/thermal/thermal_zone*/temp

# Solutions:
1. Clean heatsink and fan
2. Apply new thermal paste
3. Reduce power mode: sudo nvpmodel -m 1   # 7W
4. Improve airflow/cooling
5. Add active cooling fan

    GPU Not Detected¶

    # Issue: CUDA/TensorRT errors
# Verify GPU status
nvidia-smi

# If not found, reinstall CUDA
sudo apt purge 'cuda-*'
sudo apt purge 'nvidia-*'
sudo apt autoremove
sudo reboot

# Reinstall JetPack
sudo apt update
sudo apt install nvidia-jetpack

    Slow Performance¶

    # Issue: Lower than expected performance
# Check current power mode
sudo nvpmodel -q

# Enable maximum performance (MAXN SUPER is ID 2 on this board)
sudo nvpmodel -m 2
sudo jetson_clocks

# Verify GPU frequency
cat /sys/devices/gpu.0/devfreq/*/cur_freq
cat /sys/devices/gpu.0/devfreq/*/max_freq

# Check for thermal throttling
tegrastats
