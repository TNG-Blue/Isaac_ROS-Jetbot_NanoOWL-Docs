    NVIDIA Jetson Orin Nano Super¶

    Complete technical documentation for the NVIDIA Jetson Orin Nano Super computing platform.

    🎯 Overview¶

    The NVIDIA Jetson Orin Nano Super is the heart of the Isaac ROS Jetbot NanoOWL platform, delivering unprecedented AI performance in a compact, energy-efficient package.

    Key Highlights: - 67 TOPS AI performance (INT8) - 8GB LPDDR5 high-speed memory - 128GB UFS 3.1 storage - 25W maximum power consumption - Full CUDA, cuDNN, and TensorRT support

    💻 Technical Specifications¶

    Compute Performance¶

    Component Specification Details
    CPU ARM Cortex-A78AE 8 cores @ 2.0 GHz
    GPU NVIDIA Ampere 1024 CUDA cores, 32 Tensor cores
    AI Performance 67 TOPS INT8 precision
    Memory 8GB LPDDR5 102 GB/s bandwidth
    Storage 128GB UFS 3.1 Sequential read: 2100 MB/s

    Power & Thermal¶

    YAML
    Power Consumption:
  Idle: 5-8W
  Typical Load: 10-15W
  Maximum: 25W
  Power Mode: 7W, 15W, 25W selectable

Thermal Management:
  Operating Temperature: 0°C to 50°C
  Storage Temperature: -25°C to 85°C
  Cooling: Passive heatsink + active fan (optional)
  Thermal Throttling: Starts at 80°C

    Form Factor¶

    YAML
    Dimensions:
  Module: 69.6mm x 45mm
  Developer Kit: 110mm x 100mm x 50mm
  Weight: 110g (module only)

Mounting:
  Carrier Board: SO-DIMM connector (260-pin)
  Thermal Interface: Pre-applied thermal pad
  Mounting Holes: M3 x 4 (compatible with 96Boards CE)

    🔧 Setup & Configuration¶

    Initial Setup¶

    Bash
    # 1. Download JetPack SDK
# Visit: https://developer.nvidia.com/jetpack

# 2. Flash OS to Jetson
sudo ./sdkmanager --cli install \
  --logintype devzone \
  --product Jetson \
  --version 6.0 \
  --targethw JETSON_ORIN_NANO_TARGETS \
  --host \
  --target JETSON_ORIN_NANO_TARGETS \
  --flash all

# 3. Boot and initial configuration
# Connect display, keyboard, mouse
# Follow on-screen setup wizard

# 4. Update system
sudo apt update && sudo apt upgrade -y

# 5. Install NVIDIA container toolkit
distribution=$(. /etc/os-release;echo $ID$VERSION_ID)
curl -s -L https://nvidia.github.io/nvidia-docker/gpgkey | sudo apt-key add -
curl -s -L https://nvidia.github.io/nvidia-docker/$distribution/nvidia-docker.list | \
  sudo tee /etc/apt/sources.list.d/nvidia-docker.list

sudo apt update
sudo apt install -y nvidia-container-toolkit

    Power Mode Configuration¶

    Bash
    # View available power modes
sudo nvpmodel -q

# Set power mode (0 = MAXN, 1 = 15W, 2 = 7W)
sudo nvpmodel -m 0  # Maximum performance (25W)
sudo nvpmodel -m 1  # Balanced (15W)
sudo nvpmodel -m 2  # Power saving (7W)

# Enable jetson_clocks for maximum performance
sudo jetson_clocks --show
sudo jetson_clocks

    Fan Control¶

    Bash
    # Check fan status
cat /sys/devices/pwm-fan/cur_pwm

# Set fan speed (0-255)
echo 128 | sudo tee /sys/devices/pwm-fan/target_pwm

# Automatic fan control (via jetson-stats)
sudo pip3 install jetson-stats
sudo jtop  # Interactive monitoring tool

    System Monitoring Tools¶

    Bash
    # Install jetson-stats
sudo pip3 install jetson-stats
sudo systemctl restart jtop.service

# Launch interactive dashboard
sudo jtop

# Tegrastats (built-in monitoring)
tegrastats --interval 1000  # 1 second intervals

# NVIDIA System Management Interface
nvidia-smi

# Check GPU utilization
watch -n 1 nvidia-smi

  - CPU Power: VDD_CPU_CV

  - RAM Usage: free -h
  - GPU Memory: nvidia-smi

  - CPU: /sys/devices/system/cpu/cpu*/cpufreq/scaling_cur_freq
  - GPU: /sys/devices/gpu.0/devfreq/*/cur_freq
  - EMC (memory): /sys/kernel/debug/bpmp/debug/clk/emc/rate

    ⚡ Performance Optimization¶

    GPU Optimization¶

    Bash
    # Enable maximum GPU clock
sudo jetson_clocks --fan

# Persistent mode (for servers)
sudo nvidia-smi -pm 1

# Set GPU frequency
# View available frequencies
cat /sys/devices/gpu.0/devfreq/*/available_frequencies

# Set to maximum
echo $(cat /sys/devices/gpu.0/devfreq/*/max_freq) | \
  sudo tee /sys/devices/gpu.0/devfreq/*/userspace/set_freq

    Memory Optimization¶

    Bash
    # Increase swap size (for large models)
sudo systemctl disable nvzramconfig
sudo fallocate -l 8G /swapfile
sudo chmod 600 /swapfile
sudo mkswap /swapfile
sudo swapon /swapfile
echo '/swapfile none swap sw 0 0' | sudo tee -a /etc/fstab

# Disable zram (for consistent performance)
sudo systemctl disable nvzramconfig.service

# Adjust swappiness
echo 'vm.swappiness=10' | sudo tee -a /etc/sysctl.conf
sudo sysctl -p

    Storage Optimization¶

    Bash
    # Install on NVMe SSD (recommended)
# 1. Clone rootfs to NVMe
git clone https://github.com/jetsonhacks/rootOnNVMe.git
cd rootOnNVMe
./copy-rootfs-ssd.sh
./setup-service.sh

# 2. Reboot and verify
df -h

# Optimize ext4 filesystem
sudo tune2fs -O ^has_journal /dev/nvme0n1p1  # Disable journaling (optional)
sudo tune2fs -o discard /dev/nvme0n1p1      # Enable TRIM

    🛠️ Troubleshooting¶

    Common Issues¶

    Boot Failures¶

    Bash
    # Issue: Jetson won't boot
# Solution: Force recovery mode
1. Power off Jetson
2. Hold FORCE RECOVERY button
3. Press POWER button
4. Release both after 2 seconds
5. Reflash with SDK Manager

# Check boot logs
dmesg | grep -i error
journalctl -xe

    Overheating¶

    Bash
    # Issue: Thermal throttling
# Check temperature
cat /sys/devices/virtual/thermal/thermal_zone*/temp

# Solutions:
1. Clean heatsink and fan
2. Apply new thermal paste
3. Reduce power mode: sudo nvpmodel -m 1
4. Improve airflow/cooling
5. Add active cooling fan

    GPU Not Detected¶

    Bash
    # Issue: CUDA/TensorRT errors
# Verify GPU status
nvidia-smi

# If not found, reinstall CUDA
sudo apt purge 'cuda-*'
sudo apt purge 'nvidia-*'
sudo apt autoremove
sudo reboot

# Reinstall JetPack
sudo apt update
sudo apt install nvidia-jetpack

    Slow Performance¶

    Bash
    # Issue: Lower than expected performance
# Check current power mode
sudo nvpmodel -q

# Enable maximum performance
sudo nvpmodel -m 0
sudo jetson_clocks

# Verify GPU frequency
cat /sys/devices/gpu.0/devfreq/*/cur_freq
cat /sys/devices/gpu.0/devfreq/*/max_freq

# Check for thermal throttling
tegrastats
