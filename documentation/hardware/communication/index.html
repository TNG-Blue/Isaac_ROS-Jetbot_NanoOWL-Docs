    Communication Systems¶

    Comprehensive guide to communication interfaces and protocols used in Isaac ROS Jetbot NanoOWL.

    🌐 Overview¶

    The platform supports multiple communication layers for different use cases:

    Protocol Use Case Range Bandwidth Latency
    Ethernet High-bandwidth data 100m 1 Gbps <1ms
    WiFi Wireless control 50-100m 300 Mbps 5-20ms
    LoRa Long-range telemetry 2-15km 50 kbps 100ms+
    I2C Sensor communication 5m 400 kHz <1ms
    UART/Serial GPS, peripherals 15m 115.2 kbps <1ms
    USB LIDAR, cameras 5m 480 Mbps <10ms

    Network Configuration¶

    Master Node (Jetson Orin Nano)¶

    YAML
    # /etc/netplan/01-network-config.yaml
network:
  version: 2
  ethernets:
    eth0:
      dhcp4: no
      addresses:
        - 192.168.1.100/24
      gateway4: 192.168.1.1
      nameservers:
        addresses: [8.8.8.8, 8.8.4.4]

    Apply configuration:

    Bash
    sudo netplan apply

    Worker Nodes¶

    Similar configuration with different IPs: - Worker 1: 192.168.1.101/24 - Worker 2: 192.168.1.102/24

    ROS2 over Ethernet¶

    ROS2 uses DDS (Data Distribution Service) for communication:

    Bash
    # Set network interface
export ROS_DOMAIN_ID=0
export RMW_IMPLEMENTATION=rmw_cyclonedds_cpp

# CycloneDDS configuration
export CYCLONEDDS_URI=file://$HOME/cyclonedds.xml

    cyclonedds.xml:

    XML
    <?xml version="1.0" encoding="UTF-8" ?>
<CycloneDDS xmlns="https://cdds.io/config">
  <Domain>
    <General>
      <NetworkInterfaceAddress>eth0</NetworkInterfaceAddress>
      <MaxMessageSize>65500B</MaxMessageSize>
    </General>
  </Domain>
</CycloneDDS>

    📻 LoRa Long-Range Communication¶

    LoRa Module Setup¶

    Hardware: Adafruit RFM95W LoRa Radio (915 MHz)

    Bash
    # Install LoRa library
pip3 install adafruit-circuitpython-rfm9x

# Enable SPI
sudo raspi-config
# Interface Options → SPI → Enable

    Wiring¶

    Text Only
    Jetson GPIO → RFM95W
Pin 19 (MOSI) → MOSI
Pin 21 (MISO) → MISO
Pin 23 (SCLK) → SCK
Pin 24 (CE0)  → CS
Pin 18 (GPIO24) → RST
Pin 22 (GPIO25) → G0 (IRQ)
Pin 1 (3.3V)  → VIN
Pin 6 (GND)   → GND

    LoRa Communication Node¶

    Python
    #!/usr/bin/env python3
import rclpy
from rclpy.node import Node
import board
import busio
import digitalio
from adafruit_rfm9x import RFM9x

class LoRaNode(Node):
    def __init__(self):
        super().__init__('lora_node')

        # Configure LoRa
        spi = busio.SPI(board.SCK, MOSI=board.MOSI, MISO=board.MISO)
        cs = digitalio.DigitalInOut(board.CE0)
        reset = digitalio.DigitalInOut(board.D24)

        self.rfm9x = RFM9x(spi, cs, reset, 915.0)
        self.rfm9x.tx_power = 23  # Max power

        # Subscribe to telemetry
        self.subscription = self.create_subscription(
            String,
            '/telemetry',
            self.telemetry_callback,
            10
        )

    def telemetry_callback(self, msg):
        # Send via LoRa
        self.rfm9x.send(bytes(msg.data, 'utf-8'))
        self.get_logger().info(f'Sent: {msg.data}')

    LoRa Image Transfer¶

    For low-bandwidth image transfer:

    Python
    # Compress and transmit image
def transmit_image(image_data):
    # Compress image
    import cv2
    _, buffer = cv2.imencode('.jpg', image_data, [cv2.IMWRITE_JPEG_QUALITY, 20])
    compressed = buffer.tobytes()

    # Split into chunks (256 bytes max per LoRa packet)
    chunk_size = 256
    chunks = [compressed[i:i+chunk_size] for i in range(0, len(compressed), chunk_size)]

    # Transmit with acknowledgment
    for i, chunk in enumerate(chunks):
        packet = f"{i}/{len(chunks)}:".encode() + chunk
        rfm9x.send(packet)
        time.sleep(0.5)  # Wait for transmission

    🔗 I2C Communication¶

    I2C Bus Configuration¶

    Bash
    # Enable I2C
sudo usermod -aG i2c $USER

# Scan I2C bus
i2cdetect -y -r 1

    Common I2C Devices¶

    Device Address Purpose
    MPU6050 IMU 0x68 Motion sensing
    MPU9250 IMU 0x68 9-axis IMU
    PCA9685 0x40 16-ch PWM servo driver
    ADS1015 0x48 4-ch 12-bit ADC
    INA219 0x40 Power monitor

    I2C Communication Example¶

    Python
    import smbus2

class I2CDevice:
    def __init__(self, bus=1, address=0x68):
        self.bus = smbus2.SMBus(bus)
        self.address = address

    def read_byte(self, register):
        return self.bus.read_byte_data(self.address, register)

    def write_byte(self, register, value):
        self.bus.write_byte_data(self.address, register, value)

    def read_block(self, register, length):
        return self.bus.read_i2c_block_data(self.address, register, length)

    🔌 UART/Serial Communication¶

    GPS Module (UART)¶

    Python
    import serial
import pynmea2

class GPSNode(Node):
    def __init__(self):
        super().__init__('gps_node')

        # Open serial port
        self.ser = serial.Serial('/dev/ttyTHS0', 9600, timeout=1)

        # Publisher
        self.pub = self.create_publisher(NavSatFix, '/gps/fix', 10)

        # Timer for reading
        self.timer = self.create_timer(0.1, self.read_gps)

    def read_gps(self):
        line = self.ser.readline().decode('ascii', errors='replace')

        if line.startswith('$GPGGA'):
            msg = pynmea2.parse(line)

            # Publish NavSatFix
            fix = NavSatFix()
            fix.latitude = msg.latitude
            fix.longitude = msg.longitude
            fix.altitude = msg.altitude
            self.pub.publish(fix)

    📶 USB Communication¶

    USB Device Priorities¶

lsusb

    USB Configuration¶

    Prioritize devices on USB 3.0 ports: - USB 3.0: LIDAR, cameras (high bandwidth) - USB 2.0: GPS, peripherals (low bandwidth)

    USB Permissions¶

    Bash
    # Create udev rule for LIDAR
sudo nano /etc/udev/rules.d/99-lidar.rules
    Text Only
    KERNEL=="ttyUSB*", ATTRS{idVendor}=="10c4", ATTRS{idProduct}=="ea60", MODE="0666", GROUP="dialout", SYMLINK+="rplidar"
    Bash
    # Reload rules
sudo udevadm control --reload-rules
sudo udevadm trigger

    Quality of Service (QoS)¶

    Python
    from rclpy.qos import QoSProfile, ReliabilityPolicy, HistoryPolicy

# Sensor data (best effort)
sensor_qos = QoSProfile(
    reliability=ReliabilityPolicy.BEST_EFFORT,
    history=HistoryPolicy.KEEP_LAST,
    depth=10
)

# Control commands (reliable)
control_qos = QoSProfile(
    reliability=ReliabilityPolicy.RELIABLE,
    history=HistoryPolicy.KEEP_ALL,
    depth=10
)

# Use in publisher/subscriber
self.pub = self.create_publisher(Image, '/camera/image_raw', sensor_qos)
self.sub = self.create_subscription(Twist, '/cmd_vel', self.callback, control_qos)

    🎯 Best Practices¶

    1. Use Ethernet for critical data (control, high-res video)
    2. Use WiFi for monitoring (telemetry, low-res preview)
    3. Use LoRa for emergency backup (status, GPS)
    4. Separate I2C buses for critical sensors
    5. Use USB 3.0 for bandwidth-intensive devices
    6. Configure QoS appropriately for each topic
    7. Monitor latency and bandwidth regularly
    8. Implement timeout and retry logic
