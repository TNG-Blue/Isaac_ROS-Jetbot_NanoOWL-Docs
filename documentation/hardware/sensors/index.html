    Sensor Integration¶

    Complete sensor suite documentation including cameras, LIDAR, IMU, GPS, and thermal sensors.

    🎯 Sensor Overview¶

    The Isaac ROS Jetbot NanoOWL platform integrates a comprehensive sensor array for robust perception and navigation in diverse environments.

    Sensor Categories: - 📷 Vision Sensors: RGB cameras, stereo vision, thermal imaging - 📡 Range Sensors: LIDAR, ultrasonic, Time-of-Flight (ToF) - 📍 Motion Sensors: IMU (accelerometer + gyroscope), magnetometer - 🛰️ Position Sensors: GPS/GNSS, wheel encoders - 🌡️ Environmental: Temperature, pressure, humidity

    📷 Vision Sensors¶

    Ultrasonic Sensors (HC-SR04)¶

    Specifications:

    YAML
    Model: HC-SR04 (set of 4-8 sensors)
Range: 2cm - 400cm
Accuracy: ±3mm
Beam Angle: 15°
Frequency: 40 kHz
Measurement Cycle: 60ms minimum

Interface: GPIO (Trigger + Echo pins)
Power: 5V / 15mA
Response Time: <1ms

    Wiring (per sensor):

    Text Only
    HC-SR04 → Jetson Orin Nano
───────────────────────────
VCC     → Pin 2 (5V)
TRIG    → GPIO pin (e.g., Pin 11)
ECHO    → GPIO pin (e.g., Pin 13) + voltage divider
GND     → Pin 6 (GND)

⚠️ IMPORTANT: Echo pin outputs 5V, but Jetson GPIO is 3.3V tolerant
Use voltage divider: 1kΩ and 2kΩ resistors

    Driver Code:

    Python
    #!/usr/bin/env python3
import rclpy
from rclpy.node import Node
from sensor_msgs.msg import Range
import RPi.GPIO as GPIO
import time

class UltrasonicNode(Node):
    def __init__(self):
        super().__init__('ultrasonic_node')

        self.declare_parameter('trigger_pin', 11)
        self.declare_parameter('echo_pin', 13)
        self.declare_parameter('frame_id', 'ultrasonic_link')
        self.declare_parameter('rate', 10.0)  # Hz

        self.trigger = self.get_parameter('trigger_pin').value
        self.echo = self.get_parameter('echo_pin').value
        self.frame_id = self.get_parameter('frame_id').value

        GPIO.setmode(GPIO.BOARD)
        GPIO.setup(self.trigger, GPIO.OUT)
        GPIO.setup(self.echo, GPIO.IN)
        GPIO.output(self.trigger, False)

        self.publisher = self.create_publisher(Range, 'ultrasonic/range', 10)

        rate = self.get_parameter('rate').value
        self.timer = self.create_timer(1.0 / rate, self.measure_distance)

        self.get_logger().info('Ultrasonic sensor node started')

    def measure_distance(self):
        # Send trigger pulse
        GPIO.output(self.trigger, True)
        time.sleep(0.00001)  # 10μs pulse
        GPIO.output(self.trigger, False)

        # Wait for echo
        timeout = time.time() + 0.1  # 100ms timeout
        while GPIO.input(self.echo) == 0:
            pulse_start = time.time()
            if pulse_start > timeout:
                self.get_logger().warn('Ultrasonic timeout (no echo start)')
                return

        while GPIO.input(self.echo) == 1:
            pulse_end = time.time()
            if pulse_end > timeout:
                self.get_logger().warn('Ultrasonic timeout (no echo end)')
                return

        # Calculate distance
        pulse_duration = pulse_end - pulse_start
        distance = pulse_duration * 17150  # Speed of sound / 2
        distance = distance / 100  # Convert to meters

        # Publish Range message
        msg = Range()
        msg.header.stamp = self.get_clock().now().to_msg()
        msg.header.frame_id = self.frame_id
        msg.radiation_type = Range.ULTRASOUND
        msg.field_of_view = 0.26  # 15° in radians
        msg.min_range = 0.02
        msg.max_range = 4.0
        msg.range = distance

        self.publisher.publish(msg)

def main(args=None):
    rclpy.init(args=args)
    node = UltrasonicNode()
    try:
        rclpy.spin(node)
    except KeyboardInterrupt:
        pass
    finally:
        GPIO.cleanup()
        node.destroy_node()
        rclpy.shutdown()

if __name__ == '__main__':
    main()

    Magnetometer / Compass (HMC5883L)¶

    Specifications:

    YAML
    Model: Honeywell HMC5883L
Range: ±1.3 to ±8.1 Gauss (selectable)
Resolution: 1° to 2°
Accuracy: 1-2° heading accuracy
Sample Rate: Up to 160 Hz

Interface: I2C
I2C Address: 0x1E
Power: 3.3V / 100μA (active)

    Calibration (Critical for Accuracy):

    Python
    #!/usr/bin/env python3
# Magnetometer calibration script
import smbus2
import time
import numpy as np

bus = smbus2.SMBus(1)
MAG_ADDR = 0x1E

# Initialize magnetometer
bus.write_byte_data(MAG_ADDR, 0x00, 0x70)  # 8-average, 15 Hz
bus.write_byte_data(MAG_ADDR, 0x01, 0xA0)  # Gain = 5
bus.write_byte_data(MAG_ADDR, 0x02, 0x00)  # Continuous mode

print("Rotate magnetometer in all directions for 30 seconds...")
print("Make figure-8 patterns in 3D space")

samples = []
start_time = time.time()

while time.time() - start_time < 30:
    # Read raw data
    data = bus.read_i2c_block_data(MAG_ADDR, 0x03, 6)
    x = np.int16((data[0] << 8) | data[1])
    y = np.int16((data[4] << 8) | data[5])
    z = np.int16((data[2] << 8) | data[3])

    samples.append([x, y, z])
    time.sleep(0.01)

samples = np.array(samples)

# Calculate hard-iron offset (center of sphere)
offset = np.mean(samples, axis=0)

# Calculate soft-iron scale (ellipsoid to sphere)
centered = samples - offset
scale = np.std(centered, axis=0)
scale = scale / np.min(scale)

print(f"\nCalibration Results:")
print(f"Offset: {offset}")
print(f"Scale: {scale}")
print(f"\nAdd to imu_params.yaml:")
print(f"mag_offset: [{offset[0]:.1f}, {offset[1]:.1f}, {offset[2]:.1f}]")
print(f"mag_scale: [{scale[0]:.3f}, {scale[1]:.3f}, {scale[2]:.3f}]")

    #!/usr/bin/env python3
import rclpy
from rclpy.node import Node
from sensor_msgs.msg import Imu, NavSatFix
from geometry_msgs.msg import PoseWithCovarianceStamped
from nav_msgs.msg import Odometry
import numpy as np
from filterpy.kalman import ExtendedKalmanFilter

class SensorFusionNode(Node):
    def __init__(self):
        super().__init__('sensor_fusion_node')

        # Initialize EKF
        self.ekf = ExtendedKalmanFilter(dim_x=9, dim_z=6)
        # State: [x, y, z, vx, vy, vz, roll, pitch, yaw]

        # Subscribers
        self.create_subscription(Imu, '/imu/data', self.imu_callback, 10)
        self.create_subscription(NavSatFix, '/gps/fix', self.gps_callback, 10)
        self.create_subscription(Odometry, '/odom', self.odom_callback, 10)

        # Publisher
        self.pose_pub = self.create_publisher(
            PoseWithCovarianceStamped,
            '/fused_pose',
            10
        )

        # Timer for prediction step
        self.create_timer(0.01, self.prediction_step)  # 100 Hz

        self.get_logger().info('Sensor fusion node started')

    def prediction_step(self):
        # EKF prediction using motion model
        dt = 0.01
        self.ekf.predict(dt=dt)

        # Publish fused pose
        msg = PoseWithCovarianceStamped()
        msg.header.stamp = self.get_clock().now().to_msg()
        msg.header.frame_id = 'map'

        # Extract state estimate
        x, y, z = self.ekf.x[0:3]
        roll, pitch, yaw = self.ekf.x[6:9]

        # Fill pose
        msg.pose.pose.position.x = x
        msg.pose.pose.position.y = y
        msg.pose.pose.position.z = z

        # Convert RPY to quaternion
        from tf_transformations import quaternion_from_euler
        q = quaternion_from_euler(roll, pitch, yaw)
        msg.pose.pose.orientation.x = q[0]
        msg.pose.pose.orientation.y = q[1]
        msg.pose.pose.orientation.z = q[2]
        msg.pose.pose.orientation.w = q[3]

        # Fill covariance
        P = self.ekf.P
        msg.pose.covariance[0] = P[0, 0]   # x
        msg.pose.covariance[7] = P[1, 1]   # y
        msg.pose.covariance[14] = P[2, 2]  # z
        msg.pose.covariance[21] = P[6, 6]  # roll
        msg.pose.covariance[28] = P[7, 7]  # pitch
        msg.pose.covariance[35] = P[8, 8]  # yaw

        self.pose_pub.publish(msg)

    def imu_callback(self, msg):
        # EKF update with IMU data (acceleration & angular velocity)
        # Measurement: [ax, ay, az, wx, wy, wz]
        z = np.array([
            msg.linear_acceleration.x,
            msg.linear_acceleration.y,
            msg.linear_acceleration.z,
            msg.angular_velocity.x,
            msg.angular_velocity.y,
            msg.angular_velocity.z
        ])

        self.ekf.update(z, self.imu_measurement_model)

            msg.twist.twist.linear.y,

        # Convert GPS lat/lon to local XY
        # (Simplified; use proper projection in production)
        return lat * 111000, lon * 111000 * np.cos(np.radians(lat))

    📊 Sensor Placement Guidelines¶

    Optimal Mounting Positions¶

    YAML
    Camera:
  Position: Front center, 30cm from ground
  Orientation: 0° tilt (parallel to ground)
  Field of View: Unobstructed, 180° horizontal

Stereo Cameras:
  Baseline: 60mm (for 0.5m-5m depth range)
  Synchronization: Hardware-triggered (< 1ms)
  Alignment: Parallel, same height

LIDAR:
  Position: Top center of robot
  Height: 25cm from ground (for obstacle detection)
  Orientation: Scan plane parallel to ground
  Clearance: 360° unobstructed view

IMU:
  Position: Center of mass (CoM)
  Orientation: Aligned with robot frame
  Mounting: Rigid, vibration-damped

GPS:
  Position: Top surface, clear sky view
  Antenna: Upward-facing, no metallic obstruction
  Ground Plane: Recommended for better reception

Thermal Camera:
  Position: Co-located with RGB camera
  Orientation: Same as RGB (for fusion)
  Field of View: Should overlap RGB camera

    🔧 Calibration Tools¶

    Camera-IMU Extrinsic Calibration¶

    Bash
    # Install Kalibr calibration tool
sudo apt install ros-humble-kalibr

# Collect calibration data
ros2 bag record /camera/image_raw /imu/data -o calibration_data

# Run calibration
kalibr_calibrate_imu_camera \
  --bag calibration_data.bag \
  --cam config/camera_chain.yaml \
  --imu config/imu.yaml \
  --target config/april_6x6.yaml

# Output: camchain-imucam.yaml (extrinsic calibration)

    Multi-Sensor Time Synchronization¶

    YAML
    # config/sensor_sync.yaml
sync_node:
  ros__parameters:
    # Synchronization policy
    policy: approximate  # exact or approximate
    queue_size: 10
    slop: 0.1  # seconds (for approximate sync)

    # Input topics
    topics:
      - /camera/image_raw
      - /imu/data
      - /lidar/scan

    # Output topic
    output_topic: /sensors/synchronized
