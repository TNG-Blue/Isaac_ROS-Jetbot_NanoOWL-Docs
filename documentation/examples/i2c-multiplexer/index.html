    DFRobot I2C Multiplexer Library¶

    Source

    This page is rendered from Utilities/DFRobot_I2C_Multiplexer/README.md, the authoritative description kept next to the code in Utilities/DFRobot_I2C_Multiplexer/.

    A professional-grade I2C multiplexer driver library for the Isaac ROS Jetbot NanoOWL platform running on Jetson Orin. Provides both Python and C++ APIs for controlling DFRobot I2C multiplexers with support for port selection, device scanning, and low-level I2C operations.

    Features¶

    • 🐍 Python API with smbus2 support for easy scripting
    • ⚙️ C++ API with native Linux i2c-dev support for performance-critical applications
    • 🔍 Device Scanning on each multiplexer port
    • 🎚️ Channel Management with support for up to 8 I2C channels
    • 🔗 Context Manager Support for automatic resource management in Python
    • 🛠️ Command-line Interface for system administration and debugging
    • 📡 Automatic Port Detection and device enumeration
    • 🧪 Comprehensive Testing with unit tests for both Python and C++
    • 📖 Extensive Documentation with examples and API reference

    Installation¶

    Python Package¶

    pip install dfrobot-i2c-multiplexer

    From Source (Development)¶

    git clone https://github.com/TNG-Blue/Isaac_ROS-Jetbot_NanoOWL.git
cd Utilities/DFRobot_I2C_Multiplexer

# Python
pip install -e .

# C++ (requires CMake 3.10+)
mkdir build && cd build
cmake ..
make
make install
cd ..

    Quick Start¶

    Python¶

    from dfrobot_i2c_multiplexer import I2CMultiplexer

# Initialize multiplexer on I2C bus 1, address 0x70
mux = I2CMultiplexer(addr=0x70, bus_num=1)

# Scan devices on port 0
devices = mux.scan(port=0)
print(f"Found devices: {devices}")

# Select a specific port
mux.select_port(1)

# Cleanup
mux.close()

    Or use context manager for automatic cleanup:

    from dfrobot_i2c_multiplexer import I2CMultiplexer

with I2CMultiplexer(addr=0x70, bus_num=1) as mux:
    for port in range(8):
        devices = mux.scan(port)
        print(f"Port {port}: {devices}")

    C++¶

    #include <dfrobot/i2c_multiplexer.hpp>
#include <iostream>

using namespace DFRobot;

int main() {
    try {
        // Initialize multiplexer
        I2CMultiplexer mux(0x70, 1);

        // Scan port 0
        auto devices = mux.scan(0);
        std::cout << "Found " << devices.size() << " devices\n";

        // Select port 1
        mux.selectPort(1);

    } catch (const std::exception& e) {
        std::cerr << "Error: " << e.what() << "\n";
        return 1;
    }
    return 0;
}

    Command Line Interface¶

    # Scan all ports
i2c-mux-scan -b 1 -a 0x70

# Scan specific port
i2c-mux-scan -b 1 -a 0x70 -p 0

# Use different bus
i2c-mux-scan -b 3 -a 0x70

    API Documentation¶

    Python API¶

    I2CMultiplexer Class¶

    class I2CMultiplexer:
    """I2C Multiplexer driver for Jetson Orin"""

    def __init__(self, addr: int = 0x70, bus_num: int = 1) -> None:
        """Initialize the multiplexer."""

    def scan(self, port: int) -> List[int]:
        """Scan for devices on a specific port."""

    def select_port(self, port: int) -> None:
        """Select an I2C channel."""

    def write_to_device(self, port: int, addr: int, reg: int, data: List[int]) -> None:
        """Write data to a device on a specific port."""

    def read_from_device(self, port: int, addr: int, reg: int, nbytes: int) -> List[int]:
        """Read data from a device on a specific port."""

    def disable_all_ports(self) -> None:
        """Disable all ports."""

    def close(self) -> None:
        """Close the I2C connection."""

    def __enter__(self) -> "I2CMultiplexer":
        """Context manager entry."""

    def __exit__(self, *args) -> None:
        """Context manager exit."""

    C++ API¶

    namespace DFRobot {

class I2CMultiplexer {
public:
    static constexpr uint8_t DEFAULT_ADDR = 0x70;
    static constexpr uint8_t MAX_CHANNELS = 8;

    // Constructor/Destructor
    I2CMultiplexer(uint8_t addr = DEFAULT_ADDR, int busNum = 1);
    ~I2CMultiplexer();

    // Port control
    std::vector<uint8_t> scan(uint8_t port);
    void selectPort(uint8_t port);
    void disableAllPorts();

    // Device operations
    void writeToDevice(uint8_t port, uint8_t addr, uint8_t reg, 
                      const std::vector<uint8_t>& data);
    std::vector<uint8_t> readFromDevice(uint8_t port, uint8_t addr, 
                                       uint8_t reg, size_t nbytes);

    // Accessors
    int getCurrentChannel() const;
    int getBusNumber() const;
    uint8_t getAddress() const;
};

}  // namespace DFRobot

    Requirements¶

    Python¶

    • Python 3.8 or higher
    • smbus2 >= 0.4.1

    C++¶

    • C++17 compatible compiler (g++, clang++)
    • CMake 3.10 or higher
    • Linux i2c-dev library (libi2c-dev on Ubuntu/Debian)

    System¶

    • Jetson Orin (or compatible ARM64 Linux system)
    • I2C device files (/dev/i2c-*)

    Installation of System Dependencies¶

    Ubuntu/Debian¶

    # I2C tools and libraries
sudo apt-get install -y i2c-tools libi2c-dev

# Python development headers
sudo apt-get install -y python3-dev

# Build tools
sudo apt-get install -y build-essential cmake

    Verify I2C Setup¶

    # List I2C buses
i2cdetect -l

# Scan a bus
i2cdetect -y 1

    Troubleshooting¶

    Device Not Found¶

    1. Check if I2C bus exists: i2cdetect -l
    2. Verify multiplexer address: i2cdetect -y <bus_number>
    3. Ensure correct permissions: sudo usermod -aG i2c $USER

    Permission Denied¶

    # Add user to i2c group
sudo usermod -aG i2c $USER

# Relogin or use:
newgrp i2c

    Import Errors¶

    # Ensure package is installed
pip list | grep dfrobot

# Reinstall
pip install --upgrade --force-reinstall dfrobot-i2c-multiplexer

    Performance Characteristics¶

    • Scan Time: ~100-200ms per port (depending on devices present)
    • Port Selection: ~1ms
    • I2C Read/Write: Standard i2c-dev performance
