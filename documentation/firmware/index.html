    Key Features¶

    Our microcontroller platform delivers enterprise-grade capabilities for remotely controlled devices including drones, autonomous robots, and smart navigation systems.

    Security Capabilities¶

    🔒 Anti-Theft & Anti-Copy Protection
    Comprehensive protection mechanisms safeguard source code and firmware from unauthorized access or duplication, ensuring complete system security and intellectual property protection.
    🛡️ Anti-Jamming & Anti-Spoofing
    Advanced signal protection ensures control communications cannot be interfered with or hijacked by unauthorized sources, maintaining operational safety in contested environments.

    Communication Systems¶

    📡 Over-the-Air (OTA) Updates
    Seamless remote software updates allow patches or firmware upgrades to be deployed wirelessly via http://jetbot_ros:8081/firmware, enhancing maintainability without physical access.
    🌐 Full-duplex LoRa RC link (LR1121)
    Two Core1121-XF modules per side: commands on 2.4 GHz with frequency hopping (50 Hz), telemetry on a second band (sub-GHz by default, 10 Hz), AES-CMAC authenticated. Ground unit: Remote_UAV (GIGA R1 + Display Shield).

    Navigation & Control¶

    🌍 Multi-GNSS Integration
    Dual GNSS module implementation enhances positioning accuracy and stability, crucial for autonomous navigation and precision localization tasks in various environments.
    🤖 ROS2 Integration
    Full compatibility with Robot Operating System 2 enables seamless interaction between system components via standardized topics and services, creating an extensible ecosystem for control applications.

    Integration with Drone Control¶

    The microcontroller is specifically engineered to support drone control with 6 Degrees of Freedom (6 DOF):

    • X-axis - Lateral movement
    • Y-axis - Forward/backward movement
    • Z-axis - Vertical movement
    • Roll - Rotation around X-axis
    • Pitch - Rotation around Y-axis
    • Yaw - Rotation around Z-axis

    This comprehensive control is achieved using only IMU sensors, enhancing the drone's maneuverability while optimizing system performance through integrated data from IMU and GNSS sources.

    Directory Structure¶

    microcontroller/
├── security/           # Anti-theft and anti-copy protection mechanisms
│   ├── encryption/     # Code and firmware encryption modules
│   └── authentication/ # Device and command authentication
├── communication/      # Communication protocols and interfaces
│   ├── lora/           # LoRa 915MHz implementation
│   └── ota/            # Over-the-air update system
├── navigation/         # Positioning and navigation systems
│   ├── gnss/           # Multi-GNSS integration modules
│   └── imu/            # IMU sensor integration
├── control/            # Flight and movement control systems
│   ├── six_dof/        # 6 DOF control algorithms
│   └── stabilization/  # Autonomous stabilization logic
└── ros2/              # ROS2 integration components
    ├── topics/         # Topic definitions and handlers
    └── services/       # Service implementations
