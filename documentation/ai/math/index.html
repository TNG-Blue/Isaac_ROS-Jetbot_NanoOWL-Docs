    Mathematical Foundations¶

    The signal chain follows the estimation-engineering convention throughout:

    sensor → conditioning filter → measurement → state estimator → estimate

    Concretely: camera (§2) → temporal filter (§4) → detector (§5, §6) → Kalman estimator (§8) → tracks with an explicit covariance.

    The chain stops at the estimate. This module produces perception output; it does not command actuators, and nothing here closes a loop through the scene.

    1. Activations¶

    (1.1) Logistic sigmoid.

    \[\sigma(x) = \frac{1}{1+e^{-x}}\]

    Evaluated as \(e^{x}/(1+e^{x})\) for \(x<0\). The two forms are equal in exact arithmetic (multiply numerator and denominator by \(e^{x}\)), but the naive form overflows for large \(|x|\) while the branched form never evaluates \(e^{|x|}\).

    (1.2)–(1.5) ReLU, leaky ReLU, SiLU, hard-swish.

    \[\mathrm{relu}(x)=\max(0,x),\qquad \mathrm{lrelu}(x)=\begin{cases}x & x>0\\ \alpha x & x\le 0\end{cases}\]
    \[\mathrm{silu}(x)=x\,\sigma(x),\qquad \mathrm{hswish}(x)=x\,\frac{\mathrm{clamp}(x+3,0,6)}{6}\]

    SiLU (Elfwing et al., Neural Networks 107, 2018) is the activation of the YOLOv8-family backbones this module targets.

    Proposition 1.1. \(\sup_x |\mathrm{hswish}(x)-\mathrm{silu}(x)| = 3/(1+e^{3}) \approx 0.14228\), attained at \(x=\pm 3\).

    Proof. For \(x\le-3\), \(\mathrm{hswish}=0\) and the difference is \(|x|\sigma(x)\), which decreases monotonically to 0 as \(x\to-\infty\) and equals \(3\sigma(-3)\) at \(x=-3\). For \(x\ge 3\), \(\mathrm{hswish}=x\) and the difference is \(x(1-\sigma(x)) = x\sigma(-x)\), again maximal at the endpoint with value \(3\sigma(-3)=3/(1+e^{3})\). On \([-3,3]\) both functions are smooth and the difference stays below that value. ∎

    The test computes the supremum numerically and checks it against the closed form — a claim that fails if either activation is mis-implemented.

    2. Colour Conversion¶

    The camera delivers YCbCr (NV12 from the Jetson ISP, YUYV from UVC); the network needs RGB. The conversion is the exact inverse of the standard's forward matrix.

    (2.1) BT.601 luma. \(Y = 0.299R + 0.587G + 0.114B\) (SDTV, \(K_r=0.299\), \(K_b=0.114\)).

    (2.2) BT.709 luma. \(Y = 0.2126R + 0.7152G + 0.0722B\) (HDTV).

    Forward transform. With \(K_g = 1-K_r-K_b\):

    \[Y = K_r R + K_g G + K_b B,\qquad C_b = 128 + \frac{B-Y}{2(1-K_b)},\qquad C_r = 128 + \frac{R-Y}{2(1-K_r)}\]

    (2.3) Inverse. Solving for \((R,G,B)\):

    \[R = Y + 2(1-K_r)(C_r-128)$$ $$B = Y + 2(1-K_b)(C_b-128)$$ $$G = Y - \frac{2K_b(1-K_b)}{K_g}(C_b-128) - \frac{2K_r(1-K_r)}{K_g}(C_r-128)\]

    Derivation of the green channel. From \(Y = K_rR + K_gG + K_bB\), \(G = (Y - K_rR - K_bB)/K_g\). Substituting the expressions for \(R\) and \(B\):

    \[G = \frac{Y - K_r\!\left[Y + 2(1-K_r)\Delta_r\right] - K_b\!\left[Y + 2(1-K_b)\Delta_b\right]}{K_g}\]

    with \(\Delta_r = C_r-128\), \(\Delta_b = C_b-128\). The \(Y\) terms collect to \(Y(1-K_r-K_b)/K_g = Y\), leaving the stated coefficients. ∎

    Studio swing. Broadcast standards restrict luma to \([16,235]\) and chroma to \([16,240]\). Rescaling to full range multiplies luma by \(255/219 = 1.164383\) after subtracting the offset 16, and chroma by \(255/224 = 1.138393\). Every limited-range coefficient in the code is its full-range counterpart times \(255/224\).

    The tests verify invertibility directly: forward-transform a set of RGB triples with the standard's definition, apply the implemented inverse, and require the original values back to within 0.02 code values.

    3. Geometric Resampling¶

    (3.1) Letterbox transform. To fit a \(W_s \times H_s\) source into a \(W_d \times H_d\) network input without distortion:

    \[s = \min\!\left(\frac{W_d}{W_s}, \frac{H_d}{H_s}\right),\qquad p_x = \frac{W_d - sW_s}{2},\qquad p_y = \frac{H_d - sH_s}{2}\]
    \[u_d = s\,u_s + p_x,\qquad v_d = s\,v_s + p_y\]

    A single scale on both axes is what preserves aspect ratio, and therefore the shape statistics the detector was trained on. The minimum guarantees \(sW_s \le W_d\) and \(sH_s \le H_d\), so the content fits; the halved remainder centres it. This module offers no anisotropic stretch: it is not a similarity transform, so a box in network coordinates would not map back by one scale.

    (3.2) Inverse, half-pixel convention.

    \[u_s = \frac{(u_d + 0.5) - p_x}{s} - 0.5\]

    Pixel \(i\) covers \([i, i+1)\) with centre \(i+0.5\). Mapping centre to centre gives the \(\pm 0.5\) terms. Omitting them shifts the sampling grid by half a destination pixel — at 640×640 from 1920×1080 that is a systematic 1.5-source-pixel bias on every box edge.

    (3.3) Bilinear interpolation. With \(x_0=\lfloor u\rfloor\), \(w_x = u - x_0\) (similarly for \(v\)):

    \[I(u,v) = (1-w_x)(1-w_y)I_{00} + w_x(1-w_y)I_{10} + (1-w_x)w_y I_{01} + w_x w_y I_{11}\]

    Lemma 3.1. The four weights are non-negative and sum to 1, so \(I(u,v)\) is a convex combination of the taps and cannot leave \([\min I_{ij}, \max I_{ij}]\).

    Proof. \(w_x,w_y\in[0,1)\) makes each product non-negative, and the sum factorises as \(\left[(1-w_x)+w_x\right]\left[(1-w_y)+w_y\right] = 1\). ∎

    Bilinear interpolation is also exact for any function of the form \(a + bx + cy + dxy\); the test checks this by reconstructing \(3x+5y+7\) at non-integer coordinates.

    (3.4) Normalisation. \(\hat{x} = (x/255 - \mu)/\sigma\) per channel.

    4. Temporal Denoising¶

    Sensor noise is independent frame to frame; the scene is not. That asymmetry is what a temporal filter exploits — and the correct filter constant follows from the noise statistics rather than from tuning.

    Model. Per pixel, a random walk observed in noise:

    \[x_k = x_{k-1} + w_k,\quad w_k\sim N(0,q),\qquad z_k = x_k + v_k,\quad v_k\sim N(0,r)\]

    (4.1)–(4.3) Scalar Kalman recursion.

    \[P_k^- = P_{k-1} + q,\qquad \alpha_k = \frac{P_k^-}{P_k^- + r},\qquad P_k = (1-\alpha_k)P_k^-\]

    (4.4) Steady-state gain. At steady state \(P_k = P_{k-1} = P\), so

    \[P = \frac{(P+q)r}{P+q+r}\]

    the scalar discrete algebraic Riccati equation. Writing \(M = P+q\) and \(\alpha = M/(M+r)\): from \(P = M(1-\alpha)\) and \(P = M-q\) we get \(M\alpha = q\), i.e. \(M = q/\alpha\); combined with \(M = \alpha r/(1-\alpha)\) this gives

    \[r\alpha^2 + q\alpha - q = 0 \quad\Longrightarrow\quad \alpha = \frac{-\lambda + \sqrt{\lambda^2 + 4\lambda}}{2},\qquad \lambda = q/r\]

    taking the positive root. The test asserts \(r\alpha^2 + q\alpha - q = 0\) directly.

    (4.5) The filter. \(\hat{x}_k = \hat{x}_{k-1} + \alpha(z_k - \hat{x}_{k-1})\) — an exponential moving average whose constant is derived, not guessed. A noisier sensor (larger \(r\)) lowers \(\alpha\); a more agitated scene (larger \(q\)) raises it.

    (4.6) Robust variant. A moving object violates the constant-scene hypothesis, and a plain EMA smears it. Attenuating the gain when the innovation is large relative to the sensor noise:

    \[\alpha_{\text{eff}} = \alpha\exp\!\left(-\frac{\nu^2}{2k^2r}\right),\qquad \nu = z_k - \hat{x}_{k-1}\]

    This is the Gaussian influence function of a robust M-estimator applied to the Kalman innovation: small innovations (noise) are filtered normally, large ones (motion) pass through nearly unfiltered.

    5. Detection Geometry¶

    (5.1)–(5.2) Area and IoU. The intersection of two axis-aligned boxes is the box with corners \((\max x_1, \max y_1, \min x_2, \min y_2)\), empty when either side is non-positive. Then

    \[\mathrm{IoU}(A,B) = \frac{|A\cap B|}{|A|+|B|-|A\cap B|}\]

    using \(|A\cup B| = |A|+|B|-|A\cap B|\) (inclusion–exclusion).

    (5.3) Distance-IoU (Zheng et al., AAAI 2020):

    \[\mathrm{DIoU} = \mathrm{IoU} - \frac{\rho^2(c_A,c_B)}{d^2}\]

    with \(\rho\) the centre distance and \(d\) the diagonal of the smallest enclosing box. The penalty is non-negative, so \(\mathrm{DIoU}\le\mathrm{IoU}\) always; it separates heavily overlapping boxes with distinct centres, which plain IoU cannot.

    (5.4) Soft-NMS (Bodla et al., ICCV 2017): \(s_i \leftarrow s_i\exp(-\mathrm{IoU}^2/\sigma)\). Continuous in IoU, so unlike hard NMS it has no discontinuity at the threshold.

    (5.5) Centre ↔ corner forms. \((c_x,c_y,w,h)\leftrightarrow(c_x\mp w/2, c_y\mp h/2)\).

    (5.6) Distribution Focal Loss decoding (Li et al., NeurIPS 2020). The head predicts a distribution over integer distances rather than a scalar; the decoded distance is its expectation:

    \[d = \sum_{i=0}^{n-1} i\,\mathrm{softmax}(\ell)_i\]

    Numerical stability. \(\mathrm{softmax}(\ell + c\mathbf{1}) = \mathrm{softmax}(\ell)\) for any constant \(c\), because \(e^{\ell_i+c}/\sum_j e^{\ell_j+c} = e^{c}e^{\ell_i}/(e^{c}\sum_j e^{\ell_j})\). Choosing \(c = -\max_i \ell_i\) bounds every exponential by 1, so no overflow is possible. The test shifts all logits by \(+500\) and requires the result unchanged.

    (5.7) Anchor-free reconstruction. For anchor point \((a_x,a_y)\) at stride \(s\) and decoded distances \((l,t,r,b)\) in stride units:

    \[x_1 = a_x - ls,\quad y_1 = a_y - ts,\quad x_2 = a_x + rs,\quad y_2 = a_y + bs\]

    Anchor points sit at cell centres, \(((c+0.5)s, (r+0.5)s)\).

    Greedy NMS and the bitmask sweep. Greedy NMS keeps detection \(i\) (in descending score order) iff no kept \(j<i\) suppresses it. The GPU evaluates the full \(N\times N\) overlap predicate into a bitmask; the host then sweeps in score order, keeping a running OR of the masks of everything kept. Detection \(i\) is kept iff its bit is clear in that union — which is exactly the greedy condition, since the union contains precisely the detections suppressed by survivors. tests/test_tracking.cpp checks the equivalence against a direct implementation over 300 randomised cases.

    6. Convolution Arithmetic¶

    (6.1) Definition.

    \[y[k,p,q] = b_k + \sum_{c}\sum_{r}\sum_{s} x[c,\,ps_h - P + rd,\,qs_w - P + sd]\; w[k,c,r,s]\]

    (6.2) Output extent.

    \[O = \left\lfloor\frac{I + 2P - d(k-1) - 1}{s}\right\rfloor + 1\]

    The dilated kernel spans \(d(k-1)+1\) samples; the last valid window starts at \(I+2P-\left[d(k-1)+1\right]\), and the floor counts the whole strides that fit.

    (6.3) "Same" padding. \(P = \lfloor d(k-1)/2\rfloor\) gives \(O = \lceil I/s\rceil\) for odd \(k\).

    (6.4) Lowering to GEMM (im2col). Materialising each receptive field as a column turns the convolution into

    \[Y_{[C_{out}\times O_hO_w]} = W_{[C_{out}\times C_{in}k^2]}\;X^{col}_{[C_{in}k^2\times O_hO_w]}\]

    Padding taps are written as zeros, so the dense product computes the padded convolution exactly. The \(k^2\)-fold memory expansion buys a dense GEMM, which a tiled shared-memory kernel executes at a far higher fraction of peak than a direct seven-loop convolution. Depthwise layers skip the lowering: their per-channel GEMMs have an inner dimension of 1, too small to amortise it.

    (6.5) Batch-norm folding. Inference-time batch norm is affine:

    \[y = \gamma\frac{x-\mu}{\sqrt{\sigma^2+\epsilon}} + \beta\]

    Composed with \(x = w*u + b\), and writing \(\kappa = \gamma/\sqrt{\sigma^2+\epsilon}\):

    \[y = \kappa(w*u + b - \mu) + \beta = (\kappa w)*u + \left[(b-\mu)\kappa + \beta\right]\]

    so \(w' = \kappa w\) and \(b' = (b-\mu)\kappa + \beta\) — an exact identity, not an approximation, using only the linearity of convolution. test_batchnorm_folding checks the folded and unfused paths agree elementwise.

    Precision of the accelerated backends. cuDNN and TensorRT evaluate the same equations in reduced precision, which is a numerical choice, not an algorithmic one:

    Format Exponent Mantissa Relative resolution Used by
    FP32 8 bits 23 bits \(\approx 10^{-7}\) native kernels, CPU reference
    TF32 8 bits 10 bits \(\approx 10^{-3}\) cuDNN on Ampere, by default
    FP16 5 bits 10 bits \(\approx 10^{-3}\) TensorRT with kFP16

    TF32 keeps FP32's exponent, so it cannot overflow where FP32 would not; only the significand is truncated. FP16 narrows the exponent too, which is why TensorRT still places range-sensitive layers in higher precision rather than converting the whole network.

    Both resolutions sit far below the input's own quantisation: an 8-bit sensor sample carries \(\approx 4\times10^{-3}\) relative resolution, so the arithmetic is not the limiting error term. This is why the accelerated backends are the default and the strict-FP32 path exists for verification (05_backend_benchmark --strict) rather than for production.

    (6.6) Max pooling. \(y[p,q] = \max_{r,s} x[ps_h+r,\, qs_w+s]\).

    (6.7) Nearest upsampling. \(y[p,q] = x[\lfloor p/f\rfloor, \lfloor q/f\rfloor]\). Detection necks convolve immediately after upsampling, so bilinear smoothing would be redundant work.

    7. Linear Algebra¶

    (7.1) Cholesky factorisation. For symmetric positive definite \(A = LL^{T}\):

    \[L_{jj} = \sqrt{A_{jj} - \sum_{k<j}L_{jk}^2},\qquad L_{ij} = \frac{A_{ij} - \sum_{k<j}L_{ik}L_{jk}}{L_{jj}}\ (i>j)\]

    Chosen over an explicit inverse because it is backward stable for SPD matrices and needs no pivoting. A non-positive pivot means \(A\) is not numerically positive definite — the failure is itself the diagnostic the Kalman update needs.

    (7.2) Solving. \(LL^{T}x=b\) by forward substitution on \(Ly=b\) then back substitution on \(L^{T}x=y\), each \(O(n^2)\).

    Symmetrisation. \(A \leftarrow (A+A^{T})/2\) is the orthogonal projection onto the symmetric subspace, hence the smallest Frobenius-norm correction restoring a property rounding has broken.

    8. Kalman Filtering¶

    State: \(x = [c_x, c_y, w, h, \dot c_x, \dot c_y, \dot w, \dot h]^{T}\). Measurement: \(z = [c_x,c_y,w,h]^{T}\), so \(H = [I_4\ 0]\).

    (8.1) Transition.

    \[F = \begin{bmatrix} I_4 & \Delta t\,I_4\\ 0 & I_4\end{bmatrix}\]

    This is exact, not a first-order approximation: the continuous model is \(\dot{x} = Ax\) with \(A = \begin{bmatrix}0&I\\0&0\end{bmatrix}\), and \(A^2=0\), so \(e^{A\Delta t} = I + A\Delta t\) terminates after two terms.

    (8.2) Process noise. Treating unmodelled acceleration as constant over one interval, \(w = Ga\) with \(G = [\Delta t^2/2,\ \Delta t]^{T}\) per axis:

    \[Q_{\text{axis}} = GG^{T}\sigma_a^2 = \sigma_a^2\begin{bmatrix} \Delta t^4/4 & \Delta t^3/2\\ \Delta t^3/2 & \Delta t^2\end{bmatrix}\]

    Being \(\sigma_a^2\) times an outer product, each block is positive semi-definite by construction and has rank 1 — the test checks \(\det Q_{\text{axis}} = 0\) and the Cauchy–Schwarz inequality on its entries. (Bar-Shalom, Estimation with Applications to Tracking and Navigation, §6.2.2.)

    (8.3) Predict. \(\hat{x}^- = F\hat{x}\), \(P^- = FPF^{T} + Q\).

    (8.4) Innovation. \(\nu = z - H\hat{x}^-\), \(S = HP^-H^{T} + R\). Since \(H\) is a selector, \(HP^-H^{T}\) is the leading \(4\times4\) block of \(P^-\) — no multiplication needed.

    (8.5) Mahalanobis gate. \(d^2 = \nu^{T}S^{-1}\nu\). Under the filter's Gaussian hypothesis \(d^2\sim\chi^2_4\), so comparing against \(\chi^2_{4,0.95}=9.4877\) is a test with a stated false-rejection rate of 5% — a calibrated statistic, not a tuned pixel threshold. Computed through the Cholesky factor of \(S\) rather than by inverting it.

    (8.6)–(8.7) Joseph-form update.

    \[K = P^-H^{T}S^{-1},\qquad \hat{x} = \hat{x}^- + K\nu$$ $$P = (I-KH)P^-(I-KH)^{T} + KRK^{T}\]

    Proposition 8.1. The Joseph form preserves symmetry and positive semi-definiteness for any gain \(K\), not only the optimal one.

    Proof. Both terms are congruence products \(MP^-M^{T}\) and \(KRK^{T}\). For any \(v\), \(v^{T}MP^-M^{T}v = (M^{T}v)^{T}P^-(M^{T}v)\ge 0\) when \(P^-\succeq 0\), and likewise for \(R\succeq 0\). A sum of PSD matrices is PSD, and each term is manifestly symmetric. ∎

    The short form \(P = (I-KH)P^-\) equals this only at the optimal gain and in exact arithmetic; under rounding it can lose symmetry and drift indefinite, at which point the filter diverges. The test runs 400 update cycles and requires \(P\) to stay Cholesky-factorisable throughout.

    (8.8) Innovation-based adaptation of R (Mehra, IEEE TAC 15(2), 1970). Track the residual covariance with an EWMA and recover \(R\) from \(S = HP^-H^{T}+R\):

    \[\hat{C}_\nu \leftarrow (1-\beta)\hat{C}_\nu + \beta\,\nu\nu^{T},\qquad \hat{R} = \max\!\left(R_{\min},\ \hat{C}_\nu - HP^-H^{T}\right)\]

    The floor \(R_{\min}>0\) is essential: the subtraction can drive a diagonal entry negative, which would destroy \(S\succ 0\) and with it the Cholesky factorisation. Only the diagonal is adapted, matching a detector whose four box coordinates are measured independently.

    (8.9) Confidence weighting. \(R(c) = R_0/\max(c, c_{\min})\). A half-confidence detection is given twice the variance and moves the state proportionally less — which is how a Kalman filter is meant to weigh a less reliable sensor.

    Data association. With \(n\) tracks and \(m\) detections, the cost

    \[C_{ij} = \omega\left(1 - \mathrm{IoU}_{ij}\right) + (1-\omega)\min\!\left(\frac{d^2_{ij}}{\chi^2_{4,0.95}},1\right)\]

    is minimised over assignments by the Hungarian algorithm in its \(O(n^3)\) shortest-augmenting-path form. It maintains dual potentials \(u_i,v_j\) with \(C_{ij}-u_i-v_j\ge0\), tight on matched pairs; when every row is matched, those duals certify global optimality by complementary slackness.

    Greedy nearest-neighbour matching offers no such guarantee. test_assignment includes the canonical counter-example — greedy pays 1.00 where the optimum is 0.35 — and checks the solver against brute-force enumeration on 200 random matrices.

    9. Camera Geometry¶

    (9.1) Normalised coordinates. \(x = (u-c_x)/f_x\), \(y = (v-c_y)/f_y\).

    Dividing the pixel offset by the focal length gives the tangent of the bearing angle to the point, which is independent of the sensor's resolution. A consumer of this module's detections can therefore reason about direction without knowing the camera format.

    (9.2) Depth from apparent height. Similar triangles in the pinhole model give \(h_{px} = f_yH/Z\), hence

    \[Z = \frac{f_y H}{h_{px}}\]

    for a known physical height \(H\). This is a monocular range estimate: it is only as good as the assumed object height, and it degrades as \(1/h_{px}\), so a one-pixel error at 100 px apparent height is 1% of range while the same error at 10 px is 10%. Where stereo or LiDAR is available, prefer their measurement.

    test_camera_geometry checks the round trip — project a known object at a known range, decode the range back — along with resolution independence and the degenerate cases.

    10. Exemplar Matching¶

    The training-free recognition path. A region is reduced to a fixed-length vector, remembered as a prototype, and anything whose vector is close enough to that prototype is reported as the same object. No dataset, no labels, no gradient step.

    10.1 Descriptors live on the unit sphere¶

    (10.1) L2 normalisation. \(\hat{v} = v/\|v\|_2\).

    Magnitude in an image descriptor encodes contrast and exposure, not identity, so it is divided out. Every descriptor this module produces is a unit vector, which makes the inner product a similarity directly.

    (10.2) Cosine similarity.

    \[s(a,b) = \frac{a^{T}b}{\|a\|\,\|b\|} \in [-1,1]\]

    (10.3) Equivalence with Euclidean distance. For unit \(u,v\):

    \[\|u-v\|^2 = \|u\|^2 + \|v\|^2 - 2u^{T}v = 2(1-s)\]

    Ranking by descending cosine similarity and by ascending Euclidean distance give the same order, so the matcher may reason in whichever is convenient.

    10.2 Histograms, and why the square root¶

    (10.4) L1 normalisation. \(p_i = v_i/\sum_j v_j\) puts a histogram of counts on the probability simplex, making it independent of how many pixels were sampled.

    (10.5) The Hellinger map. \(\phi(p) = \sqrt{p}\), elementwise.

    Proposition 10.1. \(\phi\) maps the probability simplex onto the unit sphere, and the inner product of two mapped histograms is the Bhattacharyya coefficient.

    Proof. \(\|\phi(p)\|_2^2 = \sum_i(\sqrt{p_i})^2 = \sum_i p_i = 1\), so the image lies on the unit sphere. And \(\phi(p)^{T}\phi(q) = \sum_i\sqrt{p_i}\sqrt{q_i} = \sum_i\sqrt{p_iq_i} = \mathrm{BC}(p,q)\). ∎

    (10.6) This is what unifies the two descriptor families: the same cosine routine compares gradient descriptors and colour histograms, and for the histograms it is a statistically meaningful quantity — the Bhattacharyya coefficient, with \(H^2(p,q) = 1 - \mathrm{BC}(p,q)\) the squared Hellinger distance. The square root is not a trick; it is the isometry that puts a distribution on the sphere.

    10.3 The prototype is optimal, not just convenient¶

    (10.7) Incremental mean. \(\mu_k = \mu_{k-1} + (x_k-\mu_{k-1})/k\), exact for every \(k\) and numerically stabler than accumulating \(\sum x_i\). A class is refined by showing another view; no history is kept.

    (10.8) The prototype. \(c = \mu/\|\mu\|\).

    Theorem 10.2. Given exemplars \(x_1,\dots,x_n\) on the unit sphere, the unit vector maximising the total similarity \(\sum_i c^{T}x_i\) is the normalised mean.

    Proof. \(\sum_i c^{T}x_i = c^{T}v\) with \(v = \sum_i x_i\). By Cauchy-Schwarz, \(c^{T}v \le \|c\|\|v\| = \|v\|\), with equality iff \(c\) is parallel to \(v\). The maximiser is therefore \(c = v/\|v\| = \mu/\|\mu\|\). ∎

    So the prototype is not an arbitrary average: it is the single direction that best explains every example it was built from. This is the nearest-class-mean classifier (Mensink et al., TPAMI 2013), which is Bayes-optimal when the class-conditionals share a covariance.

    The test verifies the theorem the hard way — 500 random unit directions, none of which beats the prototype.

    10.4 The acceptance gate has a stated error bound¶

    A similarity threshold picked by hand is a guess. This one is calibrated against the scene and carries a bound.

    (10.9) Cantelli's inequality. For any random variable with finite mean and variance,

    \[P(X - \mu \ge z\sigma) \le \frac{1}{1+z^2}\]

    (10.10) The gate. On learning, background regions of the same frame are described and compared with the new prototype, giving \(\mu_{bg}\) and \(\sigma_{bg}\). The threshold is

    \[\tau = \max(\tau_{floor},\ \mu_{bg} + z\,\sigma_{bg})\]

    By (10.9) the probability that a background region clears \(\tau\) is at most \(1/(1+z^2)\) — without assuming the similarity distribution is Gaussian, which it is not. At \(z=4\) the bound is 5.9%; at \(z=5\), 3.8%. The floor keeps a featureless background, where \(\sigma_{bg}\approx0\), from admitting everything.

    test_exemplar_math checks the bound empirically against a deliberately skewed distribution, which is where a Gaussian assumption would have failed.

    A second gate covers ambiguity: the winning similarity must exceed the runner-up's by a margin. Two remembered objects that explain a region equally well make the assignment a coin flip, and rejecting is better than guessing.

    10.5 The two descriptor families¶

    (10.11) L2-Hys normalisation (Dalal & Triggs, CVPR 2005 §6.4). L2-normalise, clip each component at \(\kappa\), renormalise.

    L2 normalisation alone already gives invariance to an affine illumination change \(I \mapsto aI+b\): the gradient removes \(b\) and scales by \(a\), which normalisation divides out. The clip bounds how much any one gradient — a specular highlight, a hard shadow edge — can dominate. Note the renormalisation scales everything back up, so components legitimately end above \(\kappa\): the clip bounds influence, not magnitude.

    (10.12) Orientation binning. A gradient angle is mapped to a fractional bin over \([0,\pi)\) for unsigned gradients or \([0,2\pi)\) for signed ones, and its vote is split between the two neighbouring bins. Splitting rather than rounding removes the aliasing that would make the descriptor jump as an edge slowly rotates. The spatial vote is bilinear over neighbouring cells for the same reason, so the full vote is trilinear.

    Unsigned is the default: for appearance matching, a dark-to-light edge and its mirror are the same structure.

    10.6 What this method can and cannot do¶

    It recognises the instance that was marked. Marking one red mug teaches that mug — not mugs. Category-level generalisation is exactly what training buys, and this is deliberately the other trade: instant, on the spot, for one object.

    One measurable limitation, found while testing rather than assumed: pixels below the saturation gate have no usable hue and are pooled into one achromatic bin, so an object that is largely black, white or grey puts most of its colour mass there — and so does every other such object, including background. A pattern of colour-against-black scores 0.5 in colour similarity against a differently coloured pattern of the same construction, purely through shared achromatic mass. For dark or desaturated objects, lower the colour weight and let the gradient half decide.
