    Helm Charts Deployment¶

    Deploy Isaac ROS Jetbot NanoOWL using Helm package manager.

    📚 Overview¶

    Helm simplifies Kubernetes deployments through templated manifests and package management, enabling easy customization and reuse.

    Benefits: - ✅ Parameterized deployments - ✅ Version management - ✅ Rollback capabilities - ✅ Dependency management - ✅ Simplified multi-environment setup - ✅ Community package sharing

    🚀 Quick Start¶

    Install Helm¶

    Bash
    # Download and install
curl https://raw.githubusercontent.com/helm/helm/main/scripts/get-helm-3 | bash

# Verify installation
helm version

# Add Helm repositories
helm repo add bitnami https://charts.bitnami.com/bitnami
helm repo add prometheus-community https://prometheus-community.github.io/helm-charts
helm repo update

    Deploy with Helm¶

    Bash
    # Add TNG Blue Helm repository
helm repo add tngblue https://helm.tngblue.com
helm repo update

# Install chart
helm install my-jetbot tngblue/jetbot-nanoowl \
  --namespace jetbot \
  --create-namespace

# List releases
helm list -n jetbot

# Check deployment status
helm status my-jetbot -n jetbot

# Get values
helm get values my-jetbot -n jetbot

    📋 Chart Files¶

    Chart.yaml¶

    YAML
    # File: Helm/charts/jetbot-nanoowl/Chart.yaml
apiVersion: v2
name: jetbot-nanoowl
description: |
  Isaac ROS Jetbot NanoOWL Helm Chart
  Enterprise-grade autonomous robotics platform
version: 2.0.0
appVersion: 2.0.0

type: application

keywords:
  - robotics
  - ROS2
  - autonomous
  - edge-ai
  - kubernetes

home: https://github.com/TNG-Blue/Isaac_ROS-Jetbot_NanoOWL
sources:
  - https://github.com/TNG-Blue/Isaac_ROS-Jetbot_NanoOWL
maintainers:
  - name: TNG Blue Team
    email: contact@tngblue.com

dependencies:
  - name: prometheus
    version: "15.x"
    repository: https://prometheus-community.github.io/helm-charts
    condition: prometheus.enabled
  - name: elasticsearch
    version: "19.x"
    repository: https://charts.bitnami.com/bitnami
    condition: elasticsearch.enabled

    values.yaml¶

    YAML
    # File: Helm/charts/jetbot-nanoowl/values.yaml

# Global settings
global:
  namespace: jetbot
  environment: production

# Motor Controller Deployment
motorController:
  enabled: true
  replicaCount: 1
  image:
    repository: tngblue/jetbot_nanoowl
    tag: "2.0.0"
    pullPolicy: IfNotPresent
  resources:
    requests:
      memory: "1Gi"
      cpu: "500m"
      nvidia.com/gpu: 1
    limits:
      memory: "2Gi"
      cpu: "1000m"
      nvidia.com/gpu: 1
  nodeSelector:
    jetbot: "true"
  env:
    ROS_DOMAIN_ID: "0"
    ROS_LOCALHOST_ONLY: "0"

# Object Detection Deployment
detection:
  enabled: true
  replicaCount: 1
  image:
    repository: tngblue/object_detection_isaac_ros
    tag: "2.0.0"
    pullPolicy: IfNotPresent
  resources:
    requests:
      memory: "2Gi"
      cpu: "1000m"
      nvidia.com/gpu: 1
    limits:
      memory: "4Gi"
      cpu: "2000m"
      nvidia.com/gpu: 1
  modelPath: /home/jetbot/models
  confidenceThreshold: 0.5

# SLAM Deployment
slam:
  enabled: true
  replicaCount: 1
  image:
    repository: tngblue/lidar_slam
    tag: "2.0.0"
  resources:
    requests:
      memory: "2Gi"
      cpu: "1000m"
    limits:
      memory: "3Gi"
      cpu: "1500m"

# Storage
storage:
  enabled: true
  className: fast-ssd
  size: 10Gi
  mountPath: /home/jetbot/data

# Service configuration
service:
  type: ClusterIP
  ports:
    ros2: 11311
    rest: 8080
    metrics: 9090

# Networking
networking:
  podNetworkPolicy:
    enabled: true
  ingress:
    enabled: false
    hosts:
      - jetbot.example.com

# Monitoring
monitoring:
  enabled: true
  prometheus:
    enabled: true
    retention: 15d
    scrapeInterval: 30s

# Logging
logging:
  enabled: true
  elasticsearch:
    enabled: true
  kibana:
    enabled: true

# Security
security:
  rbac:
    enabled: true
  networkPolicy:
    enabled: true
  podSecurityPolicy:
    enabled: true

# High Availability
ha:
  enabled: false
  replicaCount: 3
  antiAffinity: soft

# Multi-robot support
multiRobot:
  enabled: true
  robotCount: 1
  robots: []
    # - name: jetbot-1
    #   nodeSelector: jetbot-1
    #   robotId: 1

    Deployment Template¶

    YAML
    # File: Helm/charts/jetbot-nanoowl/templates/deployment.yaml
{{- if .Values.motorController.enabled }}
apiVersion: apps/v1
kind: Deployment
metadata:
  name: {{ include "jetbot-nanoowl.fullname" . }}-motor-controller
  namespace: {{ .Values.global.namespace }}
  labels:
    {{- include "jetbot-nanoowl.labels" . | nindent 4 }}
spec:
  replicas: {{ .Values.motorController.replicaCount }}
  selector:
    matchLabels:
      {{- include "jetbot-nanoowl.selectorLabels" . | nindent 6 }}
      component: motor-controller
  template:
    metadata:
      labels:
        {{- include "jetbot-nanoowl.selectorLabels" . | nindent 8 }}
        component: motor-controller
    spec:
      {{- with .Values.motorController.nodeSelector }}
      nodeSelector:
        {{- toYaml . | nindent 8 }}
      {{- end }}
      containers:
      - name: motor-controller
        image: "{{ .Values.motorController.image.repository }}:{{ .Values.motorController.image.tag }}"
        imagePullPolicy: {{ .Values.motorController.image.pullPolicy }}
        envFrom:
        - configMapRef:
            name: {{ include "jetbot-nanoowl.fullname" . }}-config
        resources:
          {{- toYaml .Values.motorController.resources | nindent 12 }}
        volumeMounts:
        - name: data
          mountPath: {{ .Values.storage.mountPath }}
        - name: serial
          mountPath: /dev/ttyUSB0
      volumes:
      - name: data
        persistentVolumeClaim:
          claimName: {{ include "jetbot-nanoowl.fullname" . }}-pvc
      - name: serial
        hostPath:
          path: /dev/ttyUSB0
          type: CharDevice
{{- end }}

    ConfigMap Template¶

    YAML
    # File: Helm/charts/jetbot-nanoowl/templates/configmap.yaml
apiVersion: v1
kind: ConfigMap
metadata:
  name: {{ include "jetbot-nanoowl.fullname" . }}-config
  namespace: {{ .Values.global.namespace }}
data:
  ROS_DOMAIN_ID: "{{ .Values.motorController.env.ROS_DOMAIN_ID }}"
  ROS_LOCALHOST_ONLY: "{{ .Values.motorController.env.ROS_LOCALHOST_ONLY }}"
  ENVIRONMENT: "{{ .Values.global.environment }}"
  {{- if .Values.detection.enabled }}
  DETECTION_CONFIDENCE: "{{ .Values.detection.confidenceThreshold }}"
  DETECTION_MODEL_PATH: "{{ .Values.detection.modelPath }}"
  {{- end }}

    Helpers Template¶

    YAML
    # File: Helm/charts/jetbot-nanoowl/templates/_helpers.tpl
{{/*
Expand the name of the chart.
*/}}
{{- define "jetbot-nanoowl.name" -}}
{{- default .Chart.Name .Values.nameOverride | trunc 63 | trimSuffix "-" }}
{{- end }}

{{/*
Create a default fully qualified app name.
*/}}
{{- define "jetbot-nanoowl.fullname" -}}
{{- if .Values.fullnameOverride }}
{{- .Values.fullnameOverride | trunc 63 | trimSuffix "-" }}
{{- else }}
{{- $name := default .Chart.Name .Values.nameOverride }}
{{- if contains $name .Release.Name }}
{{- .Release.Name | trunc 63 | trimSuffix "-" }}
{{- else }}
{{- printf "%s-%s" .Release.Name $name | trunc 63 | trimSuffix "-" }}
{{- end }}
{{- end }}
{{- end }}

{{/*
Create chart name and version as used by the chart label.
*/}}
{{- define "jetbot-nanoowl.chart" -}}
{{- printf "%s-%s" .Chart.Name .Chart.Version | replace "+" "_" | trunc 63 | trimSuffix "-" }}
{{- end }}

{{/*
Common labels
*/}}
{{- define "jetbot-nanoowl.labels" -}}
helm.sh/chart: {{ include "jetbot-nanoowl.chart" . }}
{{ include "jetbot-nanoowl.selectorLabels" . }}
{{- if .Chart.AppVersion }}
app.kubernetes.io/version: {{ .Chart.AppVersion | quote }}
{{- end }}
app.kubernetes.io/managed-by: {{ .Release.Service }}
{{- end }}

{{/*
Selector labels
*/}}
{{- define "jetbot-nanoowl.selectorLabels" -}}
app.kubernetes.io/name: {{ include "jetbot-nanoowl.name" . }}
app.kubernetes.io/instance: {{ .Release.Name }}
{{- end }}

    🚀 Deployment Commands¶

    Install Release¶

    Bash
    # Install with default values
helm install my-jetbot tngblue/jetbot-nanoowl -n jetbot --create-namespace

# Install with custom values
helm install my-jetbot tngblue/jetbot-nanoowl \
  -f values-prod.yaml \
  -n jetbot

# Install with inline value overrides
helm install my-jetbot tngblue/jetbot-nanoowl \
  --set motorController.replicaCount=2 \
  --set detection.enabled=true \
  -n jetbot

    Manage Releases¶

    Bash
    # List releases
helm list -n jetbot

# Check release status
helm status my-jetbot -n jetbot

# Get release values
helm get values my-jetbot -n jetbot

# Upgrade release
helm upgrade my-jetbot tngblue/jetbot-nanoowl \
  -f values-prod.yaml \
  -n jetbot

# Rollback release
helm rollback my-jetbot -n jetbot

# Delete release
helm uninstall my-jetbot -n jetbot

    🔄 Dependencies¶

    Update Dependencies¶

    Bash
    # Update chart dependencies
helm dependency update ./Helm/charts/jetbot-nanoowl/

# List dependencies
helm dependency list ./Helm/charts/jetbot-nanoowl/

# Build dependencies
helm dependency build ./Helm/charts/jetbot-nanoowl/

    📈 Packaging & Distribution¶

    Package Chart¶

    Bash
    # Create Helm package
helm package ./Helm/charts/jetbot-nanoowl/

# Output: jetbot-nanoowl-2.0.0.tgz

# Push to repository
helm push jetbot-nanoowl-2.0.0.tgz oci://registry.example.com/charts

    Create Helm Repository¶

    Bash
    # Generate index
helm repo index ./Helm/releases/

# Upload to GitHub Pages, S3, etc.
# Then users can:
helm repo add tngblue https://charts.tngblue.com

# Installation problems
helm install my-jetbot ./Helm/charts/jetbot-nanoowl/ --debug

# Check events
kubectl describe pods -n jetbot
kubectl logs -n jetbot -f deployment/motor-controller
