    🔧 Configuration Reference¶

    Environment Variables¶

    Bash
    # ROS2 Configuration
export ROS_DOMAIN_ID=42
export ROS_LOCALHOST_ONLY=1

# CUDA Configuration
export CUDA_VISIBLE_DEVICES=0
export TF_FORCE_GPU_ALLOW_GROWTH=true

# Application Configuration
export JETBOT_MODEL_PATH=/models
export JETBOT_LOG_LEVEL=INFO

    🆘 Troubleshooting¶

    Common Issues¶

    Camera not detected

    Problem: Camera node fails to start

    Solution:

    Bash
    # Check camera connection
ls /dev/video*

# Test with v4l2
v4l2-ctl --list-devices

# Verify permissions
sudo usermod -aG video $USER

    CUDA out of memory

    Problem: GPU memory exhausted

    Solution: - Reduce batch size in detection config - Lower model resolution - Enable model quantization - See Performance Tuning

    ROS2 nodes not communicating

    Problem: Nodes can't discover each other

    Solution:

    Bash
    # Check ROS_DOMAIN_ID
echo $ROS_DOMAIN_ID

# Verify network
ros2 daemon stop
ros2 daemon start

# Check node graph
ros2 node list
ros2 topic list

    More troubleshooting: Getting Started → Troubleshooting
