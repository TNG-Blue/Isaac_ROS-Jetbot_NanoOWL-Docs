    ROS2_RF_Spectrum — RF spectrum monitor, jamming/spoofing detection and RF failsafe¶

    Source

    This page is rendered from Source/ROS2_RF_Spectrum/README.md, the authoritative description kept next to the code in Source/ROS2_RF_Spectrum/.

    ros2_rf_spectrum 0.2.0 watches the 2.4–2.5 GHz command/telemetry band from an SDR, flags jamming and spoofing, and turns a detected threat into a supervisory flight-mode command for ros2_flight_controller. It contains no control law: the flight controller flies the commanded mode (RTH / LAND) with its own closed position loop.

    Executable (node name) Role
    spectrum_analyzer_cuda (spectrum_analyzer_cuda) IQ → windowed FFT (CuPy on the GPU, NumPy fallback) → power spectrum [dBm] → anomaly test (mean + 3σ) and threshold classification → alerts
    jamming_detector (jamming_detector_ml_cuda) spectrum → baseline + features → LSTM (TensorRT/GPU) and random forest → jamming flag and confidence
    failsafe_controller (failsafe_controller) rf_threat_alert → escalate-only, latched flight/nav_command (failsafe_policy.py) 
    ros2 launch ros2_rf_spectrum rf_monitor_lite.launch.py   # analyser + failsafe
ros2 launch ros2_rf_spectrum rf_monitor_full.launch.py   # + ML jamming detector
ros2 service call /failsafe_controller/reset std_srvs/srv/Trigger   # operator reset

    Parameters: config/sdr_config.yaml, config/frequency_bands.yaml, config/alert_thresholds.yaml, config/threat_signatures.yaml; failsafe actions jamming_action (RTH), spoofing_action (LAND), unknown_action (LAND).

    Node flowcharts¶

    Node graph¶

    flowchart LR
    SDR["SDR driver<br/>(external)"] --> RAW[/"rf_monitor/raw_iq<br/>Float32MultiArray, interleaved I/Q"/]
    RAW --> SA["spectrum_analyzer_cuda"]
    SA --> SPEC[/"rf_monitor/spectrum_data"/]
    SA --> AST[/"rf_monitor/analyzer_stats"/]
    SA --> ALERT[/"rf_threat_alert<br/>std_msgs/String"/]
    SPEC --> JD["jamming_detector_ml_cuda<br/>(rf_monitor_full only)"]
    JD --> JDET[/"rf_monitor/jamming_detected<br/>std_msgs/Bool"/]
    JD --> JCONF[/"rf_monitor/jamming_confidence"/]
    JD --> JST[/"rf_monitor/detector_status"/]
    ALERT --> FS["failsafe_controller"]
    RESET{{"~/reset<br/>std_srvs/Trigger"}} --> FS
    FS --> NAV[/"flight/nav_command<br/>HOVER, RTH, LAND, EMERGENCY_STOP"/]
    FS --> ACT[/"rf_failsafe/active<br/>Bool, transient local"/]
    NAV --> FC["flight_controller_node<br/>(closed position loop)"]

    Processing flow¶

    flowchart TD
    A(["spectrum_analyzer_cuda: on raw_iq"]) --> A1["interleaved floats → complex IQ<br/>(odd length rejected)"]
    A1 --> A2["pad / truncate / batch to fft_size"]
    A2 --> A3{"CUDA available?"}
    A3 -- yes --> A4["GPU: window × IQ, batched FFT, fftshift,<br/>power kernel → dBm, mean over batch"]
    A3 -- no --> A5["CPU: same steps with NumPy"]
    A4 --> A6["anomaly test: bins above mean + 3σ"]
    A5 --> A6
    A6 --> A6b["classify: mean > −50 dBm → jamming;<br/>max > −30 dBm and σ < 5 dB → spoofing;<br/>anomalies > 30 % of bins → interference"]
    A6b --> A7["publish rf_monitor/spectrum_data"]
    A7 --> A8{"jamming / spoofing?"}
    A8 -- yes --> A9["publish rf_threat_alert<br/>'JAMMING DETECTED (…)' / 'SPOOFING DETECTED (…)'"]

    J(["jamming_detector: on spectrum_data"]) --> J1["buffer spectra, learn baseline"]
    J2(["timer 0.1 s: process_detection"]) --> J3{"window full and<br/>baseline learned?"}
    J3 -- no --> J4["wait"]
    J3 -- yes --> J5["features → LSTM (GPU) + random forest"]
    J5 --> J6["combined confidence vs threshold,<br/>alert cooldown"]
    J6 --> J7["publish jamming_detected (on change),<br/>jamming_confidence"]

    F(["failsafe_controller: on rf_threat_alert"]) --> F1["classify text: jamming / spoofing / unknown"]
    F1 --> F2["action = jamming_action / spoofing_action / unknown_action"]
    F2 --> F3{"more severe than the active one?<br/>HOVER < RTH < LAND < EMERGENCY_STOP"}
    F3 -- no --> F4["ignore (escalate-only, latched)"]
    F3 -- yes --> F5["publish flight/nav_command,<br/>rf_failsafe/active = true"]
    R(["~/reset"]) --> R1["clear latched action,<br/>rf_failsafe/active = false"]

    Known limitations¶

    • rf_monitor/raw_iq must be published by an external SDR driver; none is part of this package.
    • The jamming_detector outputs (rf_monitor/jamming_*) are informational: only rf_threat_alert from spectrum_analyzer_cuda drives failsafe_controller.
    • The analyser's mean + 3σ test assumes Gaussian band power, and its classification thresholds (−50 dBm mean, −30 dBm peak, 5 dB spread, 30 % of bins) are fixed constants in spectrum_analyzer_cuda.py without a recorded derivation; their false-alarm and detection probabilities on real clutter have not been measured.
