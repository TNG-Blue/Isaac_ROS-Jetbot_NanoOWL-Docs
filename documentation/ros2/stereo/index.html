    ros2_stereo — stereo depth for the Jetbot¶

    Source

    This page is rendered from Source/ROS2_Stereo/README.md, the authoritative description kept next to the code in Source/ROS2_Stereo/.

    Two IMX219 cameras (60 mm baseline) → calibrated, rectified stereo pair → semi-global matching on the GPU (NVIDIA VPI) → filtered disparity → per-pixel Kalman estimate → metric depth with its 1σ uncertainty, point cloud, rectified images for NanoOWL.

     ┌──────────┐  ┌───────────────────┐  ┌──────────┐  ┌──────────────────┐  ┌────────────────┐  ┌──────────────────┐
 │ 2×IMX219 │─▶│ resize (INTER_AREA)│─▶│ SGM      │─▶│ spatial filter   │─▶│ Kalman / pixel │─▶│ Z = fB/(d−d_off) │─▶ depth, σ_Z, points
 │ CSI 30 Hz│  │ + rectify (Bouguet)│  │ VPI|SGBM │  │ conf·range·      │  │ on disparity,  │  │ σ_Z = Z²σ_d/(fB) │─▶ disparity, image_rect
 └──────────┘  └───────────────────┘  └──────────┘  │ speckle·median   │  │ χ² gate, NIS   │  └──────────────────┘─▶ /diagnostics
   sensor           filter (geometric)   measurement └──────────────────┘  └────────────────┘      output model
    Part Language / deps Runs on
    ros2_stereo_core — calibration, rectification, matchers, filters, Kalman, depth C++17, OpenCV (+ VPI on Jetson) Jetson, any x86 (tests, SIL)
    stereo_calibrate — chessboard calibration tool C++17, OpenCV bench / laptop
    stereo_node — CSI or topic input → all outputs rclcpp Jetson, Gazebo SIL
    depth_stereo_node, stereo_3d_node — external DisparityImage → depth / cloud rclcpp anywhere

    This package drives no actuator. It is the sensor → filter → estimator part of the loops that consume depth (navigation, obstacle stop, NanoOWL 3-D localisation); those loops close on it. Its failsafe is therefore on the data: invalid depth is NaN (never 0 or a stale value), every pixel carries σ_Z, and /diagnostics goes to ERROR when no depth has been produced for 1 s. Consumers must treat NaN as unknown, never as free space.

    Quick start¶

    colcon build --packages-select ros2_stereo && source install/setup.bash

# 1. Calibrate (once per rig, and after any change of lens, mount or flip_method)
ros2 launch ros2_stereo jetbot_stereo.launch.py          # uncalibrated bring-up, see WARN
ros2 service call /stereo/stereo_node/capture_calibration_pair std_srvs/srv/Trigger   # ×25–40 poses
ros2 run ros2_stereo stereo_calibrate --images /tmp/stereo_calibration \
    --board 9x6 --square 0.025 --output ~/stereo_calibration.yaml

# 2. Run
ros2 launch ros2_stereo jetbot_stereo.launch.py calibration_file:=$HOME/stereo_calibration.yaml
ros2 run rqt_image_view rqt_image_view /stereo/disparity/color
ros2 topic echo /diagnostics --field status[0].values     # rate, latency, NIS …

# Simulation / rosbag (left/image_raw + right/image_raw in /stereo)
ros2 launch ros2_stereo stereo.launch.py sim:=true

    Without ROS: cmake -S . -B build -DBUILD_TESTING=ON && cmake --build build -j && ctest --test-dir build.

    Interfaces (stereo_node, namespace stereo in the launch files)¶

    Topic Type Content
    left/image_raw, right/image_raw (sub, topics mode) sensor_msgs/Image bgr8 or mono8, approximate-time synchronised
    left/image_rect + left/camera_info Image + CameraInfo rectified left at the working resolution, K D R P
    right/image_rect + right/camera_info idem P with T_x = −f·B (output.right_rectified)
    disparity stereo_msgs/DisparityImage 32FC1 px, NaN invalid; f, T, band, Δ = delta_d
    depth Image 32FC1 Z [m], NaN invalid (REP 118)
    depth/uncertainty Image 32FC1 σ_Z [m] per pixel
    confidence Image 32FC1 matcher confidence ∈ [0, 1] (VPI only)
    points PointCloud2 x y z (+ rgb) [m], left optical frame (REP 103), dense
    disparity/color Image bgr8 visualisation only
    /diagnostics DiagnosticArray rate, latency, timing, valid %, NIS test

    Services: set_processing (SetBool), topic enable_processing (Bool), ~/capture_calibration_pair and ~/reset_temporal_filter (Trigger). Every parameter is documented in config/stereo_params.yaml with its unit and origin; filter, estimator, matcher-penalty and depth-window parameters can be changed at run time (ros2 param set) and are validated before they are applied.

    depth_stereo_node (disparity → depth, depth/uncertainty, depth/image_mm 16UC1) and stereo_3d_node (disparity + left/camera_info → points) serve disparity from other sources (Isaac ROS ESS, stereo_image_proc): stereo_postprocess.launch.py.

    Design record¶

      CONTROL DESIGN (perception stages; no actuator)
    Sensor        : 2× Sony IMX219, 1640×1232 (2×2 binned, full FOV) @ f_s = 30 Hz, free-running,
                    grab() back-to-back → inter-camera skew ≤ 1/f_s. Measurement y = I(u, v).
    Filter        : INTER_AREA resize to 480×360 (box pre-filter, anti-aliasing) + rectification
                    (Bouguet, from a Zhang calibration); disparity gates: confidence, depth window,
                    speckle (A = 100 px, δ = 1 px), 3×3 majority median.
    Measurement   : SGM disparity d [px], Q10.5 (VPI, Δ = 1/32) or Q12.4 (SGBM, Δ = 1/16).
                    Noise σ_d = 0.3 px (bound of 0.278 px measured on the synthetic scene; re-measure).
    Estimator     : scalar Kalman filter per pixel on d, random walk with
                    Q = (x̂²σ_vΔt/(fB))² + q₀, R = σ_d² + Δ²/12, χ²₁ gate γ = 6.635, reset after 3.
    Output model  : Z = fB/(d − d_off), σ_Z = Z²σ_d/(fB);  X = (u − c_x)Z/f_x, Y = (v − c_y)Z/f_y.
    Timing        : T_s = 33 ms; latency = grab → publish, reported in /diagnostics.
    Failsafe      : NaN for invalid; diagnostics ERROR when no output for 1 s; node refuses to
                    start without calibration or explicit fallback geometry.
    Verification  : unit tests + in-process ROS SIL on a ray-traced scene (below); bench/HIL pending.
    References    : Hartley & Zisserman; Zhang 2000; Hirschmüller 2008; Simon 2006; Bar-Shalom 2001.

    1. Resolution change and rectification¶

    A resize by s about pixel centres (the cv::resize convention, pixel centres at integer coordinates) maps u' = s(u + ½) − ½. Composing with u = f·x + c for the normalised coordinate x gives

    f' = s·f,    c' = s·(c + ½) − ½,    distortion coefficients unchanged (they act on x)

    so the calibration done at the capture size is exact at the working size (scale_intrinsics, checked by ScaleIntrinsicsFollowsPixelCentreConvention). Shrinking uses INTER_AREA, whose box kernel is the pre-filter that bounds aliasing; plain bilinear decimation by 3.4 would alias. Rectification (cv::stereoRectify, CALIB_ZERO_DISPARITY) rotates both cameras by R1, R2 so epipolar lines are image rows and c_x = c_x' (d_off = 0); the baseline is recovered as B = −P2(0,3)/P2(0,0) = ‖T‖.

    2. Disparity → depth and its uncertainty¶

    For a rectified pair (Hartley & Zisserman §9.3, §12.1):

    x_l = f·X/Z + c_x,   x_r = f·(X − B)/Z + c_x'   ⇒   d = x_l − x_r = f·B/Z + d_off
Z = f·B/(d − d_off)
∂Z/∂d = −f·B/(d − d_off)² = −Z²/(f·B)   ⇒   σ_Z = Z²·σ_d/(f·B)            (first order)
E[Ẑ] − Z ≈ Z·(σ_d/(d − d_off))²                                           (second order)

    The first-order σ_Z is checked against Monte Carlo (DepthSigmaMatchesMonteCarlo, within 2 %), and the reprojection against cv::reprojectImageTo3D with the same Q matrix. For the Jetbot (f = 339.7 px at 480 px, B = 0.06 m, fB = 20.38 px·m, σ_d = 0.3 px, Δ = 1/32 px):

    Z [m] d [px] σ_Z, one frame depth step of Δ σ_Z, Kalman steady state at σ_v = 0.5 m/s time constant
    0.3 67.9 1.3 mm 0.14 mm 1.3 mm 7 ms
    0.5 40.8 3.7 mm 0.38 mm 3.6 mm 11 ms
    1.0 20.4 14.7 mm 1.5 mm 12.0 mm 31 ms
    2.0 10.2 58.9 mm 6.1 mm 29.2 mm 118 ms
    3.0 6.8 132 mm 13.8 mm 45.5 mm 265 ms
    5.0 4.1 368 mm 38.3 mm 77.4 mm 736 ms

    max_depth = 5 m is where one frame gives σ_Z/Z = 7.4 %; beyond it the band d < fB/max_depth is rejected. min_depth = 0.2 m needs d = 102 px < max_disparity = 128.

    3. Spatial filter (disparity_filter.hpp)¶

    Order: matcher invalid codes → confidence gate → depth-window band [fB/Z_max + d_off, min(fB/Z_min + d_off, D_max − 1)] → speckle removal (connected regions of < A px with steps ≤ δ are mismatches) → majority median: a k×k median is applied only where ≥ (k² + 1)/2 of the window is valid. Invalid pixels are stored as 0, the minimum of the window, so with fewer than half of them the ((k² + 1)/2)-th order statistic is a valid sample — the median can never write an invalid value into a valid pixel, and it never fills holes (randomised property test MajorityMedianPropertyRandomised).

    4. Estimator: per-pixel Kalman filter on disparity (temporal_disparity_filter.hpp)¶

    Disparity, not depth, is filtered because the matching error is homoscedastic in d (σ_d does not depend on range) while σ_Z ∝ Z²; a constant R is only correct in disparity space.

    x[k] = x[k−1] + w,   w ~ N(0, Q),   Q = (x̂²·σ_v·Δt/(fB))² + q₀     (ḋ = −(d²/(fB))·Ż, Ż ~ N(0, σ_v²))
z[k] = x[k] + v,     v ~ N(0, R),   R = σ_d² + Δ²/12                (matching + uniform quantisation)
P⁻ = P + Q;  ν = z − x̂;  S = P⁻ + R;  NIS = ν²/S
NIS ≤ γ:  K = P⁻/S,  x̂ ← x̂ + Kν,  P ← (1 − K)P⁻          (scalar: identical to the Joseph form)
NIS > γ:  keep x̂, P ← P⁻; after 3 consecutive rejections re-initialise on z (the scene changed)
no z:     P ← P⁻ (coast); output withheld once P > P_max = 1 px²

    Stability. 0 < K < 1, so the error recursion e[k] = (1 − K)e[k−1] + … is exponentially stable. With constant Q the Riccati recursion converges to P⁻∞ = (Q + √(Q² + 4QR))/2, K∞ = P⁻∞/(P⁻∞ + R) — an exponential smoother with α = K∞ and time constant −Δt/ln(1 − K∞) (table above); with Q = 0 it is the recursive mean P_n = R/n. Both are unit tests (ConvergesToRiccatiSteadyState, RecursiveMeanWithoutProcessNoise).

    Consistency. When the model holds, NIS ~ χ²₁: the gate rejects α = 1 − F₁(γ) = 1 % and the accepted NIS averages F₃(γ)/F₁(γ) = 0.925 (from x·f₁(x) = f₃(x)). NisConsistencyOnStaticScene checks both on 1.1 M simulated updates; on the robot /diagnostics reports the measured and expected values and goes to WARN when the mean deviates by more than 25 % over ≥ 10 000 updates (sampling σ of the mean ≈ √(2/N) ≤ 1.4 %, so 25 % is a real model mismatch).

    Assumptions. A pixel is the same scene point from frame to frame, i.e. image motion is small over τ. Rotation of the robot violates this at depth discontinuities; the gate and the 3-frame reset bound the damage, and q₀ is the one tunable term for it — set it only from a recording, checked with the NIS values. temporal.enable: false gives the raw per-frame estimate with σ_Z computed from σ_d.

    5. Matchers¶

    Both implement semi-global matching (Hirschmüller 2008): pixel-wise matching cost aggregated along 1-D paths with penalties P1 (|Δd| = 1) and P2 (|Δd| > 1).

    • vpi — VPIStereoDisparityEstimator, CUDA backend: census cost, Q10.5 output and a confidence map (used by the confidence gate). BGR8 → Y16_ER conversion on the GPU.
    • sgbm — OpenCV StereoSGBM (3-way), Q12.4 output, left-right consistency check with disp12MaxDiff = 1 px, P1 = 8w², P2 = 32w². CPU; used on x86 for SIL and CI.

    Calibration¶

    1. ros2 launch ros2_stereo jetbot_stereo.launch.py, show a flat chessboard (9×6 inner corners, printed square measured with a calliper) and call ~/capture_calibration_pair for 25–40 poses: tilt ±25°, 0.4–1 m, and centres spread over the whole image including the corners. With boards only near the centre the distortion is extrapolated at the edges: the synthetic rig then shows 0.35 px row error at the image edge instead of 0.04 px.
    2. stereo_calibrate --images DIR --board 9x6 --square <m> --output stereo_calibration.yaml runs a mono calibration of each camera (Zhang 2000) and then a joint refinement of both intrinsics and the extrinsics (bundle adjustment). With 0.1 px corner noise on the synthetic rig, fixed intrinsics gave rectified row errors up to 0.65 px (6 draws), the joint refinement at most 0.09 px over 40 draws with OpenCV 4.6 (0.30 px worst with 4.11).
    3. Accept when: the stereo RMS is close to the corner-noise floor √2·σ_c (σ_c, the corner-detector noise, is typically 0.1–0.2 px), the rectified row error is ≤ 0.5 px (SGM degrades beyond it — Hirschmüller & Gehrig 2009; the tool exits with code 3 above it), and no view is listed as an outlier (> 2× median error).
    4. Calibrate at the capture size with the same flip_method; the node rescales to the working size.

    Characterising σ_d (required before trusting σ_Z)¶

    Place a textured plane fronto-parallel at 1.0 m and record disparity for 10 s with temporal.enable: false. Fit a plane d = a·u + b·v + c over the valid pixels; the robust σ_d is 1.4826·MAD of the residual (the same estimator as IdealRigRecoversDepth, which measured 0.278 px for SGBM on synthetic texture). Set disparity_sigma to that value (VPI and SGBM differ), then run a static recording with the Kalman filter enabled and check temporal NIS mean ≈ 0.925 and temporal gated ≈ 1 % in /diagnostics.

    Verification¶

    Rule order: model → SIL → HIL → bench → vehicle.

    Level Evidence Status
    Unit (core, no ROS) test_stereo_geometry, test_stereo_calibration, test_disparity_filter, test_temporal_filter, test_csi_stereo_camera pass (OpenCV 4.6 and 4.11)
    Pipeline test_stereo_pipeline: ray-traced plane (1.2 m) + box (0.7 m) through a distorted, toed-in rig; depth within 1–1.5 %, σ_d measured, temporal jitter reduction pass
    SIL (ROS) test_stereo_node: nodes in-process on synthetic images: depth, disparity, CameraInfo, clouds, chained nodes, parameter validation pass (ROS 2 Humble)
    HIL / bench VPI matcher on the Jetson, σ_d on a plane, NIS on a static recording, latency pending — the VPI path has not been compiled or run yet

    Limitations¶

    • The VPI matcher (src/vpi_stereo_matcher.cpp) is compiled only on JetPack; it follows the API calls of the previous implementation but has not been built in CI.
    • The two IMX219 are free-running: fast rotation adds a disparity error u̇·Δt_skew.
    • SGBM sub-pixel errors are not Gaussian (pixel locking); the χ² gate absorbs the tails, and σ_d is a robust (MAD) estimate.
    • stereo_msgs/DisparityImage has no d_off field; the external-disparity nodes assume zero-disparity rectification.
