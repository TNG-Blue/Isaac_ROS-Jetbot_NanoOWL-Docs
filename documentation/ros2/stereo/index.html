    Stereo Vision¶

    Metric depth from the Jetbot's two IMX219 cameras: calibration, rectification, semi-global matching on the GPU, filtering and a per-pixel Kalman estimate. Every depth value comes with its 1σ uncertainty.

    Package: Source/ROS2_Stereo (ros2_stereo). Its README is the full design record: derivations, parameters and verification.

    🎯 Overview¶

    • Dual IMX219 on CSI-0/CSI-1, 60 mm baseline, 1640×1232 @ 30 Hz, processed at 480×360
    • Chessboard calibration tool (stereo_calibrate) and Bouguet rectification
    • Semi-global matching: NVIDIA VPI on CUDA, or OpenCV SGBM on the CPU for simulation and CI
    • Disparity filters: confidence, depth window, speckle, majority median
    • Per-pixel Kalman filter on disparity with χ² gating and an NIS consistency check
    • Outputs: depth (REP 118), depth uncertainty, DisparityImage, colour point cloud, rectified images and CameraInfo (for NanoOWL 3-D localisation), /diagnostics
    graph LR
    CAM["2× IMX219<br/>CSI 30 Hz"] --> RECT["Resize (INTER_AREA)<br/>+ rectification"]
    RECT --> SGM["SGM matching<br/>VPI | SGBM"]
    SGM --> FILT["Spatial filter<br/>conf · range · speckle · median"]
    FILT --> KF["Kalman per pixel<br/>χ² gate, NIS"]
    KF --> DEPTH["Z = fB/(d − d_off)<br/>σ_Z = Z²σ_d/(fB)"]
    DEPTH --> OUT["depth · σ_Z · points<br/>disparity · image_rect"]

    🚀 Quick Start¶

    colcon build --packages-select ros2_stereo && source install/setup.bash

# Calibrate once per rig (25–40 chessboard poses covering the whole image, corners included)
ros2 launch ros2_stereo jetbot_stereo.launch.py
ros2 service call /stereo/stereo_node/capture_calibration_pair std_srvs/srv/Trigger
ros2 run ros2_stereo stereo_calibrate --images /tmp/stereo_calibration \
    --board 9x6 --square 0.025 --output ~/stereo_calibration.yaml

# Run
ros2 launch ros2_stereo jetbot_stereo.launch.py calibration_file:=$HOME/stereo_calibration.yaml
ros2 run rqt_image_view rqt_image_view /stereo/disparity/color

# Simulation or rosbag: /stereo/left/image_raw and /stereo/right/image_raw
ros2 launch ros2_stereo stereo.launch.py sim:=true

    🎮 ROS 2 Interface (namespace stereo)¶

    Topic Type Content
    left/image_raw, right/image_raw sensor_msgs/Image input in sim:=true (topics) mode
    left/image_rect, left/camera_info Image, CameraInfo rectified left image, K D R P
    right/image_rect, right/camera_info Image, CameraInfo optional, P with T_x = −f·B
    disparity stereo_msgs/DisparityImage 32FC1 px, NaN = invalid
    depth Image 32FC1 metres, NaN = invalid
    depth/uncertainty Image 32FC1 σ_Z in metres
    confidence Image 32FC1 matcher confidence (VPI)
    points PointCloud2 x y z rgb, left optical frame
    disparity/color Image bgr8 visualisation
    /diagnostics DiagnosticArray rate, latency, valid pixels, NIS test

    Services: set_processing (SetBool), stereo_node/capture_calibration_pair, stereo_node/reset_temporal_filter (Trigger). Parameters with units and their origin: config/stereo_params.yaml.

    For disparity from another source (Isaac ROS ESS, stereo_image_proc), stereo_postprocess.launch.py runs depth_stereo_node (depth, σ_Z, 16UC1 mm) and stereo_3d_node (point cloud with the principal point from CameraInfo).

    📐 Stereo Geometry¶

    For a rectified pair with focal length f [px], baseline B [m] and principal-point offset d_off = c_x − c_x' (0 after zero-disparity rectification):

    d = x_left − x_right = f·B/Z + d_off          ⇒   Z = f·B / (d − d_off)
X = (u − c_x)·Z/f_x,   Y = (v − c_y)·Z/f_y      (REP 103 optical frame)

    Depth accuracy¶

    The uncertainty follows from first-order error propagation, ∂Z/∂d = −Z²/(f·B):

    σ_Z = Z² · σ_d / (f · B)

    The uncertainty grows with the square of the range. For the Jetbot (f = 339.7 px at 480 px, B = 0.06 m, matcher noise σ_d = 0.3 px):

    Range Disparity σ_Z (one frame) σ_Z (Kalman, moving at 0.5 m/s)
    0.5 m 40.8 px 3.7 mm 3.6 mm
    1 m 20.4 px 15 mm 12 mm
    2 m 10.2 px 59 mm 29 mm
    3 m 6.8 px 132 mm 46 mm
    5 m 4.1 px 368 mm 77 mm

    σ_d must be measured on the rig: a fronto-parallel plane, then 1.4826 × MAD of the plane-fit residual. The package README gives the procedure.

    🔍 Troubleshooting¶

    Symptom Likely cause Action
    /diagnostics WARN "uncalibrated" no calibration_file calibrate; the fallback geometry is a ±5 % guess
    Few valid pixels, streaks rectified row error > 0.5 px recalibrate with boards in the image corners; check stereo_calibrate output
    Holes on blank walls no texture expected: SGM needs texture (NaN = unknown, not free space)
    WARN "temporal filter inconsistent" σ_d or σ_v wrong for this rig measure σ_d; check temporal.* against a recording
    ERROR "no depth output" camera stalled nvargus-daemon running? check CSI cables and sensor ids
