    ros2_night_vision_owl¶

    Source

    This page is rendered from Source/ROS2_Night_Vision_OWL/README.md, the authoritative description kept next to the code in Source/ROS2_Night_Vision_OWL/.

    Radiometric thermal detection and tracking for ROS 2 Humble. A Meridian MI48 camera (or a synthetic scene for software-in-the-loop) feeds a filter, a constant-false-alarm-rate (CFAR) hot-target detector and a multi-target Kalman tracker. Every stage has a closed-form model: thresholds come from a chosen false-alarm probability, measurement covariances from error propagation, gates from chi-square quantiles. None of them is tuned by eye.

    Signal chain¶

     MI48 / synthetic                 thermal_detector_node                          thermal_tracker_node
┌──────────────┐  32FC1 °C  ┌─────────────────────────────────────────────┐ Detection2DArray ┌─────────────────────────┐ Detection2DArray
│ sensor       │──────────▶│ bad-pixel fix ─▶ temporal LPF ─▶ CA-CFAR     │──────────────▶│ CV Kalman (DWNA)        │──────────────▶ tracks
│ y = T + n    │           │       │            (detect)       │          │  u, v, R (2x2)  │ + likelihood-ratio GNN │  u, v, P (2x2)
└──────────────┘           │       └────── raw frame ──▶ centroid + R     │               │ + M-of-N, NIS monitor  │
                           │  NETD estimator ─▶ noise floor ─┘            │               └──────────▲──────────────┘
                           └─────────────────────────────────────────────┘                          │
                                                                          predicted state gates the next scan (feedback)

    This package ends at the estimator. It commands no actuator. A controller that follows a target (gimbal, heading) subscribes to tracks and closes its own loop on the estimated position and covariance. If detections stop, the tracker publishes an empty track list, so a consumer never acts on a stale track.

    Quick start¶

    colcon build --packages-select ros2_night_vision_owl
source install/setup.bash

# Software-in-the-loop: synthetic scene -> detector -> tracker
ros2 launch ros2_night_vision_owl night_vision_owl_pipeline.launch.py

# Hardware: MI48 over USB (port auto-detected), false-colour overlay on
ros2 launch ros2_night_vision_owl night_vision_owl_pipeline.launch.py source:=mi48 debug_image:=true

# Another node publishes <namespace>/image_temperature
ros2 launch ros2_night_vision_owl night_vision_owl_pipeline.launch.py source:=none

# Camera only (used by Docker/Kubernetes)
ros2 launch ros2_night_vision_owl camera.launch.py source:=mi48

# Algorithm tests (numpy/scipy only, no ROS needed)
python3 -m pytest test/unit -q

    Nodes¶

    All topic names are relative. The launch file puts the nodes in the thermal namespace.

    Executable Subscribes Publishes
    thermal_camera_node – image_temperature (32FC1 °C), camera_info, /diagnostics
    thermal_detector_node image_temperature detections (Detection2DArray), image_filtered, image_debug, /diagnostics
    thermal_tracker_node detections tracks (Detection2DArray), /diagnostics

    * optional. Detections and tracks use pixel coordinates (u right, v down, pixel centres on integers). Each Detection2D carries:

    Field Detection Track
    results[0].pose.pose.position centroid (u, v) filtered position (u, v)
    results[0].pose.covariance[0, 1, 6, 7] 2×2 centroid covariance R [px²] 2×2 position covariance P [px²]
    bbox the blob's box: centre u_min + (w − 1)/2, size w × h box of the track size, centred on the position
    id empty track id

    The position is read from the field that carries its covariance: results[0].pose when that 2×2 block is positive definite, otherwise the bbox centre. The tracker accepts detections from other producers such as NanoOWL; when a producer leaves the covariance empty, the tracker uses the bbox centre with default_measurement_std_px. The ros2_qt dashboard reads the same fields (Vision tab → Thermal).

    Parameters and their derivations are listed in config/thermal_pipeline.yaml. The detector's false-alarm probability, area limits and temperature gates can be changed at run time (ros2 param set). Every parameter is range-checked.

    Design¶

    1. Sensor model¶

    y[k](u, v) = T(u, v, t_k) + n[k](u, v), in °C, with n white in time and space and std σ_n, the sensor's NETD. The noise is measured, not assumed. For a static pixel, d = y[k] − y[k−1] ~ N(0, 2σ_n²), so

    σ̂_n = 1.4826 · MAD(d) / √2

    The MAD is taken over all pixels and smoothed over noise_averaging_frames. The MAD has a 50 % breakdown point. Moving targets and ego-motion bias the estimate upward, which lowers the false-alarm rate. The SIL check measured σ̂_n = 0.1009 K for a true 0.100 K.

    2. Filtering¶

    Temporal low-pass, exact ZOH discretisation. H(s) = ω_c/(s + ω_c) with a piecewise-constant input over one frame integrates exactly to

    y[k] = y[k−1] + α_k (x[k] − y[k−1]),    α_k = 1 − exp(−ω_c Δt_k)

    Δt_k comes from message stamps, so jitter is handled exactly. The project rule's α = ω_cT/(1+ω_cT) is the backward-Euler form of the same filter; the two agree to first order.

    • Noise. y[k] = Σ_i α(1−α)^i x[k−i], so for white input Var y / Var x = α² Σ(1−α)^{2i} = α/(2−α). With time-varying α_k the variance ratio follows r[k] = (1−α_k)² r[k−1] + α_k², with r = 1 at reset. The code tracks this exactly, transient included.
    • Target retention. A pixel covered for τ = d/v seconds reaches 1 − e^{−ω_c τ} of the contrast. Keeping 90 % requires v ≤ ω_c d / ln 10. At f_c = 4 Hz and d = 3 px that is 32.7 px/s.
    • Delay. The output's mean age obeys L[k] = (1−α_k)(Δt_k + L[k−1]), with steady state T(1−α)/α (23 ms at 25 Hz, f_c = 4 Hz). It is reported in the diagnostics. The tracker never sees it (see §3).

    Bad pixels. NaNs and the static bad_pixels list are replaced by the median of their valid 3×3 neighbours. A per-frame Hampel filter is deliberately not used: a w×w window deletes every target smaller than ⌈w²/2⌉ px, which on an 80×62 array means every distant target.

    Spatial matched filter (spatial_sigma_px, off by default). A Gaussian kernel g scales white-noise variance by exactly (Σg_i²)². It correlates neighbouring cells, which makes the CFAR threshold approximate. That is why it is off by default.

    3. Detection: CA-CFAR¶

    For each pixel under test (CUT), the background mean and std are estimated from N = (2R+1)² − (2G+1)² training cells around a guard band. The guard band keeps the target out of its own statistics. If the training cells and the CUT are i.i.d. Gaussian under H0, (y − μ̂)/(ŝ√(1+1/N)) follows a Student-t distribution with N−1 degrees of freedom, so

    detect  ⇔  y − μ̂ > k · max(ŝ, σ_floor),    k = t⁻¹_{N−1}(1 − P_fa) · √(1 + 1/N)

    gives a per-pixel false-alarm probability of exactly P_fa, whatever the background level. σ_floor = σ̂_n·√r is the filtered sensor noise, and it can only lower the rate. With the defaults (R = 5, G = 2, N = 96, P_fa = 1e-4), k = 3.89, compared with 3.72 when the statistics are known (4.6 % CFAR loss). The test measures the empirical per-pixel rate on Gaussian frames and checks it against a binomial 4σ band.

    Detect on the filtered frame, measure on the raw frame. The temporal filter raises the SNR for the detection decision. Its output noise, however, is AR(1) in time with correlation 1−α. Centroids taken from it would feed coloured noise to the Kalman filter and make it over-confident; in SIL this showed up as gate misses and duplicate tracks. The blob found on the filtered frame therefore only picks the window. The centroid is measured on the raw frame, whose noise is white in time, and the Kalman filter does the temporal smoothing optimally itself.

    Centroid and its covariance. The window W is the blob's bounding box grown by G. It is fixed once chosen, so the estimate is a smooth function of the data and the delta method applies. The weights are w_i = y_i − b_i, where b is a least-squares plane fitted to the undetected pixels around W; the plane is exact for any linear background. Then:

    u_c = Σ u_i w_i / Σ w_i
Var(u_c)      = s² Σ (u_i − u_c)²          / (Σ w_i)²
Cov(u_c, v_c) = s² Σ (u_i − u_c)(v_i − v_c) / (Σ w_i)²
s² = RSS_plane / (n − 3)            (unbiased residual variance, floored by σ̂_n²)

    Point-sampling a Gaussian PSF of std p adds a bias that depends on the sub-pixel phase ("pixel locking"). Poisson summation gives its first harmonic, −4πp² e^{−2π²p²} sin 2πx, which adds b²/2 per axis, capped at 1/12 px². Numerically this matches within 2 % for p ≥ 0.4 px.

    Two validity guards apply. Blobs whose window touches the image border are dropped, because truncation biases the centroid by up to about 0.8 of the target radius. When Σw < 3 s √|W|, the ratio is ill-conditioned; the thresholded blob centroid is then used with the distribution-free bound Var = width²/12.

    Measured detection NEES, e^T R^{-1} e against ground truth, with one target and noise from 0.1 to 0.3 K: 1.9–2.1 (χ²₂ mean = 2).

    4. Estimation: constant-velocity Kalman filter¶

    State x = [u, v, u̇, v̇]. Discrete white-noise acceleration (Bar-Shalom et al. §6.3.2):

    F = [[I, T·I], [0, I]],   G = [T²/2 · I; T · I],   Q = σ_a² G Gᵀ,   H = [I 0]

    The rule 0.5 a_max ≤ σ_a ≤ a_max sets σ_a. In the image plane, a_max includes ego-motion f·ω̇: an 80 px, 45° lens (f = 96.6 px) with 0.2 rad/s² platform yaw acceleration gives 19 px/s², hence the default of 20.

    • Observability. O = [H; HF] = [[I, 0], [I, T·I]] has rank 4 for any T > 0. The unit test checks rank 4 at T = 1e-3, 0.04 and 1 s.
    • Update. The Joseph form P = (I−KH)P(I−KH)ᵀ + KRKᵀ keeps P symmetric positive definite for any gain. The test runs 500 updates with R spanning 1e-8 to 1e2.
    • Consistency. In a Monte Carlo run of the true model, mean NEES and NIS fall inside the 99 % χ² bands (4 and 2 dof).

    5. Association: likelihood-ratio GNN¶

    For track i and detection j, compare "j is i" with "i was missed and j is clutter or a new target" (density β per px²):

    c_ij = d²_ij + ln|2π S_ij| − κ,     κ = 2 ln( P_D / (β (1 − P_D P_G)) ),    d² = νᵀS⁻¹ν

    An unassigned track or detection costs 0, so a pair is used only if c_ij < 0. The ln|2πS| term matters. With Mahalanobis distance alone, a vague detection (huge S) looks close to every track; in SIL it stole assignments. The gate d² ≤ χ²₂⁻¹(P_G) only speeds up the search, and the likelihood ratio makes the decision. The global optimum is found exactly as a square assignment problem on the augmented (n+m)×(m+n) matrix (Kuhn 1955; Crouse 2016, the scipy.optimize.linear_sum_assignment algorithm). The unit test checks the result against brute-force enumeration on 300 random problems.

    6. Track management¶

    • Confirmation. M of N hits (default 3 of 5). A tentative track is dropped once M can no longer be reached.
    • Deletion. A track is deleted after max_misses consecutive misses, or when its 1σ position error exceeds max_position_std_px, at which point the gate is meaningless.
    • No duplicates. An unassigned detection inside a confirmed track's gate does not start a new track. It is almost certainly a second return from that target.
    • Time. Δt comes from stamps. A scan older than the last one is rejected. A backward jump larger than max_backward_jump_s (bag loop, simulator reset) resets the tracker.

    7. Run-time consistency monitor¶

    The mean NIS over the last K confirmed updates satisfies K·ε̄ ~ χ²(2K). /diagnostics reports ε̄ with its 95 % band [χ²⁻¹(0.025), χ²⁻¹(0.975)]/K (K = 100 gives [1.63, 2.41]). It raises WARN with the direction of the mismatch: over-confident means Q or R is too small, conservative means too large.

    Known limitations¶

    • Unresolved targets. Two targets closer than about 2(G + target radius) px merge into one blob. Identity through such an encounter is not guaranteed, and the merged centroid corrupts the velocity estimate for about 1–2 s afterwards. JPDA or merged-measurement models would handle this; they are not implemented.
    • Gaussian background assumption. Heavy-tailed clutter (sky/foliage edges, sun glint) pushes the real P_fa above design. Detections before M-of-N confirmation are the protection.
    • Static fixed-pattern noise correlates centroid errors in time for slow targets, which pulls the NIS low (seen as 1.65–1.8 at 0.1 K noise). Flat-field (non-uniformity) correction on the camera removes it.
    • No ego-motion compensation. Camera rotation is absorbed by σ_a. With odometry, subtracting f·ω per frame would allow a smaller σ_a.
    • MI48 driver. The driver is the existing mi48_jetson_* module. Its CRC check has not been confirmed on hardware, so CRC failures are counted but not dropped by default (mi48.drop_crc_errors).

    Legacy components¶

    The C++ modules under src/night_vison_owl_*, the scripts/ utilities and the night_vision_owl_enhanced_pipeline / dual_thermal_owl_pipeline launch files are unchanged by this rework. They are built or installed only when their own dependencies are present, and they do not use the pipeline described above.
