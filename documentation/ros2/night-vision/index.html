    Night Vision¶

    Thermal imaging and low-light vision for 24/7 operations.

    🎯 Overview¶

    The Night Vision module provides thermal imaging and enhanced low-light vision capabilities for autonomous navigation and monitoring during nighttime and low-visibility conditions.

    Key Features: - Thermal infrared imaging (8-14μm) - Low-light image enhancement (e-IKONICS) - Image fusion (RGB + Thermal) - Real-time thermal processing - Motion detection in darkness - Thermal anomaly detection - 30+ FPS thermal processing - Object tracking in thermal

    🚀 Quick Start¶

    Installation¶

    # Install dependencies
sudo apt install -y \
    librealsense2 \
    libuvc-dev \
    libopencv-contrib-dev

# Build
cd ~/ros2_ws
colcon build --packages-select jetbot_night_vision
source install/setup.bash

    Running Night Vision¶

    # Launch thermal imaging
ros2 launch jetbot_night_vision night_vision.launch.py

# View thermal feed
ros2 run image_view image_view image:=/thermal/image_raw

# View fused image
ros2 run image_view image_view image:=/thermal/fused_image

    🔧 Configuration¶

    Thermal Camera Parameters¶

    # config/thermal_params.yaml
thermal_processor:
  ros__parameters:
    # Camera setup
    camera_type: "flir_lepton"  # flir_lepton, seek_thermal, android_thermal
    camera_port: "/dev/video0"

    # Image specifications
    thermal_width: 160
    thermal_height: 120
    thermal_fps: 60
    rgb_width: 1280
    rgb_height: 720
    rgb_fps: 30

    # Temperature range
    temp_min: -40  # Celsius
    temp_max: 80
    emissivity: 0.95  # Material property

    # Calibration
    calibration_file: "config/thermal_calibration.yaml"

    # Processing
    enable_radiometric: true
    enable_automatic_gain: true
    agc_enabled: true

    # Output topics
    thermal_image_topic: "/thermal/image_raw"
    thermal_temp_topic: "/thermal/temperature_map"

    Image Enhancement Parameters¶

    # config/enhancement_params.yaml
image_enhancer:
  ros__parameters:
    # Enhancement algorithm
    enhancement_type: "clahe"  # clahe, histogram_eq, adaptive_gamma

    # CLAHE (Contrast Limited Adaptive Histogram Equalization)
    clahe_clip_limit: 2.0
    clahe_tile_size: 8

    # Histogram equalization
    histogram_bins: 256

    # Adaptive gamma correction
    gamma_adaptive: true
    gamma_value: 1.5

    # Denoising
    denoise_enabled: true
    denoise_strength: 10

    # Output
    enhanced_image_topic: "/enhanced/image_raw"

    🌡️ Thermal Imaging Basics¶

    Temperature Measurement¶

    Thermal Radiation:
  Planck's Law: L(λ,T) = (2hc²/λ⁵) / [exp(hc/λkT) - 1]

  Stefan-Boltzmann: P = εσAT⁴
    ε = Emissivity (0.95 for most objects)
    σ = Stefan-Boltzmann constant
    A = Surface area
    T = Absolute temperature (K)

  Radiometric Accuracy:
    - Typical: ±2°C over -40 to +80°C range
    - After calibration: ±1°C possible
    - Depends on emissivity accuracy

    Colormap Selection¶

    Available Colormaps:
  Grayscale: Intensity only
    - Use case: Precision temperature analysis
    - Advantage: No color distortion

  Jet (Hot to Cold): Red-Yellow-Cyan-Blue
    - Use case: Intuitive temperature visualization
    - Advantage: Good color contrast

  Turbo: More perceptually uniform
    - Use case: Scientific visualization
    - Advantage: Better for colorblind viewers

  Ironblack: Black-Red-Yellow-White
    - Use case: Industrial inspection
    - Advantage: High contrast, natural feel

    🖼️ Image Fusion Techniques¶

    Weighted Blending¶

    // Simple alpha blending
fused = alpha * rgb + (1 - alpha) * thermal;

// Adaptive blending based on thermal contrast
float thermal_contrast = computeContrast(thermal_image);
alpha = 0.5 + 0.3 * (thermal_contrast - 0.5);
fused = alpha * rgb + (1 - alpha) * thermal;

    Laplacian Pyramid Fusion¶

    Process:
  1. Create Laplacian pyramids for both images
  2. At each scale: Select regions from higher-contrast image
  3. Reconstruct from fused pyramids

Advantages:
  - Preserves detail from both images
  - Natural-looking fusion
  - Good for object detection

Disadvantages:
  - Higher computational cost
  - Requires careful weight selection

    Guided Filter Fusion¶

    Process:
  1. Use RGB as guidance image
  2. Filter thermal data through RGB structure
  3. Enhance edges from thermal where RGB is uncertain

Advantages:
  - Respects object boundaries
  - Good edge preservation
  - Efficient computation

    🚨 Thermal Anomaly Detection¶

    Hot Spot Detection¶

    // Find regions hotter than surrounding area
std::vector<HotSpot> hotspots;

for (int y = 1; y < height - 1; y++) {
    for (int x = 1; x < width - 1; x++) {
        float center = thermal_data[y][x];
        float avg_neighbor = (thermal_data[y-1][x] + 
                             thermal_data[y+1][x] +
                             thermal_data[y][x-1] +
                             thermal_data[y][x+1]) / 4.0;

        if (center - avg_neighbor > TEMP_THRESHOLD) {
            hotspots.push_back({x, y, center});
        }
    }
}

    Cold Spot Detection¶

    // Opposite of hot spot detection
// Useful for detecting failures in heated systems
if (center - avg_neighbor < -TEMP_THRESHOLD) {
    coldspots.push_back({x, y, center});
}

    Temperature Gradient Analysis¶

    Gradient-based Features:
  - Rising edge: Sharp increase in temperature
  - Falling edge: Sharp decrease in temperature
  - Plateau: Constant temperature region
  - Boundary: Transition between different materials

Applications:
  - Electrical fault detection (high gradient at faults)
  - Surface defect detection
  - Material identification
  - Weld quality assessment

    🌙 Night Vision Modes¶

    Mode 1: Enhanced Low-Light¶

    For: Moonlit nights, street lighting
Algorithm:
  - Sensor gain: Maximum
  - Exposure time: 30-100ms
  - ISO: 1600-3200
  - Enhancement: CLAHE with high clip limit

Output: Visible light image with enhanced contrast
Performance: 30 FPS, detail preserved

    Mode 2: Thermal Only¶

    For: Complete darkness
Algorithm:
  - Thermal imaging only
  - Temperature range: -20 to +60°C
  - Colormap: Jet or Turbo

Output: Thermal false-color image
Performance: 60 FPS, no RGB needed

    Mode 3: Fused Vision¶

    For: Mixed lighting conditions
Algorithm:
  - RGB when available
  - Thermal for depth information
  - Laplacian pyramid fusion

Output: Combined RGB + Thermal image
Performance: 25 FPS, best detail

    🔍 Troubleshooting¶

    Thermal Image Distorted¶

    Causes: - Lens misalignment - Dirt on lens - Temperature out of range

    Solutions: - Clean lens gently - Recalibrate thermal camera - Verify operating temperature range

    Fusion Registration Error¶

    Causes: - RGB and thermal sensors not aligned - Different image resolutions

    Solutions: - Perform geometric calibration - Use fisheye correction - Re-estimate alignment matrix

    Low Detection Range¶

    Causes: - Thermal resolution too low - Object temperature too close to background - Attenuation by rain/fog

    Solutions: - Improve sensor orientation - Enhance image contrast - Use longer wavelength thermal (LWIR)
