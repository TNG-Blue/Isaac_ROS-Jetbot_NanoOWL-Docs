    ROS 2 Node Diagrams¶

    One diagram per ROS 2 node, drawn like the system overview: what the node subscribes to and serves (left) and what it publishes and calls (right), with the nodes and devices at the other end of every topic, its package, its Kubernetes pod and — in red — every closed loop it is part of. The wiring is read from the System Node Graph, so both always agree; the processing inside each node is drawn in its package README (Node flowcharts).

    70 diagrams. Regenerate after changing the System Node Graph or the Helm values:

    python3 Scripts/diagrams/node_diagrams.py
