    Microcontroller Integration¶

    ARM Cortex-M7 microcontroller for real-time I/O and low-level control.

    🎯 Overview¶

    The Microcontroller Integration module provides real-time low-level control and I/O interfacing through an ARM Cortex-M7 MCU, enabling precise sensor reading and actuator control.

    Key Features: - ARM Cortex-M7 (600 MHz) processor - Real-time operating system (RTOS) support - Analog/digital I/O (16 ADC channels, 12 DAC channels) - PWM generation (6+ independent PWM outputs) - CAN bus interface (2x) - I2C/SPI communication - Interrupt-driven real-time control - Wireless bootloader support - 256KB RAM, 512KB Flash

    🚀 Quick Start¶

    Installation¶

    Bash
    # Install dependencies
sudo apt install -y \
    stm32cubeprogrammer \
    stm32flash \
    minicom \
    arm-none-eabi-gcc

# Build ROS2 interface
cd ~/ros2_ws
colcon build --packages-select jetbot_microcontroller
source install/setup.bash

    Flashing Firmware¶

    Bash
    # Build firmware
cd jetbot_microcontroller/firmware
mkdir build && cd build
cmake -DCMAKE_TOOLCHAIN_FILE=../cmake/stm32f7.cmake ..
make -j4

# Flash to MCU (STM32F767)
st-flash write firmware.elf

# Or using STM32CubeProgrammer
STM32_Programmer_CLI -c port=COM3 -w firmware.elf

    Running MCU Interface¶

    Bash
    # Launch ROS2 interface
ros2 launch jetbot_microcontroller microcontroller.launch.py

# Read ADC values
ros2 topic echo /mcu/adc_values

# Set PWM
ros2 service call /mcu/pwm_set jetbot_interfaces/PWMCommand "{channel: 0, duty: 128}"

    🔧 Configuration¶

    MCU Configuration¶

    YAML
    # config/mcu_config.yaml
mcu_interface:
  ros__parameters:
    # Serial communication
    port: "/dev/ttyUSB0"
    baudrate: 921600
    timeout: 1.0  # seconds

    # Protocol
    protocol_version: 1
    checksum_type: "crc32"

    # Update rates
    adc_update_rate: 100  # Hz
    pwm_update_rate: 500  # Hz
    can_update_rate: 100  # Hz
    gpio_update_rate: 10  # Hz

    # Watchdog
    enable_watchdog: true
    watchdog_timeout: 2  # seconds

    # Motor configuration
    motor_channels: [0, 1]  # PWM channels for motors
    motor_frequency: 1000  # Hz
    motor_resolution: 255  # 8-bit

    # Servo configuration
    servo_channels: [2, 3, 4, 5]  # PWM channels for servos
    servo_frequency: 50  # Hz (standard servo)

    # ADC channels
    adc_channels:
      battery_voltage: 0
      current_sense: 1
      temperature: 2
      light_sensor: 3

    # Output
    publish_diagnostics: true
    diagnostics_frequency: 1  # Hz

    Real-time Task Scheduling¶

    YAML
    FreeRTOS Tasks:

Task 1: ADC Reading
  Priority: High (3)
  Frequency: 100 Hz (10ms period)
  Duration: <2ms
  Function: Read all ADC channels, publish data

Task 2: PWM Control
  Priority: High (3)
  Frequency: 500 Hz (2ms period)
  Duration: <1ms
  Function: Update PWM duty cycles

Task 3: CAN Communication
  Priority: Medium (2)
  Frequency: 100 Hz (10ms period)
  Duration: <3ms
  Function: Send/receive CAN messages

Task 4: UART Communication
  Priority: Medium (2)
  Frequency: Event-driven
  Duration: <5ms
  Function: Serialize/deserialize messages to Jetson

Task 5: Watchdog
  Priority: Low (1)
  Frequency: 10 Hz (100ms period)
  Duration: <1ms
  Function: Monitor system health, kick watchdog

Idle Task:
  Sleep state, lowest power

    📊 Capabilities¶

    ADC (Analog-to-Digital Converter)¶

    YAML
    Specifications:
  Resolution: 12-bit (0-4095 digital units)
  Channels: 16 multiplexed
  Sampling: Up to 100 kHz per channel
  Reference: Internal 3.3V
  Input Range: 0 - 3.3V
  Accuracy: ±1 LSB typical (±0.8mV)

Connected Sensors:
  Channel 0: Battery Voltage (via divider)
    Range: 0-12V (attenuated to 0-3.3V)
    Scaling: ADC_value * 12 / 4095

  Channel 1: Current Sense (via INA219)
    Range: ±3.2A
    Scaling: Via I2C interface

  Channel 2: Temperature (NTC thermistor)
    Range: -40 to +85°C
    Scaling: Steinhart-Hart equation

  Channel 3: Light Sensor (LDR)
    Range: 0-100kΩ
    Scaling: Logarithmic response

    PWM (Pulse Width Modulation)¶

    YAML
    Specifications:
  Channels: 6 independent outputs
  Frequency: Programmable 1 Hz - 1 MHz
  Resolution: 8-16 bit (software programmable)
  Duty Cycle: 0-100%
  Output Voltage: 3.3V (logic level)
  Output Current: 25mA per pin

Motor Control:
  Channel 0: Left Motor (1kHz, 8-bit)
  Channel 1: Right Motor (1kHz, 8-bit)

  Servo Control:
  Channel 2: Pan Servo (50Hz, 16-bit)
    Pulse Width: 1000μs (0°) - 2000μs (180°)

  Channel 3: Tilt Servo (50Hz, 16-bit)
  Channel 4: Gripper Servo (50Hz, 16-bit)
  Channel 5: Lift Servo (50Hz, 16-bit)

    CAN Bus Interface¶

    YAML
    Specifications:
  Protocol: CAN 2.0B
  Bitrate: 250 kbps, 500 kbps, 1 Mbps
  Interfaces: 2x CAN ports
  Max Devices: 127 nodes per bus

CAN Node ID Assignment:
  0x100: Motor Controller 1
  0x101: Motor Controller 2
  0x110: IMU Sensor
  0x111: Temperature Sensor
  0x120: Battery Monitor
  0x130: Diagnostics

Message Format:
  Standard ID (11-bit)
  Data Length: 0-8 bytes
  Priority: Via arbitration ID

Example Message:
  ID: 0x120 (Battery Monitor)
  Data: [V_high, V_low, I_high, I_low, T, ...]
  Frequency: 10 Hz

    Serial Communication with Jetson¶

    YAML
    Protocol: Custom binary protocol

Frame Format:
  Header: 0xAA 0xBB (2 bytes)
  Length: uint16 (2 bytes)
  Command: uint8 (1 byte)
  Payload: variable length
  Checksum: CRC32 (4 bytes)
  Footer: 0xCC 0xDD (2 bytes)

Baudrate: 921600 (High-speed)
Timeout: 100ms (watchdog timeout)
Max Retries: 3

Commands:
  0x01: Read ADC
  0x02: Set PWM
  0x03: GPIO Control
  0x04: CAN Send
  0x05: System Status
  0x06: Calibration
  ...

    💻 Firmware Development¶

    Building Firmware¶

    Bash
    # Navigate to firmware directory
cd firmware

# Create build directory
mkdir build && cd build

# Configure with STM32F7 toolchain
cmake -DCMAKE_TOOLCHAIN_FILE=../cmake/stm32f7.cmake \
      -DCMAKE_BUILD_TYPE=Release ..

# Build
make -j4

# Firmware size
arm-none-eabi-size firmware.elf

    Main Loop Structure¶

    C
    // Simplified firmware main loop
int main(void) {
    HAL_Init();
    SystemClock_Config();
    MX_GPIO_Init();
    MX_ADC_Init();
    MX_TIM_PWM_Init();
    MX_UART_Init();

    // Initialize RTOS
    osKernelInitialize();

    // Create tasks
    osThreadNew(task_adc_read, NULL, NULL);
    osThreadNew(task_pwm_control, NULL, NULL);
    osThreadNew(task_uart_comm, NULL, NULL);
    osThreadNew(task_watchdog, NULL, NULL);

    // Start scheduler
    osKernelStart();

    while(1) {
        // RTOS scheduler handles everything
    }
}

// ADC reading task
void task_adc_read(void *args) {
    TickType_t xLastWakeTime = osKernelGetTickCount();

    while(1) {
        // Read all ADC channels
        uint16_t adc_values[16];
        for(int i = 0; i < 16; i++) {
            HAL_ADC_Start(&hadc);
            HAL_ADC_PollForConversion(&hadc, 100);
            adc_values[i] = HAL_ADC_GetValue(&hadc);
        }

        // Send to Jetson
        send_adc_data(adc_values);

        // Wait for next period (10ms)
        osDelayUntil(&xLastWakeTime, 10);
    }
}

    🎮 ROS2 Interface¶

    Subscribed Topics¶

    YAML
    /mcu/pwm_command:
  type: jetbot_interfaces/PWMCommand
  description: Set PWM duty cycle

/mcu/gpio_command:
  type: jetbot_interfaces/GPIOCommand
  description: GPIO output control

/mcu/can_send:
  type: jetbot_interfaces/CANMessage
  description: Send CAN message

    Published Topics¶

    YAML
    /mcu/adc_values:
  type: jetbot_interfaces/ADCReadings
  description: All ADC channel values

/mcu/system_status:
  type: jetbot_interfaces/MCUStatus
  description: MCU health and diagnostics

/mcu/gpio_state:
  type: sensor_msgs/Joy
  description: GPIO input states

/mcu/can_receive:
  type: jetbot_interfaces/CANMessage
  description: Received CAN messages

    Services¶

    YAML
    /mcu/calibrate_adc:
  type: std_srvs/Empty
  description: Calibrate ADC readings

/mcu/firmware_update:
  type: jetbot_interfaces/FirmwareUpdate
  description: Update MCU firmware

/mcu/reset:
  type: std_srvs/Empty
  description: Reset microcontroller

    🔍 Debugging¶

    Serial Monitor¶

    Bash
    # Monitor serial communication
minicom -D /dev/ttyUSB0 -b 921600

# Or with picocom
picocom -b 921600 /dev/ttyUSB0

# Log to file
cat /dev/ttyUSB0 > serial_debug.log &

    JTAG Debugging¶

    Bash
    # With STM32 ST-LINK
openocd -f interface/stlink-v2.cfg -f target/stm32f7x.cfg

# In another terminal
arm-none-eabi-gdb firmware.elf
(gdb) target extended-remote :3333
(gdb) load
(gdb) break main
(gdb) continue
