    🚀 Quick Start¶

    Launch Full System¶

    # Clone repository
git clone <repo-url>
cd Isaac_ROS-Jetbot_NanoOWL/ROS

# Build packages
colcon build --symlink-install

# Source workspace
source install/setup.bash

# Launch robot
ros2 launch jetbot_bringup main.launch.py

    Launch Specific Module¶

    ros2 launch jetbot_detection detection.launch.py

    ros2 launch jetbot_slam slam.launch.py

    ros2 launch jetbot_control control.launch.py

    📊 Topic Map¶

    Sensor Topics¶

    Input Streams:
  /camera/image_raw          # Camera frames (30 Hz)
  /camera/camera_info        # Camera calibration
  /imu/data                  # Inertial measurement (200 Hz)
  /imu/mag                   # Magnetometer (50 Hz)
  /gps/fix                   # GPS position (1 Hz)
  /lidar/scan                # LIDAR scan (10 Hz)

    Processing Topics¶

    Detection:
  /detection/objects         # Detected objects
  /detection/annotated_image # Visualization

SLAM:
  /slam/pose                 # Robot pose
  /slam/map                  # Occupancy grid
  /slam/landmarks            # Visual landmarks

Fusion:
  /sensors/fused_state       # Fused pose & velocity
  /odom/integrated           # Integrated odometry

    Control Topics¶

    Command Input:
  /cmd_vel                   # Velocity command
  /cmd_vel_safe              # Safety-checked command

Feedback:
  /motor/state               # Motor velocity & current
  /joint_states              # Joint feedback
  /odometry                  # Wheel odometry

    🔧 Configuration¶

    Main Configuration File¶

    # config/jetbot_config.yaml

robot:
  name: jetbot_nanoowl
  type: differential_drive

detection:
  enabled: true
  model: yolov8_nano
  confidence: 0.5
  device: cuda

slam:
  enabled: true
  type: visual_inertial

control:
  drive_type: differential
  max_linear_velocity: 1.0
  max_angular_velocity: 2.0

    Node Configuration¶

    # Launch with custom parameters
ros2 launch jetbot_detection detection.launch.py \
  confidence:=0.6 \
  model:=yolov8_small \
  device:=cuda

    🔍 Troubleshooting¶

    Common Issues¶

    Problem Solution
    Nodes not connecting Check ROS domain ID, firewall
    High latency Monitor CPU/GPU usage, check network
    Detection errors Verify model files, check GPU memory
    SLAM map empty Check camera calibration, features

    Debug Commands¶

    # List all nodes
ros2 node list

# Check node info
ros2 node info /detection_node

# Monitor topics
ros2 topic echo /detection/objects

# View system graph
rqt_graph

# Check performance
ros2 topic hz /detection/objects
