    Control System¶

    Motor control, servo management, and actuation system.

    🎯 Overview¶

    The Control System module provides real-time motor control, servo management, and actuation for the Isaac ROS Jetbot NanoOWL platform.

    Key Features: - Dual DC motor PWM control (0-100%) - Servo control with pulse width modulation (0.5-2.5ms) - PID velocity tracking (linear and angular) - Odometry feedback integration - Emergency stop safety mechanism - Motor current monitoring - Acceleration/deceleration profiles - Multi-motor coordination

    🚀 Quick Start¶

    Installation¶

    Bash
    # Install dependencies
sudo apt install -y \
    ros-humble-geometry2 \
    ros-humble-std-msgs \
    python3-gpiozero

# Build
cd ~/ros2_ws
colcon build --packages-select jetbot_control
source install/setup.bash

    Running Control¶

    Bash
    # Launch control system
ros2 launch jetbot_control control.launch.py

# Test motors
ros2 service call /motor_control jetbot_interfaces/srv/MotorCommand "{left_speed: 0.5, right_speed: 0.5}"

# Set servo angle
ros2 service call /servo_control jetbot_interfaces/srv/ServoCommand "{channel: 0, angle: 90.0}"

    🔧 Configuration¶

    Motor Control Parameters¶

    YAML
    # config/motor_config.yaml
motor_controller:
  ros__parameters:
    # Motor specifications
    left_motor_pin: 17
    right_motor_pin: 27
    left_pwm_pin: 12
    right_pwm_pin: 13

    # Motor characteristics
    max_speed: 1.0  # m/s
    motor_constants:
      kp: 0.5
      ki: 0.1
      kd: 0.05
      max_integral: 1.0

    # Speed control
    acceleration_limit: 2.0  # m/s²
    deceleration_limit: 3.0  # m/s²

    # Feedback
    enable_odometry_feedback: true
    odometry_topic: "/odom"

    # Safety
    max_current: 2.0  # Amperes
    emergency_stop_timeout: 0.5  # seconds

    # PWM
    pwm_frequency: 1000  # Hz
    pwm_range: [0, 255]

    Servo Control Parameters¶

    YAML
    # config/servo_config.yaml
servo_controller:
  ros__parameters:
    # Servo channels (I2C based)
    i2c_bus: 1
    i2c_address: 0x40

    # Servo specifications
    num_servos: 4
    servos:

        name: "pan"
        min_angle: -90
        max_angle: 90
        min_pulse: 0.5   # milliseconds
        max_pulse: 2.5
        center_pulse: 1.5

      - id: 1
        name: "tilt"
        min_angle: -45
        max_angle: 45
        min_pulse: 0.5
        max_pulse: 2.5
        center_pulse: 1.5

      - id: 2
        name: "gripper"
        min_angle: 0
        max_angle: 180
        min_pulse: 0.5
        max_pulse: 2.5
        center_pulse: 1.5

      - id: 3
        name: "lift"
        min_angle: 0
        max_angle: 90
        min_pulse: 0.5
        max_pulse: 2.5
        center_pulse: 1.5

    # Frequency
    pwm_frequency: 50  # Hz (standard servo frequency)

    # Speed profile
    speed_limit: 60  # degrees per second

    PID Controller Tuning¶

    YAML
    # Velocity controller
velocity_pid:
  kp: 0.8
  ki: 0.2
  kd: 0.1
  max_integral: 1.0
  setpoint_tolerance: 0.05

# Angular velocity controller
angular_pid:
  kp: 1.0
  ki: 0.15
  kd: 0.08
  max_integral: 1.0
  setpoint_tolerance: 0.02

# Position controller (servos)
position_pid:
  kp: 2.0
  ki: 0.1
  kd: 0.5
  max_integral: 0.5
  setpoint_tolerance: 0.5  # degrees

    🎮 Motor Control¶

    Direct Motor Control¶

    C++
    // Simple motor command
motor_controller->setMotorSpeed(
    MotorID::LEFT,
    0.7  // 70% power
);

motor_controller->setMotorSpeed(
    MotorID::RIGHT,
    0.7
);

    Velocity Control with Feedback¶

    C++
    // Set desired velocity
geometry_msgs::msg::Twist cmd_vel;
cmd_vel.linear.x = 0.5;   // m/s
cmd_vel.angular.z = 0.2;  // rad/s

// PID controller adjusts motor speeds
motor_controller->setVelocity(cmd_vel);

// Get odometry feedback
nav_msgs::msg::Odometry odom = motor_controller->getOdometry();

    Trajectory Tracking¶

    C++
    // Follow a path with velocity profiles
std::vector<geometry_msgs::msg::Pose> path;
// ... populate path ...

motor_controller->followPath(
    path,
    target_velocity = 0.5,  // m/s
    max_acceleration = 1.0, // m/s²
    lookahead_distance = 0.2 // meters
);

    🛡️ Safety Features¶

    Emergency Stop¶

    C++
    // Activate emergency stop
motor_controller->emergencyStop();

// Motor speeds go to zero
// Safety timeout prevents runaway
// Requires manual reset to continue

    Current Limiting¶

    YAML
    Safety Thresholds:
  - Stall current: > 2.0A (motor blocked)
  - Thermal limit: > 50°C (reduce power)
  - Voltage limit: < 7.2V (low battery)

Response:
  - Stall detected → Reduce speed
  - Thermal: Pause for 10 seconds
  - Low voltage: Trigger warning, reduce max speed

    Acceleration Limits¶

    C++
    // Smooth acceleration prevents motor strain
motion_profile.setAccelerationLimit(2.0);  // m/s²
motion_profile.setDecelerationLimit(3.0);  // m/s²

// Ramp velocity gradually
motor_controller->setVelocityWithProfile(target_velocity);

    📊 ROS2 Topics and Services¶

    Published Topics¶

    YAML
    /motor/odom:
  type: nav_msgs/Odometry
  description: Motor odometry (position and velocity)

/motor/current:
  type: std_msgs/Float32
  description: Motor current draw (Amperes)

/servo/state:
  type: sensor_msgs/JointState
  description: All servo positions and velocities

/system/battery:
  type: std_msgs/Float32
  description: Battery voltage

    Subscribed Topics¶

    YAML
    /cmd_vel:
  type: geometry_msgs/Twist
  description: Velocity commands (linear and angular)

/servo/command:
  type: trajectory_msgs/JointTrajectory
  description: Servo position commands

    Services¶

    YAML
    /motor_reset:
  type: std_srvs/Empty
  description: Reset motor controller

/emergency_stop:
  type: std_srvs/Empty
  description: Trigger emergency stop

/get_motor_status:
  type: jetbot_interfaces/GetMotorStatus
  description: Query motor state

/set_servo_angle:
  type: jetbot_interfaces/SetServoAngle
  description: Set servo to specific angle

    🔍 Troubleshooting¶

    Motors Not Moving¶

    Check: - Power supply connected and sufficient voltage - PWM pins configured correctly - Motor driver IC enabled - Safety limits not triggered

    Test:

    Bash
    # Direct PWM test
gpio -g pwm 12 128  # 50% duty cycle

    Unsmooth Motion¶

    Solutions: - Tune PID gains (start with lower kp, increase gradually) - Check encoder connections - Verify motor power supply stability - Reduce acceleration limits temporarily

    Servo Jitter¶

    Solutions: - Verify servo signal line shielding - Check PWM frequency (50Hz for servos) - Increase servo power supply capacity - Reduce number of servos updated simultaneously
