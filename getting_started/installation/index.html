        Software Installation¶

        This guide will walk you through installing all necessary software components for the Isaac ROS Jetbot NanoOWL platform.

        Installation Overview

        The installation process involves setting up software on both the host PC and the Jetson Orin Nano Super devices. Total installation time: 2-3 hours.

        Troubleshooting¶

        Common Installation Issues ### Docker Permission Denied
        Bash
        1
2
3
        # Solution: Add user to docker group and restart
sudo usermod -aG docker $USER
newgrp docker
        ### CUDA Not Found in Container
        Bash
        1
2
3
        # Solution: Verify NVIDIA container toolkit
sudo nvidia-ctk runtime configure --runtime=docker
sudo systemctl restart docker
        ### Jetson Out of Memory
        Bash
        1
2
3
4
5
6
        # Solution: Increase swap space
sudo fallocate -l 8G /swapfile
sudo chmod 600 /swapfile
sudo mkswap /swapfile
sudo swapon /swapfile
echo '/swapfile none swap sw 0 0' | sudo tee -a /etc/fstab
        ### Portenta H7 Not Detected
        Bash
        1
2
3
        # Solution: Check USB permissions and drivers
sudo usermod -aG dialout $USER
sudo udevadm control --reload-rules
