### 🔧 **Hardware Components**

#### 🖥️ **Core Computing**
- **2× Jetson Orin Nano Super** (8GB) - Primary AI processing units
- **2× MicroSD Cards** (64GB+, Class 10) - System storage
- **2× Power Adapters** (19V/65W USB-C PD) - Dedicated power per Jetson
- **Ethernet Switch** (5-port Gigabit) - Network connectivity

#### 🎛️ **Control & Actuation**
- **1× Arduino Portenta H7** - Real-time microcontroller
- **1× Portenta Breakout Board** - GPIO and interface expansion
- **6× BLDC Motors** with integrated encoders - Precise actuation
- **1× Motor Controller** (6-channel, CAN interface) - Motor driver
- **1× Emergency Stop Button** (NC contact, 10A) - Safety system

#### ⚡ **Power & Distribution**
- **24V/500W Power Supply** - Main system power
- **Power Distribution Board** - Multi-rail power management
- **DC-DC Converters** (19V, 12V, 5V, 3.3V) - Voltage regulation
- **Power Cables & Connectors** - Professional wiring harness

#### 👁️ **Sensors & Perception**
- **2× Intel RealSense D435i** - RGB-D cameras with IMU
- **1× IMU Module** (9-DOF) - Additional inertial sensing
- **2× USB 3.0 Hubs** (4-port, powered) - Camera connectivity
- **LiDAR** (optional) - Enhanced mapping and obstacle detection

### 📚 **Knowledge Prerequisites**

#### 🟢 **Beginner Level**
- **🐧 Linux basics**: Command line, file system navigation
- **🐍 Python fundamentals**: Basic syntax and concepts
- **🔌 Electronics safety**: Power management, ESD protection
- **🔧 Mechanical assembly**: Using tools, following diagrams

#### 🟡 **Intermediate Level**
- **🤖 ROS 2 concepts**: Nodes, topics, services, parameters
- **🐳 Docker basics**: Containers, images, volumes
- **🔧 Git workflow**: Version control, branching, collaboration
- **📊 Debugging skills**: Log analysis, troubleshooting

#### 🟠 **Advanced Level**
- **☸️ Kubernetes**: Container orchestration, deployments
- **🧠 Computer vision**: Image processing, deep learning
- **📡 Networking**: TCP/IP, CAN bus, real-time communication
- **⚙️ Control systems**: PID controllers, kinematics

        🛡️ Safety Guidelines¶

        ⚠️ Critical Safety Information

        Read this section completely before starting any work!

        ⚡ Electrical Safety¶

        • Power Off: Always disconnect power before making connections
        • ESD Protection: Use anti-static wrist straps when handling electronics
        • Voltage Verification: Double-check all voltage levels with multimeter
        • Emergency Stop: Ensure accessible emergency cutoffs at all times
        • Fire Safety: Keep appropriate fire extinguisher nearby

        🔧 Mechanical Safety¶

        • Tool Inspection: Check tools for damage before use
        • Torque Specs: Follow manufacturer specifications for critical joints
        • Moving Parts: Keep fingers clear of motors and actuators
        • Weight Limits: Respect payload and structural limitations
        • Workspace: Maintain clean, organized work environment

        🖥️ Cyber Security¶

        • Network Isolation: Use dedicated networks for development
        • Access Control: Implement proper authentication mechanisms
        • Data Protection: Secure sensitive configuration files
        • Update Management: Keep all software components updated
        • Monitoring: Log and monitor all system activities
