    Monitoring & Maintenance¶

    Keep your production system running smoothly with comprehensive monitoring and maintenance.

    🎯 Learning Objectives¶

    By the end of this tutorial, you will: - ✅ Setup system monitoring dashboards - ✅ Configure alerts and notifications - ✅ Perform routine maintenance - ✅ Troubleshoot common issues - ✅ Document system health

    Estimated Time: 1.5 hours
    Difficulty Level: Professional
    Prerequisites: OTA Integration completed

    📊 Step 1: Monitoring Infrastructure¶

    1.1 Install Monitoring Stack¶

    Bash
    # Install monitoring tools
sudo apt install -y prometheus grafana-server telegraf

# Start services
sudo systemctl start prometheus
sudo systemctl start grafana-server
sudo systemctl start telegraf

# Enable on boot
sudo systemctl enable prometheus
sudo systemctl enable grafana-server
sudo systemctl enable telegraf

    1.2 Configure Prometheus¶

    Bash
    # Edit Prometheus config
sudo nano /etc/prometheus/prometheus.yml

# Add Jetbot job:
cat >> /etc/prometheus/prometheus.yml << 'EOF'

  - job_name: 'jetbot'
    scrape_interval: 15s
    static_configs:
      - targets: ['localhost:9100', 'localhost:8080']
EOF

# Restart Prometheus
sudo systemctl restart prometheus

    Bash
    # Access Grafana: http://jetbot.local:3000
# Default: admin/admin

    🚨 Step 2: Alerting System¶

    2.1 Create Alert Rules¶

    Bash
    # Create alert configuration
cat > /etc/prometheus/alerts.yml << 'EOF'
groups:
  - name: jetbot_alerts
    interval: 30s
    rules:
      - alert: HighCPUUsage
        expr: (100 - (avg by (instance) (rate(node_cpu_seconds_total{mode="idle"}[5m])) * 100)) > 80
        for: 5m
        annotations:
          summary: "High CPU usage on {{ $labels.instance }}"

      - alert: HighMemoryUsage
        expr: (node_memory_MemAvailable_bytes / node_memory_MemTotal_bytes) < 0.2
        for: 5m
        annotations:
          summary: "Low available memory on {{ $labels.instance }}"

      - alert: HighDiskUsage
        expr: (node_filesystem_avail_bytes / node_filesystem_size_bytes) < 0.1
        for: 5m
        annotations:
          summary: "Low disk space on {{ $labels.instance }}"

      - alert: HighTemperature
        expr: node_thermal_zone_temp > 80000
        for: 2m
        annotations:
          summary: "High CPU temperature on {{ $labels.instance }}"

      - alert: ROS2NodeDown
        expr: up{job="jetbot"} == 0
        for: 1m
        annotations:
          summary: "ROS2 node down on {{ $labels.instance }}"
EOF

    2.2 Setup Alertmanager¶

    Bash
    # Install Alertmanager
sudo apt install -y prometheus-alertmanager

# Configure notifications
cat > /etc/prometheus/alertmanager.yml << 'EOF'
global:
  resolve_timeout: 5m

route:
  receiver: 'default'
  repeat_interval: 12h

receivers:
  - name: 'default'
    webhook_configs:
      - url: 'http://localhost:5000/alerts'  # Your webhook

    email_configs:
      - to: 'admin@example.com'
        from: 'alerts@example.com'
        smarthost: 'smtp.gmail.com:587'
        auth_username: 'alerts@example.com'
        auth_password: 'password'
EOF

# Start Alertmanager
sudo systemctl start prometheus-alertmanager
sudo systemctl enable prometheus-alertmanager

    📈 Step 3: ROS2 Metrics¶

    3.1 Create ROS2 Metrics Exporter¶

    Bash
    # Create metrics collector
cat > ~/ros2_metrics_exporter.py << 'EOF'
import rclpy
from rclpy.node import Node
from prometheus_client import Counter, Gauge, Histogram, start_http_server
import time

class ROS2MetricsExporter:
    def __init__(self):
        rclpy.init()
        self.node = rclpy.create_node('ros2_metrics_exporter')

        # Start Prometheus HTTP server on port 8080
        start_http_server(8080)

        # Define metrics
        self.cpu_usage = Gauge('ros2_cpu_usage_percent', 'CPU usage percentage')
        self.memory_usage = Gauge('ros2_memory_usage_mb', 'Memory usage in MB')
        self.node_count = Gauge('ros2_node_count', 'Number of active ROS2 nodes')
        self.topic_count = Gauge('ros2_topic_count', 'Number of active topics')
        self.latency = Histogram('ros2_message_latency_ms', 'Message latency in milliseconds')
        self.messages_published = Counter('ros2_messages_published', 'Total messages published')

        # Timer for updates
        self.timer = self.node.create_timer(10.0, self.collect_metrics)

    def collect_metrics(self):
        """Collect ROS2 metrics"""
        import os
        import psutil

        # CPU and memory
        cpu = psutil.cpu_percent(interval=1)
        memory = psutil.virtual_memory().used / (1024**2)

        self.cpu_usage.set(cpu)
        self.memory_usage.set(memory)

        # ROS2 nodes and topics
        try:
            result = os.popen('ros2 node list 2>/dev/null').read()
            nodes = len(result.strip().split('\n'))
            self.node_count.set(nodes)

            result = os.popen('ros2 topic list 2>/dev/null').read()
            topics = len(result.strip().split('\n'))
            self.topic_count.set(topics)
        except:
            pass

def main():
    exporter = ROS2MetricsExporter()
    rclpy.spin(exporter.node)
    rclpy.shutdown()

if __name__ == '__main__':
    main()
EOF

# Run exporter
python3 ~/ros2_metrics_exporter.py &

    🔧 Step 4: Routine Maintenance¶

    4.1 Create Maintenance Script¶

    Bash
    # Create maintenance routine
cat > /usr/local/bin/jetbot-maintenance.sh << 'EOF'
#!/bin/bash

echo "=== Jetbot Maintenance Routine ==="

# 1. Clean temporary files
echo "1. Cleaning temporary files..."
rm -rf ~/.ros/log/*
rm -rf /tmp/jetbot_*
find ~/.cache -type f -mtime +7 -delete

# 2. Update packages
echo "2. Checking for updates..."
apt update
apt list --upgradable

# 3. Disk cleanup
echo "3. Disk cleanup..."
sudo apt autoclean
sudo apt autoremove -y

# 4. Log rotation
echo "4. Rotating logs..."
sudo logrotate -f /etc/logrotate.d/jetbot-ros2

# 5. Database maintenance
echo "5. Checking disk space..."
df -h

# 6. Verify services
echo "6. Verifying services..."
systemctl status jetbot-ros2 --no-pager
systemctl status prometheus --no-pager

# 7. Backup configuration
echo "7. Backing up configuration..."
tar -czf /home/jetbot/backups/config_backup_$(date +%Y%m%d).tar.gz \
  /home/jetbot/ros2_ws/src/*/config/

echo "✓ Maintenance complete"
EOF

chmod +x /usr/local/bin/jetbot-maintenance.sh

# Schedule weekly maintenance
(crontab -l 2>/dev/null; echo "0 2 * * 0 /usr/local/bin/jetbot-maintenance.sh") | crontab -

    4.2 System Backup¶

    Bash
    # Create backup script
cat > /usr/local/bin/jetbot-backup.sh << 'EOF'
#!/bin/bash

BACKUP_DIR="/home/jetbot/backups"
DATE=$(date +%Y%m%d_%H%M%S)

echo "Starting system backup..."

# Backup ROS2 workspace
tar -czf $BACKUP_DIR/ros2_ws_$DATE.tar.gz \
  --exclude='build' --exclude='install' \
  /home/jetbot/ros2_ws/

# Backup configs
tar -czf $BACKUP_DIR/configs_$DATE.tar.gz \
  /home/jetbot/.ros/ \
  /home/jetbot/.config/

# Backup calibrations
tar -czf $BACKUP_DIR/calibrations_$DATE.tar.gz \
  /home/jetbot/camera_calibration* \
  /home/jetbot/imu_calibration*

# Cleanup old backups (keep last 10)
ls -t $BACKUP_DIR/*.tar.gz | tail -n +11 | xargs rm -f

echo "✓ Backup complete: $BACKUP_DIR"
EOF

chmod +x /usr/local/bin/jetbot-backup.sh

# Schedule daily backups
(crontab -l 2>/dev/null; echo "0 3 * * * /usr/local/bin/jetbot-backup.sh") | crontab -

    🐛 Step 5: Troubleshooting Guide¶

    5.1 Common Issues¶

    YAML
    Issue: High CPU Usage (>80%)
  Check:
    ros2 topic bw /camera/image_raw
    ros2 topic hz /camera/image_raw
  Solutions:
    - Reduce processing frequency
    - Optimize algorithms
    - Profile with ros2_tracing

Issue: Memory Leak
  Check:
    free -h
    top -p $(pgrep -f ros2)
  Solutions:
    - Check for circular subscriptions
    - Limit message queue size
    - Restart nodes periodically

Issue: Network Issues
  Check:
    ros2 daemon status
    netstat -an | grep ROS2
  Solutions:
    - Restart DDS middleware
    - Check firewall rules
    - Verify domain ID consistency

Issue: Sensor Failures
  Check:
    ros2 topic hz /sensor/topic
    ros2 topic echo /diagnostics
  Solutions:
    - Recalibrate sensor
    - Check connections
    - Update driver firmware

    5.2 Performance Profiling¶

    Bash
    # Profile ROS2 system
ros2 trace --profile lttng

# Analyze trace
tracecompass ~/lttng-traces/

# Generate report
python3 << 'EOF'
import subprocess
import json

# Get system metrics
metrics = {
    'cpu': subprocess.run(['top', '-bn1'], capture_output=True).stdout.decode().split('\n')[2],
    'memory': subprocess.run(['free', '-h'], capture_output=True).stdout.decode().split('\n')[1],
    'disk': subprocess.run(['df', '-h', '/'], capture_output=True).stdout.decode().split('\n')[1]
}

print(json.dumps(metrics, indent=2))
EOF
