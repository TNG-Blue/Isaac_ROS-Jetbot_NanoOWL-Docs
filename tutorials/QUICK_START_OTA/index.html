        ⚡ Quick Start: OTA Update for RT1062¶

        🚀 5-Minute Setup¶

        Step 1: Start Go Server (30 seconds)¶

        Bash
        1
2
        cd server_ota
go run server_ota.go

        ✅ Server running at http://localhost:8080

        Step 2: Upload Firmware (1 minute)¶

        Option A: Web UI 1. Open: http://localhost:8080 2. Drag & drop: RT1062_v2.1.0.py 3. Click "Upload"

        Option B: Command line

        Bash
        1
2
        curl -X POST http://localhost:8080/upload \
  -F "firmware=@RT1062_v2.1.0.py"

        Step 3: Update RT1062 Config (30 seconds)¶

        Python
        1
2
3
4
        # OpenMV_RT1062.py
class Config:
    OTA_SERVER = 'http://192.168.1.100:8080'  # Change IP
    FIRMWARE_VERSION = "2.0.0"

        Step 4: Test (2 minutes)¶

        Check for update:

        Python
        1
2
        # Send to RT1062
{"cmd": "OTA_CHECK"}

        Download:

        Python
        1
        {"cmd": "OTA_DOWNLOAD", "type": "firmware"}

        Apply:

        Python
        1
        {"cmd": "OTA_APPLY", "type": "firmware"}

        ✅ Done! Device will reboot with new firmware.

{"cmd": "OTA_ROLLBACK", "type": "firmware"}

// Get device statistics
{"cmd": "GET_STATS"}

        🐛 Troubleshooting¶

        Cannot connect?

        Bash
        1
2
3
4
5
6
7
8
        # Check server
curl http://192.168.1.100:8080/

# Check firewall
sudo ufw allow 8080

# Test ping
ping 192.168.1.100

        Update failed? - Re-upload firmware - Check file size - Verify network - Check server logs: server_ota/logs/

        📊 System Flow¶

        Text Only
        1
2
3
4
5
        1. Developer uploads firmware → Go Server
2. RT1062 checks for updates (auto every 1 hour)
3. RT1062 downloads new version
4. RT1062 applies & reboots
5. ✅ Updated!
