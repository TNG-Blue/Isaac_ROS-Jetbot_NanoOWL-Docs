        🔄 RT1062 ↔️ Go OTA Server Integration¶

        🎯 Overview¶

        Hệ thống OTA (Over-The-Air) update tích hợp hoàn toàn giữa RT1062 OpenMV và Go OTA Server chuyên nghiệp.

        ⚡ Quick Start (5 phút setup)¶

        Bước 1: Start Go OTA Server¶

        Bash
        1
2
        cd server_ota
go run server_ota.go

        Output:

        Text Only
        1
2
3
4
        🚀 Starting Embedded OTA Server v2.1.0...
✅ Server running at http://localhost:8080
📁 Firmware directory: ./firmware
💾 Memory limit: 64MB, Max concurrent: 5

        Bước 2: Upload Firmware¶

        Open browser: http://localhost:8080

        Upload file: RT1062_v2.1.0.py

        Bước 3: Configure RT1062¶

        Python
        1
2
3
4
5
        # OpenMV_RT1062.py
class Config:
    OTA_SERVER = 'http://192.168.1.100:8080'  # Your server IP
    FIRMWARE_VERSION = "2.0.0"
    DEVICE_TYPE = "RT1062"

        Bước 4: Test Update¶

        Send command to RT1062:

        JSON
        1
        {"cmd": "OTA_CHECK"}

        ✅ Done! RT1062 sẽ tự động detect và download update.

        🌐 Go Server API¶

        Web Dashboard¶

        URL: http://192.168.1.100:8080/

        Features: - 📊 View all firmware files - ⬆️ Upload new firmware (drag & drop) - ⬇️ Download firmware - 📈 View statistics (total files, downloads, etc.) - 🔍 File information (version, size, device type)

        📝 Firmware Naming Convention¶

        Format: {DEVICE_TYPE}_v{VERSION}.{EXT}

        Examples:

        Bash
        1
2
3
4
5
6
7
8
        RT1062_v2.0.0.py      ✅ Good
RT1062_v2.1.0.py      ✅ Good
RT1062_v2.2.0.bin     ✅ Good
rt1062_v2.0.0.py      ✅ Good (case-insensitive)

firmware.py           ❌ Bad (no version)
RT1062.py             ❌ Bad (no version marker)
v2.0.0.py             ❌ Bad (no device type)

        Server Auto-Extract: - Device Type: RT1062 - Version: v2.1.0 - Extension: .py, .bin, .hex, etc.

        🔐 Security¶

        1. HTTPS (Production)¶

        Generate cert:

        Bash
        1
        openssl req -x509 -newkey rsa:4096 -keyout key.pem -out cert.pem -days 365 -nodes

        Update Go server:

        Go
        1
        server.ListenAndServeTLS("cert.pem", "key.pem")

        Update RT1062:

        Python
        1
        OTA_SERVER = 'https://192.168.1.100:8443'

        🐛 Troubleshooting¶

        Problem: Cannot connect to server¶

        Text Only
        1
        [ERROR] OTA check failed: [Errno 113] EHOSTUNREACH

        Solutions: 1. Check server is running:

        Bash
        1
        curl http://192.168.1.100:8080/
        2. Verify IP address in Config 3. Check firewall:
        Bash
        1
        sudo ufw allow 8080
        4. Test ping:
        Bash
        1
        ping 192.168.1.100

        Problem: File size mismatch¶

        Text Only
        1
        [ERROR] Size mismatch! Expected: 45678, Got: 45600

        Solutions: 1. Re-upload firmware to server 2. Check network stability 3. Retry download 4. Verify file integrity on server

        Problem: Go server 503¶

        Text Only
        1
        [OTA] Server returned 503

        Solutions: 1. Server overloaded (rate limit) 2. Wait a few seconds and retry 3. Check server logs:

        Bash
        1
2
        cd server_ota/logs
tail -f ota_$(date +%Y-%m-%d).log

        Problem: Out of memory¶

        Text Only
        1
        [ERROR] Download failed: [Errno 12] ENOMEM

        Solutions: 1. Streaming download already implemented 2. Force garbage collection:

        Python
        1
        gc.collect()
        3. Reduce chunk size:
        Python
        1
        chunk_size = 256  # Default 512
