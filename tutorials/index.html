    Tutorial

    Tutorials¶

    Task-oriented walkthroughs. Each tutorial states what you need, gives commands you can run from a fresh checkout, and ends with measurable checks: an expected rate, a consistency statistic, an acceptance threshold or a test that passes. Every procedure comes from the README or design record of the package it uses, which remains the reference.

    Verification status

    Most of the stack is verified by unit tests and software-in-the-loop simulation. Hardware-in-the-loop and vehicle evidence is still being produced for several components; the tutorials say where. Follow the verification order of the Control Design Standard — model, SIL, HIL, bench with current limits, vehicle — and never skip ahead.

    Basic¶

    • Fly Your First Mission

      Write a mission file and fly it end to end in the full-stack SIL against wind and model error; avoid keep-out zones; re-task in flight. No hardware.

      Start

    • Calibrate the Stereo Camera

      Chessboard calibration with acceptance criteria, measurement of the disparity noise, and the NIS test of the per-pixel Kalman filter.

      Start

    • Connect the Flight Controller and Sensors

      Vehicle network, micro-ROS agent and jetowl_bridge; verify every sensor stream and its timestamps, on hardware or with the Gazebo virtual MCU.

      Start

    Advanced¶

    • Deploy a Custom Detection Model

      ONNX export, TensorRT engine on sm_87, the Isaac ROS decoder geometry, and the Kalman tracker that turns detections into estimates.

      Start

    • Configure and Validate 2-D LiDAR SLAM

      LD19 and LPB40B set-up, bench calibration of the range noise, mapping, and the consistency checks that come before navigation.

      Start

    • Connect a Ground Control Station

      QGroundControl over MAVLink: link budget, acknowledged commands, datalink-loss failsafe and the TLS relay for consoles behind NAT.

      Start

    Deployment¶

    • Deploy the Stack on a Two-Jetson Cluster

      One image per node, k3s on two boards, Helm, DDS across the boards, and a measured failover.

      Start

    • Update MCU Firmware Over the Air

      Publish a .fw release, download it to the inactive slot, apply it, and watch the A/B bootloader confirm or roll back.

      Start

    • Monitor a Running Robot

      Diagnostics of every package, the terminal node manager, cluster and Jetson resources, and what to record for a flight review.

      Start

    Suggested order¶

    If you want to… Follow
    see the system work without hardware Quick Start → Fly Your First Mission
    bring up a vehicle Hardware Setup → Connect the Flight Controller and Sensors → Monitor a Running Robot → Connect a Ground Control Station
    work on perception Calibrate the Stereo Camera → Configure and Validate 2-D LiDAR SLAM → Deploy a Custom Detection Model
    ship to the robot Deploy the Stack on a Two-Jetson Cluster → Update MCU Firmware Over the Air

    Writing a tutorial¶

    New tutorials follow the same structure: a table of time, prerequisites and outcomes; numbered steps with commands that run as written; a verifiable check after each step; links to the reference page. Claims about performance must come from a measurement in the repository, with its conditions. See Contributing.
