    HOW TO READ THIS FILE¶

    The Project spans several subsystems, each with its own dependency set: ROS 2 packages, CUDA and TensorRT libraries, MATLAB/Simulink models, microcontroller firmware, an Android client, a Go OTA server, Kubernetes/Helm deployment assets and an MkDocs documentation site. Components are grouped by subsystem below.

    • Bundled — source is vendored in this repository (including Git submodules) and is redistributed with it.
    • Linked — resolved at build time from the platform (JetPack, rosdep, apt, pip) and linked into Project binaries; not redistributed here.
    • Runtime / tooling — invoked as a separate process, driver or service, or used only to build the documentation; not linked into Project binaries and not redistributed here.

    License identifiers reflect each upstream project's stated license at the time of writing. Before redistributing a build, verify them against the LICENSE file in the version you actually ship — particularly for submodules, which track upstream branches.

    12. RADIO AND SDR HARDWARE SUPPORT (Source/ROS2_RF_Spectrum)¶

    The RF spectrum package addresses software-defined radios — HackRF, RTL-SDR, LimeSDR, USRP — through device configuration in config/sdr_config.yaml. The corresponding host libraries and drivers (libhackrf, librtlsdr, LimeSuite, UHD) are not bundled, not linked and not redistributed by this Project; the user installs them from their own distribution.

    ⚠️ libhackrf and librtlsdr are GPL-2.0 projects, which the Project's compatibility policy classifies as incompatible with Apache-2.0 for linked code. They are therefore used only through out-of-process tooling and kernel/USB drivers. Do not link GPL SDR libraries into a Project binary or container layer that you then redistribute under Apache-2.0.

    ⚠️ Radio transmission and spectrum monitoring are regulated activities. Operating an SDR with this software is the user's responsibility under the radio regulations of their jurisdiction.
