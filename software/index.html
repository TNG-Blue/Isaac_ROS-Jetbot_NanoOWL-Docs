        💻 Software Stack¶

        The Isaac ROS Jetbot NanoOWL software stack provides a comprehensive, containerized robotics development platform built on ROS 2 Humble with advanced AI/ML capabilities and distributed computing architecture.

        🎯 Software Philosophy

        Our software stack is designed with modularity, scalability, and maintainability as core principles. Every component is containerized, version-controlled, and follows industry best practices for robotics development.

        🏗️ Architecture Overview¶

        🌐 Application Layer

        🤖 Autonomous Navigation
        👁️ Object Detection
        🗺️ SLAM & Mapping
        🎮 Remote Control

        Purpose: High-level robotics applications and user interfaces

        🔄 Middleware Layer

        🤖 ROS 2 Humble
        📊 Isaac ROS
        🧠 NanoOWL
        🔧 micro-ROS

        Purpose: Communication, coordination, and real-time processing

        🐳 Container Layer

        🐳 Docker Engine
        ☸️ Kubernetes
        📊 Monitoring Stack
        🔧 CI/CD Pipeline

        Purpose: Orchestration, deployment, and infrastructure management

        🖥️ System Layer

        🐧 Ubuntu 22.04 LTS
        🎮 NVIDIA JetPack
        ⚡ CUDA Runtime
        🔧 Device Drivers

        Purpose: Operating system, drivers, and hardware abstraction

        🔥 Key Components¶

        🤖 ROS 2 Ecosystem¶

        • ROS 2 Humble LTS: Long-term support robotics middleware
        • Isaac ROS: NVIDIA's accelerated ROS packages
        • Navigation2: Advanced autonomous navigation stack
        • MoveIt2: Motion planning and manipulation framework

        🧠 AI/ML Framework¶

        • NanoOWL: Real-time object detection and classification
        • TensorRT: Optimized deep learning inference
        • OpenVINO: Intel neural network optimization
        • ONNX Runtime: Cross-platform ML model execution

        🐳 Container Platform¶

        • Docker: Application containerization
        • Kubernetes: Container orchestration and scaling
        • Helm: Package management for Kubernetes
        • Prometheus: Monitoring and alerting

        🎛️ Real-time Control¶

        • micro-ROS: Bridge between ROS 2 and microcontrollers
        • RT Kernel: Real-time Linux kernel patches
        • EtherCAT: Industrial Ethernet communication
        • CAN Bus: Controller Area Network protocol
