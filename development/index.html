    🚀 Getting Started¶

    Prerequisites¶

    Bash
    # System requirements
- Ubuntu 22.04 LTS
- Git 2.37+
- Python 3.10+
- C++ 17 compiler
- ROS2 Humble

# Development tools
- VS Code or similar IDE
- Docker (optional but recommended)
- colcon build system

    Development Setup¶

    Bash
    # 1. Clone repository
git clone https://github.com/TNG-Blue/Isaac_ROS-Jetbot_NanoOWL.git
cd Isaac_ROS-Jetbot_NanoOWL

# 2. Create development branch
git checkout -b feature/your-feature

# 3. Install dependencies
./install.sh

# 4. Build workspace
colcon build --symlink-install

# 5. Source setup
source install/setup.bash

    Commit Message Format¶

    Text Only
    <type>(<scope>): <subject>

<body>

Fixes #<issue-number>

    Types: feat, fix, docs, style, refactor, test, chore
    Scope: detection, slam, control, etc.

    Example:

    Text Only

- Implement NanoOWL inference node
- Add vision-language model preprocessing
- Support dynamic model switching
