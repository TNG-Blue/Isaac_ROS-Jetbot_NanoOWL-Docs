    CI/CD Pipeline¶

    Continuous Integration and Continuous Deployment infrastructure for Isaac ROS Jetbot NanoOWL.

    🎯 Overview¶

    Our CI/CD pipeline ensures: - ✅ Automated Testing: Every commit is tested - ✅ Code Quality: Style and lint checks enforced - ✅ Build Verification: Multi-platform builds - ✅ Automated Deployment: Docker images and docs

    🔄 CI Workflow¶

    Pipeline Stages¶

    graph LR
    A[Push/PR] --> B[Lint & Format]
    B --> C[Build]
    C --> D[Unit Tests]
    D --> E[Integration Tests]
    E --> F[Docker Build]
    F --> G[Deploy Docs]
    G --> H[Release]

    🧪 GitHub Actions Workflows¶

    Main CI Workflow¶

    .github/workflows/ci.yml:

    YAML
    name: Continuous Integration

on:
  push:
    branches: [main, master, develop]
  pull_request:
    branches: [main, master]

jobs:
  lint:
    name: Code Quality Checks
    runs-on: ubuntu-22.04

    steps:
      - uses: actions/checkout@v3

      - name: Setup Python
        uses: actions/setup-python@v4
        with:
          python-version: '3.10'

      - name: Install linters
        run: |
          pip install black flake8 isort
          sudo apt install clang-format -y

      - name: Check Python formatting
        run: |
          black --check src/
          flake8 src/
          isort --check-only src/

      - name: Check C++ formatting
        run: |
          find src/ -name "*.cpp" -o -name "*.hpp" | \
            xargs clang-format --dry-run -Werror

  build:
    name: Build & Test
    runs-on: ubuntu-22.04
    needs: lint

    steps:
      - uses: actions/checkout@v3

      - name: Setup ROS2 Humble
        uses: ros-tooling/setup-ros@v0.6
        with:
          required-ros-distributions: humble

      - name: Install dependencies
        run: |
          sudo apt update
          rosdep update
          rosdep install --from-paths src --ignore-src -y

      - name: Build
        run: |
          source /opt/ros/humble/setup.bash
          colcon build --symlink-install --cmake-args -DCMAKE_BUILD_TYPE=Release

      - name: Run tests
        run: |
          source /opt/ros/humble/setup.bash
          source install/setup.bash
          colcon test --return-code-on-test-failure

      - name: Test results
        uses: actions/upload-artifact@v3
        if: always()
        with:
          name: test-results
          path: build/*/test_results/*.xml

  docker:
    name: Docker Build
    runs-on: ubuntu-22.04
    needs: build
    if: github.event_name == 'push'

    steps:
      - uses: actions/checkout@v3

      - name: Set up Docker Buildx
        uses: docker/setup-buildx-action@v2

      - name: Login to Docker Hub
        uses: docker/login-action@v2
        with:
          username: ${{ secrets.DOCKER_USERNAME }}
          password: ${{ secrets.DOCKER_PASSWORD }}

      - name: Build and push
        uses: docker/build-push-action@v4
        with:
          context: .
          platforms: linux/amd64,linux/arm64
          push: true
          tags: |
            tngblue/jetbot-nanoowl:latest
            tngblue/jetbot-nanoowl:${{ github.sha }}
          cache-from: type=registry,ref=tngblue/jetbot-nanoowl:buildcache
          cache-to: type=registry,ref=tngblue/jetbot-nanoowl:buildcache,mode=max

  docs:
    name: Deploy Documentation
    runs-on: ubuntu-22.04
    needs: build
    if: github.ref == 'refs/heads/main'

    steps:
      - uses: actions/checkout@v3

      - name: Setup Python
        uses: actions/setup-python@v4
        with:
          python-version: '3.10'

      - name: Install MkDocs
        run: |
          pip install mkdocs-material mkdocs-git-revision-date-localized-plugin

      - name: Build docs
        run: mkdocs build

      - name: Deploy to GitHub Pages
        uses: peaceiris/actions-gh-pages@v3
        with:
          github_token: ${{ secrets.GITHUB_TOKEN }}
          publish_dir: ./site

    🐳 Docker Build Pipeline¶

    Multi-stage Dockerfile¶

    Docker
    # syntax=docker/dockerfile:1
ARG ROS_DISTRO=humble
ARG BASE_IMAGE=dustynv/ros:${ROS_DISTRO}-pytorch-l4t-r35.4.1

# =============================================================================
# Base Stage: Common dependencies
# =============================================================================
FROM ${BASE_IMAGE} as base

ENV DEBIAN_FRONTEND=noninteractive
WORKDIR /workspace

# Install system dependencies
RUN apt-get update && apt-get install -y \
    build-essential \
    cmake \
    git \
    python3-pip \
    && rm -rf /var/lib/apt/lists/*

# Install Python dependencies
COPY requirements.txt .
RUN pip3 install --no-cache-dir -r requirements.txt

# =============================================================================
# Builder Stage: Compile ROS2 packages
# =============================================================================
FROM base as builder

# Copy source code
COPY . /workspace/src/Isaac_ROS-Jetbot_NanoOWL

# Install ROS dependencies
RUN . /opt/ros/${ROS_DISTRO}/setup.sh && \
    rosdep update && \
    rosdep install --from-paths src --ignore-src -y

# Build packages
RUN . /opt/ros/${ROS_DISTRO}/setup.sh && \
    colcon build \
      --symlink-install \
      --cmake-args -DCMAKE_BUILD_TYPE=Release \
      --parallel-workers 4

# =============================================================================
# Runtime Stage: Minimal runtime image
# =============================================================================
FROM base as runtime

# Copy built packages from builder
COPY --from=builder /workspace/install /workspace/install

# Setup entrypoint
COPY ./docker/entrypoint.sh /entrypoint.sh
RUN chmod +x /entrypoint.sh

ENTRYPOINT ["/entrypoint.sh"]
CMD ["ros2", "launch", "jetbot_nanoowl", "bringup.launch.py"]

    Build Script¶

    scripts/build_docker.sh:

    Bash
    #!/bin/bash
set -e

VERSION=${1:-latest}
PLATFORMS="linux/amd64,linux/arm64"

echo "Building Docker image: tngblue/jetbot-nanoowl:${VERSION}"

docker buildx build \
  --platform ${PLATFORMS} \
  --tag tngblue/jetbot-nanoowl:${VERSION} \
  --tag tngblue/jetbot-nanoowl:latest \
  --push \
  --cache-from type=registry,ref=tngblue/jetbot-nanoowl:buildcache \
  --cache-to type=registry,ref=tngblue/jetbot-nanoowl:buildcache,mode=max \
  .

echo "Build complete!"

    📦 Release Pipeline¶

    Automated Releases¶

    .github/workflows/release.yml:

    YAML
    name: Release

on:
  push:
    tags:
      - 'v*'

jobs:
  release:
    name: Create Release
    runs-on: ubuntu-22.04

    steps:
      - uses: actions/checkout@v3
        with:
          fetch-depth: 0

      - name: Generate changelog
        id: changelog
        run: |
          # Generate changelog since last tag
          CHANGELOG=$(git log $(git describe --tags --abbrev=0 HEAD^)..HEAD --pretty=format:"- %s (%h)")
          echo "changelog<<EOF" >> $GITHUB_OUTPUT
          echo "$CHANGELOG" >> $GITHUB_OUTPUT
          echo "EOF" >> $GITHUB_OUTPUT

      - name: Create Release
        uses: actions/create-release@v1
        env:
          GITHUB_TOKEN: ${{ secrets.GITHUB_TOKEN }}
        with:
          tag_name: ${{ github.ref }}
          release_name: Release ${{ github.ref }}
          body: |
            ## What's Changed
            ${{ steps.changelog.outputs.changelog }}

            ## Docker Images
            ```bash
            docker pull tngblue/jetbot-nanoowl:${{ github.ref_name }}
            ```

          draft: false
          prerelease: false

      - name: Build release artifacts
        run: |
          tar -czf isaac-ros-jetbot-${{ github.ref_name }}.tar.gz src/

      - name: Upload artifacts
        uses: actions/upload-release-asset@v1
        env:
          GITHUB_TOKEN: ${{ secrets.GITHUB_TOKEN }}
        with:
          upload_url: ${{ steps.create_release.outputs.upload_url }}
          asset_path: ./isaac-ros-jetbot-${{ github.ref_name }}.tar.gz
          asset_name: isaac-ros-jetbot-${{ github.ref_name }}.tar.gz
          asset_content_type: application/gzip

    🧪 Pre-commit Hooks¶

    .pre-commit-config.yaml:

    YAML
    repos:
  # Python formatting
  - repo: https://github.com/psf/black
    rev: 23.1.0
    hooks:
      - id: black
        language_version: python3

  # Python linting
  - repo: https://github.com/pycqa/flake8
    rev: 6.0.0
    hooks:
      - id: flake8
        args: ['--max-line-length=100']

  # Python import sorting
  - repo: https://github.com/pycqa/isort
    rev: 5.12.0
    hooks:
      - id: isort

  # C++ formatting
  - repo: https://github.com/pre-commit/mirrors-clang-format
    rev: v15.0.7
    hooks:
      - id: clang-format

  # YAML validation
  - repo: https://github.com/pre-commit/pre-commit-hooks
    rev: v4.4.0
    hooks:
      - id: check-yaml
      - id: end-of-file-fixer
      - id: trailing-whitespace

  # Copyright headers
  - repo: local
    hooks:
      - id: copyright-check
        name: Check copyright headers
        entry: scripts/check_copyright.sh
        language: script
        files: \.(py|cpp|hpp|h)$

    🔒 Security Scanning¶

    Dependency Scanning¶

    .github/workflows/security.yml:

    YAML
    name: Security Scan

on:
  schedule:
    - cron: '0 0 * * 0'  # Weekly
  push:
    branches: [main]

jobs:
  dependency-scan:
    runs-on: ubuntu-22.04

    steps:
      - uses: actions/checkout@v3

      - name: Run Snyk
        uses: snyk/actions/python@master
        env:
          SNYK_TOKEN: ${{ secrets.SNYK_TOKEN }}

      - name: Upload results
        uses: github/codeql-action/upload-sarif@v2
        with:
          sarif_file: snyk.sarif

    🎯 Best Practices¶

    1. Fast Feedback: Keep CI runs under 10 minutes
    2. Fail Fast: Run quick checks first (lint before build)
    3. Cache Dependencies: Speed up builds with caching
    4. Parallel Execution: Run independent jobs in parallel
    5. Clear Logs: Make failures easy to debug
    6. Branch Protection: Require CI pass before merge
