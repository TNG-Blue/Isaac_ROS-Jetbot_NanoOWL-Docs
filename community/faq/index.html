    Frequently Asked Questions¶

    Common questions about Isaac ROS Jetbot NanoOWL.

    🚀 Getting Started¶

    What hardware do I need?

    Minimum: - NVIDIA Jetson Nano (4GB) - Camera module - MicroSD card (64GB+) - Power supply

    Recommended: - Jetson Orin Nano (8GB) - Multiple cameras/sensors - NVMe SSD - See Hardware Setup

    Can I use different Jetson models?

    Yes! Supported platforms: - ✅ Jetson Nano - ✅ Jetson Xavier NX - ✅ Jetson AGX Xavier - ✅ Jetson Orin Nano - ✅ Jetson AGX Orin

    Performance varies by model.

    Do I need robotics experience?

    No! Our Quick Start Guide is beginner-friendly. However, basic Linux knowledge helps.

    What's the fastest way to get started?

    Use Docker installation:

    Bash
    git clone https://github.com/TNG-Blue/Isaac_ROS-Jetbot_NanoOWL.git
cd Isaac_ROS-Jetbot_NanoOWL
docker-compose up -d
    See Quick Start

    🔧 Installation & Setup¶

    Which installation method should I choose?
    • Docker: Fastest, easiest, recommended for beginners
    • Native: Best performance, for developers
    • Kubernetes: For production/fleet deployment
    Installation fails with memory error

    Reduce parallel workers or add swap:

    Bash
    colcon build --parallel-workers 1
# Or add 4GB swap
sudo fallocate -l 4G /swapfile
sudo mkswap /swapfile
sudo swapon /swapfile

    How much disk space do I need?
    • Minimum: 32GB (basic installation)
    • Recommended: 128GB+ (includes models, data)
    • Docker: Additional 10GB for containers

    📹 Camera & Sensors¶

    Camera not detected
    1. Check physical connection
    2. Verify permissions:
      Bash
      sudo usermod -aG video $USER
ls -l /dev/video0
    3. Test camera:
      Bash
      nvgstcapture-1.0
    Which cameras are supported?
    • ✅ CSI cameras (OV5647, IMX219, IMX477)
    • ✅ USB webcams
    • ✅ Thermal cameras
    • ✅ Stereo camera pairs
    Low frame rate from camera
    • Reduce resolution: 640x640 instead of 1920x1080
    • Lower framerate parameter
    • Check CPU/GPU usage with tegrastats

    🎯 Object Detection¶

    Detection not working
    1. Check model file exists
    2. Verify GPU access:
      Bash
      python3 -c "import torch; print(torch.cuda.is_available())"
    3. Check logs:
      Bash
      ros2 node info /object_detection
    Detection accuracy is low
    • Lower confidence threshold (0.3-0.5)
    • Use better lighting
    • Try larger model (yolov8s vs yolov8n)
    • Calibrate camera
    Can I use custom object classes?

    Yes! Train custom YOLOv8 model and convert to TensorRT. See Custom Models Tutorial

    🗺️ Navigation & SLAM¶

    Robot not building map
    1. Check LIDAR data:
      Bash
      ros2 topic echo /scan
    2. Ensure LIDAR spinning
    3. Drive slowly during mapping
    4. Check TF tree
    Navigation fails to reach goal
    • Ensure clear path in costmap
    • Check robot footprint size
    • Adjust inflation radius
    • Use intermediate waypoints
    SLAM drift over time
    • Enable loop closure
    • Add more distinctive features to environment
    • Calibrate IMU
    • Use better odometry

    ⚡ Performance¶

    System running slow
    1. Check power mode:
      Bash
      sudo nvpmodel -m 0  # Max performance
sudo jetson_clocks
    2. Monitor resources:
      Bash
      tegrastats
    3. Reduce workload (lower resolution, simpler model)
    What FPS should I expect?

    On Jetson Orin Nano (640x640 input): - YOLOv8n: 35-45 FPS - YOLOv8s: 25-30 FPS - YOLOv8m: 15-20 FPS

    High latency
    • Use Ethernet instead of WiFi
    • Reduce QoS history depth
    • Enable GPU power mode
    • Check network with ping

    🐛 Troubleshooting¶

    ROS2 nodes can't communicate
    1. Check ROS_DOMAIN_ID:
      Bash
      echo $ROS_DOMAIN_ID
    2. Test multicast:
      Bash
      ros2 multicast receive
ros2 multicast send  # In another terminal
    3. Check firewall
    Build fails

    See Troubleshooting Guide

    Where are log files?
    Bash
    ~/.ros/log/
~/ros2_ws/log/

    📦 Docker & Deployment¶

    Docker container won't start
    1. Check Docker daemon:
      Bash
      sudo systemctl status docker
    2. Verify GPU access:
      Bash
      docker run --rm --runtime nvidia nvidia/cuda:11.8.0-base-ubuntu22.04 nvidia-smi
    3. Check logs:
      Bash
      docker-compose logs
    How to update Docker images?
    Bash
    docker-compose pull
docker-compose up -d
