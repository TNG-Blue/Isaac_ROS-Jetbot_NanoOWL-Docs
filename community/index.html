    🆘 Getting Help¶

    Before You Ask¶

    1. Search existing discussions and issues - Your question might already be answered
    2. Check the documentation - We have comprehensive guides for most topics
    3. Review the FAQ - Common questions are answered there

    How to Ask Good Questions¶

    Writing Effective Questions

    • Be specific: Include error messages, code snippets, and system info
    • Show what you've tried: Demonstrate your debugging efforts
    • Provide context: Explain what you're trying to achieve
    • Use code blocks: Format code properly for readability
    • Include versions: Specify ROS2, JetPack, and library versions

    Example of a good question:

    **Environment:**
- Jetson Orin Nano Super 8GB
- JetPack 6.2
- ROS2 Humble
- Isaac ROS Jetbot NanoOWL v1.0.0

**Issue:**
Object detection node crashes with "CUDA out of memory" error after 5 minutes.

**What I've tried:**
- Reduced batch size from 8 to 4
- Lowered model resolution from 640x640 to 320x320
- Monitored GPU memory with nvidia-smi

**Error output:**
    RuntimeError: CUDA out of memory. Tried to allocate 256.00 MiB 
    **Question:**
How can I further optimize GPU memory usage for long-running detection?

    ❓ Frequently Asked Questions¶

    How do I get started with the project?

    Check out our Quick Start Guide to get up and running in 30 minutes.

    What hardware do I need?

    At minimum, you need a Jetson Orin Nano Super and one camera. See Hardware Requirements for details.

    Can I use this for commercial projects?

    Yes! The project is licensed under Apache 2.0, which allows commercial use. See License for details.

    How can I contribute?

    Read our Contributing Guide to learn how to submit code, documentation, or ideas.

    Is there professional support available?

    Yes, we offer professional support packages for enterprise users. Contact us for details.

    What ROS2 version is required?

    We officially support ROS2 Humble Hawksbill on Ubuntu 22.04 LTS.
